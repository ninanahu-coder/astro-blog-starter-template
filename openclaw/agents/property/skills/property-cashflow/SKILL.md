# 投资房现金流测算（西澳口径）

## 输入（5 项，缺则追问）

`P` 购入价 · `d` 首付比例 · `r` 贷款年利率 · `W` 预期周租 · `t` 边际税率（37% 常见档）

## 一次性成本

- **印花税（WA transfer duty，一般住宅档，2025-26 口径）**：分级累进——
  ≤A$120k：1.9%；120k–150k：$2,280 + 超出部分 2.85%；150k–360k：$3,135 + 3.8%；
  360k–725k：$11,115 + 4.75%；>725k：$28,453 + 5.15%
  ⚠️ 档位随预算案调整，计算前联网核对 WA RevenueOnline 当前档位。
- 过户与杂费：约 A$2,500–4,000（估）
- **LMI**：首付 < 20% 时提示（约为贷款额 1–4%，按 LVR 查表，标注为估算）

## 年度现金流

```
贷款额 L        = P × (1 − d)
年利息 I        = L × r            （只息 IO 口径；PI 口径注明本金部分不计税抵扣）
年租金收入 R    = W × 52 × (1 − 空置假设 2%)
持有成本 H      = council rates + water + 保险 + 物业管理费(约 R×8%) + strata(如有) + 维修预留
                  （无实际数据时用估算并逐项标「估」）
折旧 D          = 新房可观 / 老房有限——提示需 quantity surveyor 报告，演示口径用 0 或客户提供值
税前缺口 G      = R − I − H
负扣税退税 T    = G < 0 时： |G − D| × t   （即（亏损+折旧）×边际税率）
税后现金流 C    = G + T
每周口径        = C ÷ 52
```

## 输出模板

| 项目 | 年额 | 周额 |
|---|---|---|
| 租金收入（扣 2% 空置） | | |
| 贷款利息 | | |
| 持有成本合计 | | |
| 税前现金流 | | |
| 负扣税退税（边际税率 t） | | |
| **税后真实现金流** | | |

随后给「利率 +1%」情景的同表，并用一句话对比。

## 示例（自检用）

P=750k，d=20%，r=6.1%，W=$650，t=37%：
L=600k；I=36.6k；R=33.1k；H≈7.5k（估）；G=−11.0k；D=0；T≈4.1k；C≈−6.9k ≈ **−$133/周**。
输出必须能复现该量级，偏差大于 5% 说明算错，重算。
