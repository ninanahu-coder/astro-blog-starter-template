# 新手引导与教程系统

> 分支 `claude/earth-onboarding`，从 `claude/earth-start-ui`（ddceeca，入境卡开场）开，更新日志 v36。
> 每一节都标了状态：
> - **【现状】**：main 或起点分支上已经有的；
> - **【v36 已做】**：本分支落地的第一版；
> - **【提议】**：还没做。
>
> 数字都是**待平衡**：第几天解开、离开几天算回流，交 Codex 跑数据后再定（AGENTS.md）。

## 0. 起点分支为什么选 `claude/earth-start-ui`

- 引导从「盖章入境」那一刻接着往下走。便签、回流卡片沿用入境卡的令牌（卡纸、墨蓝、圆珠笔蓝、入境章洋红），这些令牌和 `DESIGN.md`、`.impeccable/` 方向契约只在这个分支上。从 main 开的话，要么复制一份令牌，要么等合并后返工。
- 这个分支只比 main 多一个提交（ddceeca），改动集中在 `#create`，和本分支改的今天页、各页顶部、设置页不重叠。合并顺序：先合 `earth-start-ui`，再合本分支。
- 和 `claude/earth-main-ui`（4efad46）的关系：那边整块换了 `:root` 的令牌，并改了 `.next`、hero、toast 几处。本分支的新样式都用自己的类名（`.slip`、`.back-card`、`.later`），只在 `#create` 的令牌选择器上加了两个类名。合并时这一行要手工合一下。

## 1. 玩家与「值回票价」的那一刻

- **玩家**：在西澳、南澳的华人和留学生，手机为主。大多玩过手游，但没玩过这种「地图是真的」的生活模拟。
- **值回票价的那一刻（假设，待用户确认）**：在游戏里看到自己住的城市、自己去过的店，然后第一次「人到现场」在真实地点打卡。
  - 前 10 分钟到不了这一步：要先学会需求和出行。
  - 前 3 天的目标是把玩家带到那里。
- **原则**：
  - 不另做教学模式，所有教学都发生在真玩法里；
  - 一次只教一件事；
  - 每条提示都能关；
  - 老玩家什么都看不到。

## 2. 现有的引导零件【现状】

| 零件 | 在哪 | 做什么 | 存在哪 |
| --- | --- | --- | --- |
| 入境卡开场 | `#create`（`earth-start-ui`） | 四步建角色，盖章入境；登机牌存根是同步码恢复入口 | 云端存档 |
| 新手指南 | `data/guide.ts` + `core/guide.ts`，今天页 `.guide` 卡 | 前 3 天每天一组步骤，做到自动打勾，提前做完提前解开下一组；「去看看」跳到对应页 | 进度从存档推算；「知道了」关掉整张卡，写在**本机** `prefs.guide` |
| 下一步 | 今天页 `.next` 卡 | 按需求最低项、能不能上班、在不在家，给出一件事和一个按钮 | 不存 |
| 每日奖励提示 | `dailyNote` | 每个现实日第一次读档时 toast 一句 | 云端 `daily` |
| 主线第一章 | `data/story.ts` | 「落地珀斯的头一周」：吃饭、认识人、出去走走，章末发奖 | 云端 `story` |
| 玩法说明 | `facts.ts`、`placeFacts`、「我 · 设置 · 玩法说明」 | 常驻的说明 | 不存 |
| 昨天回顾、更新日志 | 今天页 `.recap`、「我 · 更新」 | 跨日回顾；更新有没有看过 | 本机 |

**缺口**：

- 今天页从第一分钟起就摆着钓鱼、课程、证书、车行、房产等所有卡片，新玩家不知道先看哪个。
- 出行、附近、成长、社交、「我」这几页，第一次进去时没有任何说明。尤其「附近」要求人在现场，新玩家常以为它坏了。
- 同步码没人教：换手机就丢档，是这类网页游戏流失的头号原因。
- 离开几天再回来时，只有一句每日奖励（连续天数还被清零），没有「你停在哪」。
- 指南的「知道了」只存本机，换设备又会出现。

## 3. 体验路线

### 3.1 前 10 分钟【现状 + v36】

| 时刻 | 玩家看到 | 学会什么 | 来源 |
| --- | --- | --- | --- |
| 0:00 | 入境卡盖章 → 今天页 | 角色 = 一张入境卡；起始现金和有没有车 | 【现状】 |
| 0:10 | 「下一步」卡 + 新手指南第 1 天：按下一步做一件事 | **需求**：做事花时间，需求跟着变 | 【现状】 |
| 1:00 | 指南：和当地人聊天 | 今天页「这里的人」，好感 | 【现状】 |
| 3:00 | 今天页底部「之后会出现：钓鱼……（到第 2 天或去过第二个地方）」 | 页面会长出来，不用一次看懂 | 【v36】 |
| 4:00 | 第一次点「出行」：顶部便签「路费和时间出发前就写着」 | **出行**：选路线、选走法、没去过的点是橙色 | 【v36】 |
| 5:00 | 到第二个地方 → toast「🔓 新出现：爱好（钓鱼、摄影、观鸟……）和星空；车行和修车厂」，今天页一张「新出现」便签 | 新东西出现在哪 | 【v36】 |
| 8:00 | 精力低 → 下一步提示去睡；指南：找地方过第一夜 | 过夜、跨日 | 【现状】 |

### 3.2 前 3 天【现状 + v36】

| 天 | 新手指南（自动打勾） | 同时出现的 | 来源 |
| --- | --- | --- | --- |
| 第 1 天 | 下一步、聊天、过夜 | 出行页便签 | 【现状】+【v36】 |
| 第 2 天 | 去新地方、找工作、**上一个班** | 钓鱼、摄影、星空、课程证书、车行修车厂自动出现；成长页、社交页第一次进去有便签 | 【现状】+【v36】 |
| 第 3 天 | 有落脚处、去过 3 个地方、**记下同步码**、**真实打卡**（附近） | 房产出现；「附近」第一次进去的便签说清「要人在现场，不在外面就跳过」；「我 · 设置」的便签教同步码 | 【v36】新增「记下同步码」一步 |

- **打工**：第 2 天由指南教（应聘 → 上班），主线第一章也有对应目标。【现状】
- **真实打卡**：指南第 3 天的最后一步，配合「附近」页便签。【现状】+【v36】

### 3.3 第 4 天以后【提议】

- 指南结束后，下一步卡片接手；主线第二章接着推。
- **提议**：第 4–7 天每天一条「今天可以试试」，从还没碰过的系统里挑一个：共同事件、二手摊、周目标、图鉴。
  - 只挑玩家没做过的；
  - 数据驱动，加在 `data/onboard.ts`。

## 4. 渐进出现【v36 已做】

- **只藏、不锁**：卡片暂时不显示，功能本身不加门槛，引擎规则不变。
  - 在今天页之外能做的事照样能做，比如车行的「买车」动作。
- **核心循环从第一分钟就在**：需求、下一步、心愿、做事、工作、住处、出行、真实定位打卡，都不受影响。
- **底部 5 个标签不藏**：底部导航保持固定，方便记位置，读屏的地标也稳定。

| 功能 id | 包含的卡片 | 什么时候出现（任一即可，**待平衡**） |
| --- | --- | --- |
| `hobby` | 钓鱼、摄影任务、爱好卡（摄影、观鸟、园艺、手工、乐器）、今天的天（星空） | 第 2 天；去过第二个地方 |
| `study` | 课程、职业证书 | 第 2 天；有工作；已有证书 |
| `garage` | 车行、修车厂 | 第 2 天；有车（留学生开局就有）；去过第二个地方 |
| `estate` | 房产 | 第 3 天；有住处；已有房产 |

**规则**：

- **解开后永远显示**：每次成功的动作之后，`settleOnboard()` 把条件已满足的功能记进存档的 `onboard.feats`，只增不减。
  - 例如卖了车，车行也不会再藏起来。
- **玩家知道还有什么**：今天页最下面写「之后会出现：……（怎么让它出现）」。
- **新出现的功能有提示**：
  - 动作结果后面接「🔓 新出现：…」；
  - 今天页一张「新出现」便签，写在哪里找。
- **老手可以跳过**：
  - 「现在全部显示」按钮一次解开全部；
  - 设置里关掉「引导提示和渐进出现」后，所有卡片直接显示。

## 5. 上下文提示（便签）【v36 已做】

- 第一次进入下面这些页面时，页面顶部出现一张便签：
  - 出行、附近、成长、社交；
  - 「我」，便签上有「去看同步码」按钮；
  - 「我 · 设置」，讲同步码别外传。
- 一页最多一条。
- 点「知道了」后：
  - 本机马上藏起来，不等服务器；
  - 再把引导动作发给服务器记进 `onboard.tips`，换设备也不再出现。
- 断网时动作留在本机内存里，30 秒后下次画界面时再交。
- 关掉全部引导后再打开：页面便签重新出现一次。里程碑（同步码）和「新出现」不重放。
- 今天页不加页面便签，那里由新手指南负责。

**外观**：

- 入境卡世界的「登机牌撕线存根」：
  - 左边是护照深蓝的存根，放金色线条图标，和底部标签用同一套图标；
  - 中间一道打孔虚线，上下各一个半圆缺口；
  - 右边是卡纸正文：墨蓝粗体标题、墨蓝正文、圆珠笔蓝按钮。
  - 标题不用衬线：`Terra Serif` 子集只有开场用到的十几个汉字，便签文案里的字大多不在里面，会混进回退字体。
- 卡纸在浅色和深色主题下都保持纸色（DESIGN.md「卡片是实物」）。

## 6. 回流提示【v36 已做】

- **触发**：
  - 服务端在这个现实日第一次读档、发每日奖励之前调用 `noteReturn()`；
  - 上次领奖的日子离今天 ≥ 3 天（**待平衡**）就记下 `onboard.back = { day, gap, seen: false }`；
  - 从没领过奖的不算。
- **显示**：回来当天和第二天，今天页最上面一张「再入境」卡片：
  - 一枚洋红双圈章「入境 / RE-ENTRY / N DAYS」，只用字体子集里有的字形；落下时有 460ms 指数缓出，减少动态效果时直接出现；
  - 标题「欢迎回来，离开了 N 天」；
  - 一句实话：游戏里的时间没有走，需求和钱都停在你离开时的样子；
  - 主线停在哪一步；
  - 有需求低于 30 时提醒先补；
  - 离开期间的更新，取更新日志里日期晚于离开那天的，最多 3 条。
- **关闭**：
  - 「知道了，接着玩」后记 `seen: true`；
  - 不点的话，两天后自动不再显示；
  - 关掉全部引导也照样显示，因为这不是教学。
- **【提议】**：
  - 离开 ≥ 14 天的回流玩家，可以把新手指南里没做完的步骤重新拿出来；
  - 每日奖励的连续天数怎么处理（现在断了清零），交 Codex 看留存数据再说。

## 7. 存档字段与迁移

```ts
onboard: {
  feats: string[];      // 已解开的功能 id（只增不减）
  tips: string[];       // 已关掉的页面提示 id、'feat:<功能 id>'、里程碑（'sync-kept'）
  back: { day: number; gap: number; seen: boolean } | null; // 最近一次回流：现实日、离开天数、看过没有
  off: boolean;         // 玩家关掉了全部引导
}
```

- **写入只走服务端**：
  - 新动作 `{ t: 'onboard', op: 'tip' | 'off' | 'on' | 'back' | 'all' }` 经 `parseAction()` 校验，`tip` 只认已知 id；
  - 由 `applyAction()` 结算：不花时间，有待处理事件时也能关提示，不算心愿和主线；
  - 没有变化时不加版本号。
- **校验**：`sanitizeState()` 里的 `cleanOnboard()` 只留已知 id、去重。回流记录的 `gap` 小于门槛或日期在未来（按服务端时间）就丢掉。
- **迁移（假设）**：
  - 存档同步分支（`claude/earth-save-sync`）正在制定 `PlayerState` 新字段的迁移规范，写本文时还没出来。
  - 本分支先按下面的约定做，规范出来后对齐：
    - 字段**缺失** = 这个功能上线前建的老角色，全部解开、所有提示当作看过（`veteranOnboard()`）；
    - 字段**存在但结构不对** = 按新角色处理（`freshOnboard()`）；
    - 新角色由 `createCharacter()` 写入 `freshOnboard()`。
  - 如果规范要求用存档版本号（`v`）判断迁移，把「缺失 = 老角色」改成按版本号判断即可，其他逻辑不动。
- **本机仍保留的**：新手指南卡的「知道了」（`prefs.guide`）、昨天回顾、更新已读。这三样是显示偏好，不在本轮迁移。
  - **【提议】**：把指南的「知道了」也并进 `onboard.off`，等存档同步规范定了再一起迁。

## 8. 无障碍

| 项 | 做法 | 状态 |
| --- | --- | --- |
| 读屏 | 便签和回流卡片是带标题的 `section`（`aria-labelledby`）；图标 `aria-hidden`；关掉按钮的 `aria-label` 写全「关掉提示「……」，以后不再出现」 | 【v36】 |

| 对比度 | 卡纸上墨蓝正文 ≥ 6.5:1（DESIGN.md）；存根金色图标只是装饰 | 【v36】 |
| 新出现的卡片 | 不插进读屏朗读队列，避免打断；动作结果的 toast（`role="status"`）已带「新出现：…」 | 【v36】 |
| 页面级「跳到下一步」 | **提议**：今天页顶部加一个只对键盘可见的「跳到下一步」链接 | 【提议】 |
