# 界面配图设计清单（第 21 批）

地点主视觉（35 张）和事件插图（84 张）之外，按界面逐个看了哪里适合加 AI 生成的 CG。玩家主要用手机，所以只给「一眼能认出是什么」的地方配图：

- 行内缩略图替换或补在 `.row` 左边的 emoji 方块（48px，圆角 12px）；
- 卡片顶上的封面（沿用地点卡的 `.hero` 样式，高 140px）；
- 页头横幅（高 96px 的一条）和空状态小插图。

规则：

- 所有图都由 `tools/earth/comfyui/prompts.mjs` 生成任务，`npm run earth:cgi:gpti -- --only=<键名>` 出图，`manifest.json` 索引，页面用 `cgi[键名]` 读取。
- 有图用图，没图退回现在的样式（emoji 方块、无封面）；所有插值经过 `esc()`。
- 方形任务出 1024×1024（Codex 通道不严格按尺寸出图，脚本按 PNG 实际宽高居中裁正方形），压成 256 宽 WebP；宽图出 1536×1024，压成 960 或 640 宽。
- 提示词规则同地点和事件：不写游戏标签词（机场、医院、健身房、车行）；有人只写背影、剪影或手；不分州的画面写「普通澳洲场景、不要地标」；不让人物裸上身。

## 三、维护

- 新增体验、摄影任务、节日、车辆、房产、住处、职业、课程、证书、鱼时，在 `prompts.mjs` 对应的 `*_SCENE` 表补一句英文画面再跑脚本；`tests/earth/cgi.test.ts` 会检查每项都有图、尺寸合规。
- 改了某一类的画风，只要加 `--force` 和 `--only=` 重跑那几张。
