# 主界面设定：入境之后（v27）

> 范围：进入游戏后的 `#game`。包括顶栏 `#hud`、今天页、底部标签 `#tabs`、出行页（地图 + 路线 / 附近）、事件弹窗 `#modal`、提示条 `#toast`。
> 开场 `#create` 不在本文件，它的方向契约在 `claude/earth-start-ui` 分支的 `.impeccable/surfaces/src-pages-earth-astro.md`。
> 本轮只改界面表现：规则、数值、文案、无障碍约定都不动（`src/game/core` 没碰）。

## 1. 同一个世界

开场是“落地澳洲”：护照封皮加一张入境卡。进了游戏，玩家手里拿的就是**盖过章的入境卡和登机牌存根**。主界面不另起风格，只把开场的材料延伸到每天要用的界面上。

| 材料 | 开场里的样子 | 主界面里用在哪 |
| --- | --- | --- |
| 护照封皮深海军蓝 `#15284d` | 封皮底色 | 顶栏（非今天页）、地点名牌、「下一步」卡、主按钮 |
| 烫金 `#dcbc6c` | 标题字、封皮细纹 | 顶栏页名、名牌上的地名、「下一步」的 NEXT 标签；深色模式的主按钮 |
| 冷白卡纸 `#f3f7f5` | 入境卡、登机牌 | 所有卡片、标签栏、弹窗正文 |
| 墨蓝印刷字 `#18263f` | 卡面印刷字 | 正文 |
| 圆珠笔蓝 `#1d3fbf` | 玩家填的值、勾选 | 选中态、玩家自己的数值（现金）、当前标签、链接、焦点环 |
| 洋红入境章 `#b3155c` | 盖章 | **全界面唯一的强色**：「下一步」的按钮、事件弹窗的到达章、没去过的地点、标签上的数字角标 |
| 打孔虚线 + 两侧半圆缺口 | 栏与栏之间 | 「下一步」卡的票根线、弹窗插图和正文之间、标签栏上沿 |
| 中英双语小标签（衬线大写） | 姓名 NAME | 地点名牌下的英文地名、「下一步 NEXT」、弹窗到达章 |

字体：中文继续用系统黑体（PingFang SC 等）。开场的 Noto Serif SC 子集 `/earth/fonts/terra-serif.woff2` 只含数字、大写拉丁字母和十几个汉字，所以主界面只把它用在**英文大写小标签**上（英文一律 `text-transform: uppercase`，保证字形都在子集里）。中文标题不用这个字体，否则子集外的字会掉到别的字体，一个标题里混两种字。

强色只有一种：洋红章。绿色、琥珀、红色只表示状态（需求高/中/低、钱够不够），面积小，不做装饰。

## 2. 信息层级

一屏从上到下，按“我现在怎样 → 该做什么 → 还能做什么”排：

1. **顶栏**（我在哪、什么时候、我的钱）——一眼确认状态，不需要操作。
2. **状态**（健康 + 5 项需求）——最缺的一项标「最缺」，顶栏人物头上冒想法气泡。
3. **下一步**——全页唯一的洋红按钮，拇指区。只给一个建议。
4. **心愿、快捷动作**——次一级，卡纸底、细线框。
5. **提醒卡**（周结算钱不够、排队中的动作、昨天回顾、新手指南）——出现时才有，警告用红色淡底，不抢「下一步」的位置。
6. **地点卡及以下**（天象、这里的人、工作、能做的事、商店……）——参考信息，往下翻。

## 3. 顶栏 `#hud`

| 页 | 内容 | 视觉 |
| --- | --- | --- |
| 今天 | 当地场景插画；左上人物名牌（头像外圈升级环，点了去成长页）；右上现金、天气；左侧地点名牌（中文地名 + 英文地名 + 日期时段）；人物头上的想法气泡；下方一排身份、星级、火险、紫外线、心情、同步状态 | 地点名牌是一小块护照封皮：海军蓝底、烫金地名、衬线大写英文名。现金是卡纸胶囊，数字用圆珠笔蓝 |
| 其他四页 | 副标题 + 页名；现金、星级；心情、同步；六项迷你需求条 | 整条是护照封皮的海军蓝，页名烫金；随时段微调蓝色深浅（清晨偏亮、黄昏偏紫、夜里最深），保留原来“顶栏跟着时段变”的功能 |

离线、排队提示条挂在顶栏底部，琥珀淡底（不是错误，是提醒）。

## 4. 底部标签 `#tabs`

五个：今天 / 出行 / 成长 / 社交 / 我（第 15 批定稿，不改）。

- 外观是**登机牌存根**：卡纸底，上沿一条打孔虚线。
- 当前标签：图标和字变圆珠笔蓝，字下有一道 18px 的笔划线；`aria-current="page"` 照旧。
- 社交标签的在线人数角标用洋红章色。
- 每个按钮 ≥ 64px 高（`--nav-h`），底部留 `safe-area-inset-bottom`。

## 5. 各标签页

| 标签 | 内容（不变） | 本轮改的表现 |
| --- | --- | --- |
| 今天 | 第 2 节的顺序 | 「下一步」做成登机牌：海军蓝底、烫金 NEXT、打孔票根线、洋红按钮；上班中的计时卡用最深的蓝 |
| 出行 | 顶部分段「路线 / 附近」；地图（真实底图或手绘）；目的地卡（走法方块 + 路费后余额 + 出发）；全部路线列表 | 地图圆角收小、加细线框；没去过的地点用洋红；目的地卡选中的走法用圆珠笔蓝勾选；「出发」是海军蓝主按钮 |
| 成长 | 等级、每日奖励、收集、成就 | 跟随卡片和进度条的新样式 |
| 社交 | 在线玩家、聊天、留言、合作、交易 | 同上；聊天里的名字用圆珠笔蓝 |
| 我 | 概况 / 资产 / 关系 / 日志 / 更新 / 设置 | 子栏分段控件改成卡纸底 + 选中白卡；同步码框是虚线框 |

## 6. 弹窗 `#modal`

事件弹窗是这个世界的**招牌时刻**：每次到达一个地点，相当于在护照上盖一个章。

- 插图（或当地场景）在上，标题在插图底部。
- 原来插图上方的小字「到达 某地 · 14:20」改成**右上角的洋红入境章**：圆角矩形双线框、略微倾斜，打开时带一次落下的 ease-out（`html.calm` 或系统“减少动态效果”时不动）。结果页的章写「结果」。
- 插图和正文之间是一道打孔线，两侧半圆缺口。
- 第一个能选的选项用圆珠笔蓝框 + 淡蓝底（原规则：第一项钱不够时顺延）。
- 焦点管理、`inert`、Esc 关结果页都不变。

## 7. 状态

| 状态 | 现在的处理 | 表现 |
| --- | --- | --- |
| 空 | 留言板“还没有人在这里留言”；附近页没有收录场所；没有其他玩家在线；心愿全部完成 | 灰字一句说明，不放插画占位 |
| 加载 | 附近页“正在载入”；真实底图加载完之前显示手绘地图；动作提交时 `body.busy` 把面板和弹窗压暗、禁点 | 不加转圈；手绘地图本身就是占位 |
| 错误 | 真实地点下载失败给“重试”；真实底图失败回到手绘地图并在设置里说明；动作被服务器拒绝用 toast 说原因 | 错误卡用红色淡底 + 1px 红框，标题写问题，正文写怎么办 |
| 离线 | 顶栏下挂离线条：“可以查看；做事、出行可以先排队，联网后自动补交（已排 N 个）”；同步点变琥珀 | 琥珀淡底；排队卡里能逐个取消 |

## 8. 手机单手操作

- 主操作在下半屏：「下一步」排在状态卡后、通常落在屏幕中下部；标签栏贴底；出行的「出发」按钮在目的地卡最下面。
- 所有可点元素 ≥ 44×44px（顶栏心情胶囊外层按钮 44px 高，胶囊画在里面）。
- 弹窗从底部弹起（底部抽屉），选项在拇指区；最多占 92% 屏高，可滚动。
- toast 浮在标签栏上方 16px，不挡标签。
- 字号设置（标准 / 大 / 特大）和“减少动画”只在本机生效，继续有效。

## 9. 深色模式

跟随系统。深色不是把浅色反过来，而是**合上的护照**：页面底是封皮深蓝 `#0b1630`，卡片是略亮的海军蓝，正文是雾白；圆珠笔蓝提亮到 `#9db1ff`，入境章提亮到 `#ef6aa3`，主按钮换成烫金底 + 深蓝字。所有组合按 WCAG AA 配对（正文 ≥ 4.5:1）。

## 10. 刻意没做的

- **emoji 图标**：活动、地点、需求的图标仍是 emoji（数据里定义的内容），本轮不替换；标签栏是自绘 SVG 线性图标，保持。
- **需求环**：保留六个环（测试和第 15 批定稿依赖它），只换成卡纸世界的配色；环轨道用细刻度，像表盘。
- **页面结构**：所有 `render*` 函数的输出结构只做了三处小改（地点名牌加英文名、「下一步」标签加 NEXT、弹窗小字改成入境章），其余全是样式。

## 11. 没验证的

用户约定不用浏览器和截图，所以 impeccable 要求的“看渲染结果”的评审没做。只跑了 `impeccable detect`（静态规则）、`npm test`、`tsc`、`npm run check`。真机上的观感、深色模式实际对比度、地图上的配色，需要在手机上看一眼。
