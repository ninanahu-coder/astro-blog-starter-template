# 体验改造 P2：图标和音效

接 P1（`ux-p1.md`）。用户 2026-11-21 定的两条：**音效默认开、最轻一档**；**内容图用 Fluent Emoji 扁平版**。

## 1. 两种图标，各管一摊

| 用在哪 | 用什么 | 许可 | 怎么来的 |
| --- | --- | --- | --- |
| 界面图标：「在这里」各组、真实定位、箭头、抽屉标题、主线勾选 | [Lucide](https://github.com/lucide-icons/lucide) 线条图标，和底部标签同一画法 | ISC，界面里不用署名 | `tools/earth/icons/build-lucide.mjs` 把用到的 15 个图标做成雪碧图 `src/game/ui/lucide-sprite.ts`，页面在**构建时**写进 HTML（不进首屏脚本），用 `lu('名字')` 引用 |
| 内容图：物品、食物、动物、需求、天气、头像…… | [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 扁平版 | MIT，许可放在 `public/earth/emoji/LICENSE.txt` | `tools/earth/icons/build-emoji.mjs` 扫描源码里用到的 emoji（目前 242 个），拷对应 SVG 到 `public/earth/emoji/<编码>.svg`，生成 `src/game/data/emoji-set.ts` |

- **换图的方式**：页面每次写完顶栏、面板、弹窗、提示条，把文字节点里的 emoji 换成 `<img class="emo" alt="原 emoji">`。
  - 读屏照样念出 emoji 的名字，复制文字时也还是 emoji。
  - 数据和文案里照旧直接写 emoji。新加了 emoji 的话，要重跑生成脚本，测试会提醒。
- **不换的地方**：SVG 里的文字（地图、印章）、输入框、属性（`aria-label`、`title`）、开场入境卡（不在游戏界面里）。
- **首屏**：查找表约 5KB，按需加载。刚打开页面的一瞬间先显示系统 emoji，表下好后再补换已经画好的部分。首屏 JS gzip 只多了约 1.3KB，主要是 ZzFX。
- **图的大小**：242 张，平均约 2.8KB，最大的是头像「卷发的人」约 34KB。用到哪张下哪张，浏览器会缓存。
- **安全**：生成脚本和测试都检查 SVG 里没有脚本、事件属性、外链。这些图是用 `<img>` 放的，本来也不会执行。

## 2. 音效

- `src/game/ui/zzfx.ts`：移植 [ZzFX](https://github.com/KilledByAPixel/ZzFX)（MIT，附许可）的采样生成，改成纯函数。
- 每个提示音由一到四个 ZzFX 声部叠成，第一次用到时算好采样并缓存，之后直接放。
- 新增「进账」的投币声，排在升级、到达之后，「做成」之前。
- 默认开、总音量「轻」。浏览器要求先点一下才能出声，所以第一次点击后才开始响。环境音和背景音乐仍然默认关。
- 只用正弦波和三角波；噪声只用在盖章和雷声这两种本来就是闷响的地方。整段都不超过半秒。
- **没有人用耳朵试听过**。数值集中在 `sound.ts` 的 `CUES`，真机听过再调。

## 5. 多角度复核（2026-11-21）

从四个角度各派一名审查员只读审查：emoji 换图、音效、构建脚本与安全、测试质量。每条问题再单独找人反驳一遍，结果 10 条成立、4 条被驳回。成立的都已修：

- **事件和结果页标题里的 emoji 被拉满**（高）：事件主视觉的 `#modal .ev-hero img` 规则比小图的规则更具体，标题里的小图被铺满整个标题、压暗。小图规则改成 `#app img.emo, #modal img.emo, #toast img.emo`，并清掉定位和透明度。
- **风暴声其实是高通**：ZzFX 里滤波为正是高通、为负是低通。改成 -200（22.05 kHz 下约等于 400 Hz 截止）。
- **没做成、盖章的滑音滑过 0 Hz**，听起来先降到底再往上走：放慢滑音；盖章起点提到 160 Hz，手机喇叭也放得出来。
- **还没点页面就出声**：开场就有待处理事件时，会在没有用户手势的情况下建 AudioContext，浏览器把它挂起，攒下的声音等第一次点击时一起放。现在玩家点过或按过键之前，提示音直接不放。
- **Lucide 雪碧图的校验是黑名单**，挡不住 `<img/src/onerror>` 这类写法，而雪碧图是用 `set:html` 写进页面的。改成白名单：只许几种图形元素和几何属性。
- **许可**：
  - 雪碧图前面带上完整的 ISC 许可。
  - ZzFX 源码头部改成 `/*! */`，压缩时保留。
  - 新增 `public/earth/LICENSES.txt` 汇总三份许可。
- **测试**：
  - 补了滑音不过 0、风暴是低通、声部叠加、页面传「进账」、点击前不出声的测试。
  - 「页面不传进账」「声部不叠加」两条变异原来抓不到，现在能抓到。

被驳回的 4 条：

- 带命名空间前缀的 `<s:script>`：图是用 `<img>` 放的，不会执行。
- 老玩家已经存过设置的，音效保持他们原来的值：这是有意的，尊重已经保存的选择。
- `emojify` 没有行为测试：有单元测试、页面接线测试，加上实测（文字 emoji 为 0、坏图为 0）。
- 文档里「复制文字时还是 emoji」：`<img alt>` 在浏览器里复制出来就是 alt，属实。
