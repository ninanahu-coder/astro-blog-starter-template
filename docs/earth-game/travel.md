## 1. 现状：出行和跨区

**【现状】**

- 出行只有一个动作 `travel`：沿 `Region.routes` 走一段。`travelOptions()` 列出从当前地点出发的路线，`priceRoute()` 按方式算价钱和时间：
  - 航班 `air`：60 分钟 + 距离 ÷ 750 km/h；票价 $120 + 每公里 $0.25；
  - 渡轮 `ferry`：45 分钟、$40；
  - 公路 / 土路：直线 × 1.25；有车按车速和每公里成本，没车坐长途巴士（$8 + 每公里 $0.12）。
- 路上 `advance()` 一分钟一分钟扣需求，饿到、累到见底会晕倒；跨过结算日跑 `weeklyTick()`（房租、房产、车险）。
- 世界由西澳、南澳两个区域拼成（`areas-base.ts`）。`CROSS_ROUTES` 两条跨区路线：珀斯—阿德莱德航班、卡尔古利—锡杜纳公路。到了以后存档 `region` 跟着变，地图和在线频道换区域（第 43 轮）。
- 没有「离开地图」的概念：去不了墨尔本、悉尼，也回不了国。

**【现状里的问题，提议交给 Codex 评估】** 珀斯—阿德莱德的航班按公式是 **$653、3 小时 50 分**（交通分支文档 §3 也算出同样的数）。真实单程票价大约 **$119 起**（Skyscanner 2026-11 显示的最低单程），直飞约 **2 小时 50 分**（Skyscanner、Trip.com 一致）。公式价是真实促销价的五倍多。本批**没改** `priceRoute()`：交通分支（`claude/earth-transport`）和房产车辆分支（`claude/earth-home-vehicle`）都在改出行价格附近的代码，改它会冲突，而且是数值调整，应先由 Codex 评估。见 §12。

## 4. 机票的季节

**【本批】** 票价 = 下限 + (上限 − 下限) × 需求度，再乘特质的费用倍率（精打细算 × 0.85）。需求度 0–1 按出发那天落在哪个「票价季节」里定，几段重叠取最大，都不在为 0（下限）。

游戏日历一年四季、每季 28 天，季节名和南半球一致（夏 = 12–2 月），所以把真实的旺季大致按比例放进季内日子：

| 票价季节 | 游戏日子 | 跨州需求度 | 回国需求度 | 依据（需求度本身都待平衡） |
| --- | --- | --- | --- | --- |
| 圣诞和暑假 | 夏季第 1–18 天 | 1 | 0.8 | BITRE 12 月指数比 1 月高约 22%；南航 12-01 至 03-10 加到每天一班 |
| 春节 | 夏季第 16–25 天 | 0.3 | 1 | 春节在 1 月下旬到 2 月中旬，落在南航加班期里 |
| 年中假期 | 冬季第 1–8 天 | 0.6 | 0.6 | 西澳学校 7 月初放假；大学年中放假 |
| 国庆和春季假期 | 春季第 9–15 天 | 0.4 | 0.6 | 西澳学校 9 月底到 10 月初放假；国内 10 月 1–7 日放假 |

- 春节每年日期不同，游戏里固定在夏季第 16–25 天。
- 出行页在旺季提示「现在是某某，机票偏贵」。
- **【提议】** 地图上珀斯—阿德莱德那条航班也按季节浮动。要改 `priceRoute()`，等交通分支合并后再做（见 §12）。

## 5. 离开期间怎么结算

**【本批】** 只能从有对应航线的机场出发（珀斯、阿德莱德），回来也回到同一个机场。`takeTrip()` 一个动作做完：

| 项目 | 规则 | 数值 |
| --- | --- | --- |
| 时间 | 时钟往前走 天数 × 1440 分钟，整天，不按航班时刻 | 天数只能选目的地列出的：跨州 3 / 5 / 7，回国 7 / 14 / 21（待平衡） |
| 需求 | 离开期间不扣需求、不会晕倒（吃住在外面另有着落）；回来时按旅行类型**重置**到固定值 | 跨州：饱食 70、精力 55、清洁 70、娱乐 90、社交 70；回国：90 / 50 / 80 / 80 / 95（待平衡） |
| 房租、车险、房产 | 跨过几个结算日就结算几次，和平时一样（`awayTime()` 调用原来的 `weeklyTick()`）；付不起照样被收房、记麻烦值、断供 | 出发前的预估会算出「经过 N 次周结算，约 $X」，现金可能不够时标红 |
| 工作 | 天数 ≤ 请假上限保留工作；超过就被辞退，日志写明 | 上限 9 天（待平衡）。依据：《公平工作法》全职每年 4 周年假折算；第十轮定口径为「可保留工作的请假（不带薪）」，游戏一年 112 天，4/52 × 112 ≈ 9。临时工其实没有带薪假，本批不区分 |
| 上班卡 | 打着上班卡时不能走 | 先打下班卡 |
| 待处理事件 | 有事件时不能走 | |
| 心情 | 跨州回来「旅行回来」+8、48 小时；回国回来「见到了家人」+12、96 小时；时差 ≥ 2 小时加「倒时差」−4、24 小时 | 都待平衡 |
| 纪念品 | 回来时放进背包，超过携带上限的不加 | 见 §7 |
| 能力、声望 | 不变 | |
| 车 | 停在原地，不加里程 | |
| 心愿、昨天回顾 | 走 `applyAction` 的统一收尾：跨日换心愿，「昨天回顾」记下离开的几天 | |

**回来时的事件**（`RETURN_EVENTS`，按顺序看，第一个满足条件、掷骰过了的触发；几率待平衡）：

| 事件 | 什么时候 | 几率 | 选项 |
| --- | --- | --- | --- |
| 🛃 入境申报 | 回国回来 | 70% | 如实申报：多排 30 分钟，没收一份家乡零食；不申报：街头检定 DC 70，过了麻烦值 +5，没过没收两份、麻烦值 +15、扣 $200 |
| 📬 塞满的信箱 | 租着或住着房子 | 50% | 坐下来处理（花 1 小时）；先睡觉（多付 $30 滞纳金） |
| 🌙 凌晨三点醒了 | 任何旅行 | 40% | 起来整理照片；硬睡（体能检定 DC 40） |

- 入境申报的 $200 是游戏里的处罚，**不是真实罚款金额**；文案里也不写真实金额（没查到对应条目的出处）。真实情况是入境卡上要申报食品，申报了的东西检疫后放行或没收，不罚款——这一点和游戏选项一致。
- 3 张插图暂借已有图（海关借「路边盘查」，信箱借「旅舍厨房」，凌晨借「夜里的灯」），`tools/earth/comfyui/prompts.mjs` 已写好专用提示词，等重新出图。

## 8. 州内自驾游规划

**【本批】** `planRoadTrip(state, world, days, interstate = false)`：从当前地点开始一站站挑下一站——先挑没去过的，再挑开车时间短的——直到总开车时间超过 天数 × 6 小时（`ROAD_TRIP_DRIVE_MIN_PER_DAY`，待平衡）。只走公路、土路（车能走才算）和渡轮，不坐飞机；不出本州，`interstate` 为 true 时可以走跨区公路（卡尔古利—锡杜纳）。价钱和时间全部来自现有的 `travelOptions()`，没有新公式。

- 只是建议：不改存档，玩家还是一段段点「出发」。出行页显示「三天自驾游建议」：路线、总公里数、开车小时、路费，和一个看第一站的按钮。住宿、吃饭没算进去，页面上写明。
- 用 `travelOptions()` 的好处：交通分支以后加的公交、火车、步行会自动进规划；天气路况分支改了价格也会自动反映。
- **【提议】** 让玩家选天数（1 / 3 / 5）和「可以跨州」开关；画在地图上（等 `gps-route` 分支的路线图层）；规划里加住宿（按沿途有没有房车营地、旅舍）。

## 14. 模拟结果

`npm run earth:sim -- --days=180 --runs=100`，main（`4f9c9e5`）和本分支各跑一次，见下。

**结果：两份报告逐字相同（77 行，`diff` 无差异），本批没有改变任何模拟数字。**

原因（解释，不是平衡结论）：模拟机器人不会做 `trip` 动作，只在西澳地图内走 `travel`；回来的 3 个事件 weight 为 0，不进抵达事件的抽取池，所以不消耗随机数、不改变别的事件；纪念品商店不卖，不进机器人的购物选择；`awayTime()` 只有 `trip` 调用。所以 `balance-report.md` 没有重新生成。旅行对经济的影响（每次几百到一千多澳元的支出、离开期间房租照扣、丢工作）要等模拟机器人学会「攒够钱就回国一次」这类行为后才看得出来，留给 Codex。
