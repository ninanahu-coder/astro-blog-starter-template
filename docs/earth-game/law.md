- **【现状】**：main（`4f9c9e5`）里已经有的；

## 1. 内容原则

- 只写**后果和代价**：罚款、扣分、停驾、法庭、社区服务、麻烦值。不写作案方法，不写暴力细节（原 `heat-check` 被抓时的「被按住」「健康 −10」已删）。
- **违法的选项不给净收益**。冒险没被查到，结果也只是「没事」：不给钱、能力、声望，不降麻烦值（测试「违法的选项不给好处」逐条检查所有带 `risk` 的选项）。
- 「查不查得到」用 `risk`（固定几率），**不用能力检定**，免得「街头」「体能」高的人变成「更会违法」。
- 签证只做简化提示，并写明不是法律意见。

## 2. 麻烦值和通缉星级

### 2.1 【现状】

| 项 | 规则 |
| --- | --- |
| 字段 | `heat` 0–100 |
| 星级 | `wantedStars = min(5, floor(heat / 20))`（`attributes.ts`） |
| 盘查 | `heat ≥ 60`（3 星）到达任何地点必出 `heat-check`，优先于签名事件和抛锚 |
| 上涨 | 事件效果 `fx.heat > 0` × 特质系数：`lawful` 0.5、`daredevil` 1.5；没钱续车险每周 +8 |
| 来源 | `rbt` 搪塞失败 +20、`pearl-offer` +15/+10、喂野生动物 +10、凑近海龟 +3、矿权地 +10 等 |
| 下降 | 活动「低调几天」−40；`rbt` 配合 −10；`heat-check` 配合 −50；不会随时间自然下降 |

### 2.2 【本批】

- **自然冷却** 0.25/小时（`HEAT_RULES.coolPerHour`，待平衡），在 `advance()` 里随时间流逝结算，不乘特质系数。
  分支 `claude/earth-activity-attrs` 的 `vitals.ts` 也加了同样的 `heatCoolPerHour: 0.25`；**合并时只留一处**（见 §9）。
  从 60 冷却到 59 要 4 小时，从 60 降到 40 要 80 小时（3 天多），「低调几天」仍是主要降法。
- **违章上涨**：每条违章有自己的 `heat`（0–30），走 `addHeat()`，乘特质系数（守规矩减半、胆大包天 1.5 倍）。
- 星级和盘查阈值不变。

### 2.3 【提议】

- 星级分档效果：1–2 星只是「被注意」（路检几率上升），3 星盘查，4–5 星直接收到法庭传票。现在 4、5 星和 3 星效果一样。
- 守规矩特质也加快冷却（例如 ×1.5），目前冷却对所有人一样。

## 3. 交通罚单

### 3.1 【现状】

- 只有 `rbt`（路边临检）：「配合检查」麻烦值 −10；「找借口搪塞」街头检定 DC 55，过了没事还涨街头 +2，没过罚 $250、麻烦值 +20。
- 问题：
  1. `rbt` 只看 `arrivedBy: ['road']`，**坐长途大巴的人也会被拦下做呼气测试**；
  2. 结果和喝没喝酒无关；
  3. 「搪塞」靠街头能力躲过罚单还涨能力，等于奖励糊弄警察。

### 3.2 【本批】

- 新事件字段 `driving: true`：只有自己开车（有车、驾照没暂停、走公路）抵达时才进抽取池。`rbt`、`speed-late`、`parking-limit` 都标了。
- **`rbt` 路边临检**（权重 3 不变）：
  - 配合吹气：5 分钟、麻烦值 −10（沿用），然后做呼气测试 `breathTest`：4 小时内在酒吧（`pub`）或酒庄（`wine`）喝过酒就按酒驾处理，否则「读数为零」。
  - 拒绝吹气：拒绝测试本身违法，走法庭（§5）。
- **`speed-late` 赶时间**（新，权重 2）：按限速开晚到 10 分钟；踩油门 `risk 0.5`，没被拍到也只是「心还怦怦跳」（娱乐 −3），被拍到按超速 10–19 km/h。
- **`parking-limit` 限时停车**（新，权重 2，只在城市、城镇）：回去挪车 15 分钟；再待一会儿 `risk 0.4`，被抄牌按停车超时。
- **喝酒窗口**：喝酒的活动结束时记 `law.drank`，之后 4 小时（`DRINK.windowMin`，待平衡）内遇到呼气测试会超标。游戏不算杯数、体重，统一按最低档（0.05 以上、0.08 以下）。
- 出行卡：刚喝过酒、选了自己开车时提醒一句「现在自己开车遇到路边呼气测试会超标」；不拦着，让玩家自己选。
- 抽到法律后果时，事件结果文字后面接一句处罚说明（例如「路边的测速相机闪了一下。超速 10–19 km/h：罚款 $200，扣 2 分。」），同样写进日志。

### 3.3 【提议】

- 超速分档跟路况、车型挂钩（现在只有 10–19 km/h 一档会出现，1–9 和 20–29 两档只在数据表里）。
- 停车：真实地点（`venues`）开车去时也可能超时；停车罚款金额核对后换成真实值。
- WA 公众假期双倍扣分（官网写明所有超速违章都适用）。SA 不用双倍扣分。
- 新手 P 牌（WA 4 / 8 分，SA 4 分）和零酒精限制。现在游戏只有全驾照。
- 指定司机：和 NPC 一起喝酒时让对方开车（社交玩法）。
- 呼气测试按喝了多少分档（0.05–0.08 罚单、0.08 以上法庭和立即停驾）。

### 4.2 扣分上限【本批】

- 两州全驾照都是 **3 年内 12 分**停驾，分数从违章日期算起 3 年后过期。
- 停驾长度：WA 写在「Excessive Demerit Points Notice」里，官网没给固定值；SA 页面也没给 12 分的停驾长度。游戏统一 **90 天**（待平衡）。
- 扣满停驾后，3 年内的分数清零（视为「用掉」），避免一停再停。
- 停驾期间：`priceRoute` 把车当作没有，公路只能坐长途大巴，土路走不了；不记里程、不涨驾驶；交通事件抽不到。
- WA 的「Good Behaviour Period」（12 个月内再扣 2 分以上停双倍时间，代替停驾）没做，写进提议。

## 5. 法庭、社区服务和欠款

### 5.1 【现状】

- 没有法庭，没有社区服务。`heat-check`「想办法溜走」体能检定 DC 60：过了麻烦值 −15、涨体能 +2 街头 +2；没过罚 $500、健康 −10、麻烦值 −30。

### 5.2 【本批】

- **走法庭的违章**（`court: true`）：酒驾再犯、拒绝呼气测试、拒不配合警察。结果是罚款、可能停驾、可能判社区服务，并且**定罪记录 +1**（`law.record`）。普通罚单不算定罪。
- `heat-check` 改写：
  - 老实配合：不变（30 分钟、$200、麻烦值 −50）。
  - 想办法溜走：`risk 0.7`。没被拦下：麻烦值 **+10**（「他们记下了你的样子」），下次到达照样被盘查；被拦下：2 小时、麻烦值 −30、按「拒不配合警察」走法庭。不再涨能力，不再掉健康。
- **社区服务**：新活动「社区服务」（城市、城镇，8–16 点，每次 4 小时，精力 −15、娱乐 −5），只有欠着小时时能做，不给钱、不涨能力。判决后 28 天内做完；逾期周结算麻烦值 +15、期限顺延 28 天（待平衡）。
- **欠款**：罚款当场从现金扣，不够的记 `law.owed`；周结算先补交，还欠着麻烦值 +5（待平衡）。

### 5.3 【提议】

- 法庭日期：不当场判，而是给一个「第 N 天去某城的法院」的约定，缺席加重。
- 法律援助 / 律师咨询（Legal Aid WA、Legal Services Commission SA 都有免费咨询），作为可选的花时间动作。
- WA 的罚款执行（Fines Enforcement Registry）：欠款太久暂停驾照。现在只涨麻烦值。
- `pearl-offer`（「便宜珍珠」买来转手，净赚 $400 并涨街头 +3）目前没动，因为是否违法要看情节；建议加一个「提醒他这样会被查」的选项，或把「转手」改成有 `risk` 的收赃后果。改了会动模拟，留给平衡会话。

## 6. 对签证的影响（简化提示）

- 【本批】出身是「留学生」或「背包客」（持学生签证、打工度假签证的设定）且有定罪记录时，法庭判决的那句话后面、档案卡里都显示：
  > 法庭定罪通常要在签证申请里如实申报，可能影响品格审查。这里只是简化提示，不是法律意见；现实中请咨询注册移民代理。
- 普通交通罚单（交了罚款的）不算定罪，不显示提示。
- 【提议】和分支 `claude/earth-education-career` 的签证工时（`core/visa.ts`）放在同一个「签证」卡里显示。不做「签证被取消」之类的游戏结局。

## 7. 存档字段【本批】

新字段 `law`（遵守 `save-sync.md` §5.1）：

```ts
law: {
  hist: { t: number; id: string; n: number }[]; // 违章记录（游戏时钟、违章 id、扣分），最多 30 条
  ban: number;    // 驾照暂停到这个游戏时钟，0 = 没有
  owed: number;   // 欠的罚款
  cs: number;     // 欠的社区服务小时
  csDue: number;  // 社区服务期限（游戏日），没有为 −1
  record: number; // 法庭定罪次数
  drank: number;  // 最近一次喝酒的游戏时钟，−1 = 没有或已过窗口
}
```

- `createCharacter` 给空记录；`sanitizeState` 只加一行 `law: cleanLaw(r.law, clock)`。
- `cleanLaw`：旧存档缺字段给空记录；只认自有属性（原型链上的键不算）；违章时间不能晚于存档时钟、id 必须在 `OFFENCES` 里；停驾最长到「现在 + 最长停驾」；欠社区服务一定有期限；未来或过期的喝酒时间清掉；幂等。序列化后远小于 4 KB。
- 没改 `SAVE_VERSION`，没改已有字段的形状。
