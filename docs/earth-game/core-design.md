# 地球人生 —— 底层代码设计：人物属性与基本元素

本文说明游戏最底层的数据模型和数值规则。代码在 `src/game/core/` 与 `src/game/data/`，测试在 `tests/earth/`。

## 1. 分层

```
data/      纯数据：地点、路线、互动、事件、特质、物品（策划改这里）
  ↓ 只被读取
core/types.ts       所有结构的类型定义
core/attributes.ts  派生属性：心情、检定分、星级、等级、特质/物品修正系数
core/character.ts   创建角色、存档校验 sanitizeState()
core/engine.ts      动作：出行 / 互动 / 事件 / 打卡 / 买 / 用
  ↓ 返回新的 PlayerState
pages/earth.astro   只渲染和接收输入；server/world.ts 只校验和存储
```

三条硬规则：

1. **引擎是纯函数**：动作函数接收旧状态、返回新状态，不改入参，不读时钟，随机数只来自 `state.seed`。同一份代码在手机、测试和（第二阶段的）服务端上结果一致。
2. **只存原始值，派生值现算**：心情、星级、等级、检定分都不进存档，避免存档里出现互相矛盾的字段。
3. **内容即数据**：所有数值变化都用同一个 `Effect` 结构描述；特质只是一组修正系数。加内容不需要改引擎。

## 2. 人物属性（`PlayerState`）

### 2.1 原始属性（存档里的字段）

| 分组 | 字段 | 范围 | 说明 |
| --- | --- | --- | --- |
| 身份 | `id` `name` `avatar` `origin` `traits` | — | 出身决定开局；特质创建时选 2 个，之后不可改 |
| 生活需求 | `needs.hunger/energy/hygiene/fun/social` | 0–100 | 随游戏时间下降；饱食或精力为 0 时持续掉健康 |
| 能力 | `skills.stamina/strength/driving/swimming/charisma/survival/street` | 0–100 | 靠行为成长，边际递减：增长 = 原值 × 特质倍率 × 0.35 × (1 − 当前值/110) |
| 收藏 | `collected` `courseDays` | — | 已完成的体验；每门课最近一次上课的游戏日 |
| 状态 | `cash` `health` `respect` `heat` `vehicle` | 见下 | 现金 ≥0；健康 0–100；声望 ≥0；麻烦值 0–100 |
| 物品 | `inventory` | 每种 1..上限 | `itemId → 数量` |
| 职业 | `job` | — | `{ career, loc, level, shifts, good, lastDay }`：雇主、工作地点、等级、本级已上班次与表现好的班次、最近上班日 |
| 住房 | `home` | — | `{ type, loc, furniture }`：房型、所在地点、各槽位的家具 |
| 周结算 | `nextWeek` | — | 下一次周结算的游戏日 |
| 心愿 | `wishes` `wishDay` | — | 今天还没完成的心愿 id；这批心愿生成于哪个游戏日 |
| 每日奖励 | `daily` | — | `{ day, streak }`：最近领取的现实日序号（珀斯时间）、连续天数 |
| 房产 | `properties` | — | `{ id, loan, rented, missed }[]`：剩余贷款、是否出租、连续欠款周数。住在自有房里时 `home.owned` 指向它 |
| 关系 | `relations` | 分数 −100..100 | `npcId → { score, last, bonded }`：分数、每种互动最近一次的游戏日、是否已领好友回报 |
| 世界进度 | `loc` `clock` `visited` `checkins` `seen` `pending` | — | 位置、游戏分钟、到访次数、打卡、一次性事件、待处理事件 |
| 系统 | `seed` `rev` `journal` | — | 随机数状态、云同步版本号、最近 40 条日志 |

### 2.2 派生属性（`attributes.ts`，现算）

| 属性 | 公式 | 作用 |
| --- | --- | --- |
| 心情 | `平均需求 × 0.6 + 最低需求 × 0.4 + 特质加值`，钳制 0–100 | 短板效应：任何一项见底都会拖垮心情 |
| 心情档 | <25 低落（检定 −10）· <50 一般（0）· <85 愉快（+5）· ≥85 亢奋（+10） | 影响所有检定 |
| 检定分 | `能力值 + 特质加值 + 最高一件装备加值 + 心情加值` | 事件选项判定：`检定分 + 随机 0–60 ≥ 难度` |
| 通缉星级 | `floor(麻烦值 / 20)`，0–5 星 | ≥3 星（麻烦值 ≥60）到达新地点必被盘查 |
| 等级 | 声望阈值 0/10/25/50/90/150/240/360/520/720 | 1–10 级，对应称号“新来的”到“西澳之子” |

### 2.3 特质修正系数（`TraitMods`）

| 字段 | 类型 | 作用点 |
| --- | --- | --- |
| `gain` | 乘数 | 能力**增长**时（扣减不受影响） |
| `decay` | 乘数 | 需求随时间下降的速度 |
| `check` | 加值 | 检定分 |
| `cost` | 乘数 | 出行费用、商店价格 |
| `heat` | 乘数 | 麻烦值**上涨**时 |
| `hurt` | 乘数 | 健康**扣减**时 |
| `mood` | 加值 | 心情 |

两个特质的乘数相乘、加值相加。互斥关系写在 `conflicts`，必须双向（测试会检查）。现有 10 个特质见 `data/traits.ts`。

## 3. 基本元素

| 元素 | 定义位置 | 关键字段 | 一句话 |
| --- | --- | --- | --- |
| 区域 `Region` | `data/wa.ts` | 边界、海岸线、地点、路线、出生点、医院 | 一张地图；加新区域 = 加一个数据文件 |
| 地点 `GameLocation` | 同上 | 坐标、`kind`、`tags`、打卡半径 | `kind`/`tags` 决定能做什么、能买什么、会遇到什么 |
| 路线 `Route` | 同上 | 两端、方式（公路/土路/渡轮/航班） | 费用与耗时按真实距离算 |
| 打卡点 `Poi` | `data/wa.pois.json` | 坐标、类别、来源 | 本人到现场 400 米内可打卡 |
| 互动 `Activity` | `data/activities.ts` | 适用地点、耗时、效果、前置条件 | 吃、睡、打工、冲浪、买车…… |
| 事件 `GameEvent` | `data/events.ts` | 触发范围、权重、一次性、选项 | 到达地点时触发 |
| 选项 `EventChoice` | 同上 | 检定（能力 + 难度）、成功/失败结果 | 失败分支可省略 |
| 效果 `Effect` | `core/types.ts` | 现金、健康、声望、麻烦值、时间、需求、能力、座驾、物品 | 所有数值变化的唯一载体 |
| 特质 `TraitDef` | `data/traits.ts` | 修正系数、互斥 | 角色的长期性格 |
| NPC `NpcDef` | `data/npcs.ts` | 所在地点、作息时间、喜欢的物品、好友回报 | 只在自己的地点和作息时间内出现 |
| 时段 | `core/time.ts` | 清晨 5–8 · 白天 8–17 · 傍晚 17–20 · 夜晚 20–5 | 互动可设营业时间 `hours`，支持跨午夜 |
| 职业 `CareerDef` | `data/careers.ts` | 应聘地点、开工时段、班长、表现检定能力、各等级工资与要求 | 5 种职业，每种 3 级 |
| 住房 `HomeDef` | `data/housing.ts` | 周租、舒适度、可租地点 | 合租房间 / 一居室公寓 / 海景小屋 |
| 交通工具 `VehicleDef` | `data/vehicles.ts` | 价格、回收比例、公路 / 土路时速、油费、骑行消耗、车内睡眠 | 摩托车、二手轿车、四驱越野、露营车；在车行买卖，换车自动折抵 |
| 课程 `CourseDef` | `data/courses.ts` | 对应能力、基础学费、时长、成长量、开课地点与时间 | 7 门课；学费 = 基础价 × (1 + 当前能力/25)；每门每天一次 |
| 体验 `ExperienceDef` | `data/experiences.ts` | 地点、片区、价格、开放时间、效果、首次声望 | 15 个，分 5 个片区；首次进收藏册，集齐片区得称号 |
| 家具 `FurnitureDef` | `data/furniture.ts` | 槽位、价格、心情加成、睡眠加成、解锁的在家活动 | 5 个槽位各放一件；同槽位换新时旧的半价折现 |
| 房产 `PropertyDef` | `data/properties.ts` | 地点、自住房型、房价、物业费、出租周租金 | 4 套；每人每套只能买一次 |
| 节日 `FestivalDef` | `data/festivals.ts` | 地点、季节、开始日、持续天数 | 5 个；节日期间当地开放专属体验，到场加娱乐 |
| 心愿 `WishDef` | `data/wishes.ts` | 文字、出现条件、哪种动作算完成 | 15 条；每个游戏日随机 3 条 |
| 物品 `ItemDef` | `data/items.ts` | 价格、携带上限、售卖地点、`use` 或 `passive` | 消耗品用掉减一；装备持有即生效，同技能只取最高一件 |

### `Effect` 的结算顺序（`applyEffect`）

1. 现金、声望、麻烦值（上涨 × 特质 `heat`）、座驾
2. 能力（增长 × 特质 `gain`）、物品增减（钳制到携带上限）
3. 时间流逝（需求按衰减率 × 特质 `decay` 下降，可能晕倒）
4. 需求增减
5. 健康（扣减 × 特质 `hurt`），归零则在最近的医院醒来，付医药费 $100 + 现金的 10%（最多 $500）

先流逝时间再加需求，保证“睡 8 小时”之后精力是满的。

## 4. 动作接口（`engine.ts`）

| 函数 | 作用 | 会被拒绝的情况 |
| --- | --- | --- |
| `travel` | 沿路线前往相邻地点，抵达时可能触发事件 | 有待处理事件、无路线、缺四驱、钱不够 |
| `performActivity` | 在当前地点做一件事 | 有待处理事件、地点不符、前置条件不满足 |
| `resolveEvent` | 选择事件选项并结算 | 选项不存在 |
| `gpsCheckIn` | 用真实坐标抵达地点、领取打卡奖励 | 不在任何地点半径内、没有新东西可领 |
| `shopAt` / `buyItem` | 查看 / 购买当前地点商品 | 买不到、钱不够、已带满 |
| `useItem` | 使用消耗品 | 没有、是装备 |
| `careersAt` / `applyJob` / `workShift` / `quitJob` | 找工作 / 应聘 / 上班 / 辞职 | 条件不够、不在工作地点、不在开工时段、今天上过班、太累 |
| `homesAt` / `rentHome` / `sleepHome` / `leaveHome` | 看房 / 租房 / 回家睡觉 / 退租 | 钱不够首周租金、不在住处 |
| `dealerAt` / `buyVehicle` / `sellVehicle` / `sleepInVehicle` | 车行 / 买车（旧车折抵）/ 卖车 / 车里过夜 | 不在车行、车行没开门、钱不够、车不能睡人 |
| `coursesAt` / `takeCourse` | 课程 / 上课 | 不在开课时间、今天上过、钱不够、太累 |
| `experiencesAt` / `doExperience` | 体验 / 参加体验 | 不在开放时间、钱不够 |
| `furnitureAt` / `buyFurniture` / `sellFurniture` | 家具 / 添置 / 卖掉 | 没有住处、不在住处、钱不够 |
| `cookAtHome` / `relaxAtHome` | 在家做饭 / 放松 | 不在住处、缺对应家具 |
| `propertiesAt` / `buyProperty` / `sellProperty` | 在售房产 / 买房（全款或贷款）/ 卖房 | 人不在当地、钱不够、已拥有 |
| `moveIntoProperty` / `toggleRentOut` / `repayLoan` | 搬进自有房 / 出租或停租 / 提前还贷 | 没有这套房、没有贷款、金额无效 |
| `netWorth` | 净资产 | — |
| `npcsAt` / `interactNpc` | 查看在场 NPC / 聊天、送礼、帮忙 | TA 不在、今天做过了、没有 TA 喜欢的东西、太累 |

所有动作返回 `{ ok, state, msg }`。

客户端不直接调用这些函数。`core/actions.ts` 定义了动作协议：`parseAction()` 把网络输入校验成 `GameAction`，`applyAction()` 分发给上表的函数，由服务端（`server/world.ts`）执行并保存。

## 5. 人际关系

每个 NPC 可以做三种互动，每种每个游戏日一次：

| 互动 | 花费 | 关系 | 其他 |
| --- | --- | --- | --- |
| 聊天 | 30 分钟 | 魅力检定（检定分 + 随机 0–60 ≥ 45）成功 +7，否则 +3 | 社交 +18、娱乐 +5、魅力 +0.5 |
| 送礼 | 10 分钟 + 一件 TA 喜欢的物品 | +12 | 社交 +8 |
| 帮忙 | 2 小时、精力 18（精力低于 25 时不能帮） | +9 | 声望 +1、力量与体能 +0.5 |

关系档位：有过节 <0 · 陌生人 0 · 认识 10 · 朋友 30 · 好友 60 · 挚友 90。关系**第一次**达到好友时，发放该 NPC 的一次性回报（钱、能力或物品），之后不再发。

现有 9 个 NPC 分布在 9 个地点，其中黑德兰港的卡车司机戴夫只在夜里（20:00–6:00）出现。

## 6. 职业与住房

**职业**：5 种（咖啡店、海滩救生队、旅游公司、矿业公司、货运公司），每种 3 级。

- 在符合条件的地点应聘，只能有一份工作，跳槽会清零进度。
- 每天在工作地点、开工时段内上一个班，消耗时间和需求，按等级发工资。
- 每个班做一次表现检定（职业对应的能力，难度按等级 55 / 70 / 85），表现好多发 20% 奖金。
- 本级上满 8 个班、其中 5 个表现好、且满足下一级的能力和声望要求时自动升职，声望 +3。

**住房**：

| 房型 | 周租 | 心情 | 可租地点 |
| --- | --- | --- | --- |
| 合租房间 | $160 | +0 | 城市、港口、城镇、海岸、矿区 |
| 一居室公寓 | $320 | +5 | 城市、港口、城镇、海岸 |
| 海景小屋 | $650 | +10 | 有海滩的地点 |

- 每周结算一次（全局结算日，每 7 天）：扣房租和车辆保险保养。租房时先付到下一个结算日的房租（按天折算）。
- 结算时付不起房租，房子被收回，家具半价折现；付不起车辆保险不收车，麻烦值 +8。
- 家具：床、厨房、浴室、娱乐、装饰五个槽位。炊具解锁在家做饭（$6），音响解锁在家放松（免费）。搬走时家具半价折现。
- 回家睡觉免费，精力回满，清洁、娱乐、健康的恢复量随舒适度提高。
- 只能有一处住处，搬家时旧住处直接退掉，已付租金不退。
- 派生属性：住处心情 = 房型舒适度 + 家具舒适度；每周固定开销 = 房租 + 车辆保险。

## 7. 房产与贷款

公式集中在 `core/finance.ts`，常量在 `FINANCE`：

| 项目 | 规则 |
| --- | --- |
| 首付 | 房价的 10% |
| 每周还款 | 利息（剩余贷款 × 0.1%）+ 本金（房价 × 0.5%，约 180 周还清） |
| 卖房 | 到手 = 房价 × 95% − 剩余贷款 |
| 出租 | 每周收租金；5% 概率空置；1/12 概率维修，花费房价的 0.2%–0.6% |
| 欠款 | 当周付不起物业费 + 还款：记一次欠款，利息计入本金。连续欠款超过 2 周，按房价的 85% 强制卖出 |
| 收益上限 | 全款出租的期望年化净收益 ≤ 4%（`expectedYield()`，测试检查每套房） |
| 净资产 | 现金 + 车辆残值 + 家具折现 + Σ（房价 × 95% − 贷款） |

每周结算的顺序：房租（住自有房不交）→ 每套房依次结算租金、维修、物业费与还款、断供 → 车辆保险。

自住：`moveIntoProperty()` 把 `home` 设为 `{ type, loc, furniture, owned }`，之后和租的房子一样可以添家具、回家睡觉。出租和自住互斥。

## 8. 日历、心愿与每日奖励

**日历**（`core/time.ts`）：一年 4 季，每季 28 天，共 112 个游戏日；游戏第 1 天是第 1 年春季第 1 天。

- 事件可以写 `seasons`，只在这些季节出现（野花季只在春天，热浪只在夏天，冬季风暴只在冬天）。
- 节日每年固定日期举行。体验写了 `festival` 的只在节日期间开放，并计入「节日」收藏片区。
- `inSpan()` 判断某一天是否在节日期间，以及离下次开始还有几天。

**心愿**（`core/wishes.ts`）：

- 每个游戏日第一次成功行动后生成 3 条，随机数来自存档的种子；需要工作或住处的心愿只在有的时候出现。
- 判定在 `applyAction()` 里统一做：成功的动作如果满足某条心愿，娱乐 +12、声望 +0.5，并从列表里移除。
- 过了当天，没完成的直接换掉，没有惩罚。

**每日奖励**（`core/daily.ts`，由服务端按真实时间触发）：

- 以珀斯时间 0 点为界，每个现实日第一次读取存档或行动时发放。
- 金额：连续第 1 天 $30，每多一天 +$10，到 $90 封顶；每连续满 7 天当天另加 $150 和声望 +2。断一天从第 1 天重新算。
- 这是引擎里唯一用到真实时间的地方。真实日期由服务端算好传给纯函数 `claimDaily()`，引擎本身仍然不读时钟。

## 9. 存档兼容

存档格式版本仍是 `v: 1`。新增字段由 `sanitizeState()` 补默认值：旧存档里的 `home.paidUntil` 会迁移成 `nextWeek`。其余缺少的字段按空值读取：`traits` 空列表、`inventory` 空背包、`relations` 空关系、`job` 和 `home` 为空。未知 NPC 的关系丢弃。非法特质组合整体丢弃，背包里未知物品丢弃、数量钳制到上限。测试覆盖了这些情况。

## 10. 怎么加内容

- **新特质**：在 `data/traits.ts` 加一条，只用 `TraitMods` 里已有的字段。需要新类型的修正时，先在 `attributes.ts` 加一个乘数函数，再在引擎对应位置调用。
- **新物品**：在 `data/items.ts` 加一条，二选一：`use`（一个 `Effect`）或 `passive`（检定加值）。
- **新节日**：在 `data/festivals.ts` 加一条，并在 `data/experiences.ts` 加至少一个带 `festival` 的体验（测试会检查）。
- **新心愿**：在 `data/wishes.ts` 加一条，`done` 只能用已有的动作类型。
- **新房产**：在 `data/properties.ts` 加一条；租金和物业费要让 `expectedYield()` 落在 0–4%，否则测试不过。
- **新职业 / 新房型**：在 `data/careers.ts` / `data/housing.ts` 加一条。
