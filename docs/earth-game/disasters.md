# 自然灾害系统（第 43 批）

分支 `claude/earth-disasters`，从 main `4f9c9e5` 开；2026-11-22 合并 main `dd348d9`，更新日志改为 v73。合并时做的事见 §12，下面 §1、§9 里写「未合并」的分支现在都已在 main。每节标注：

- **【现状】**：main 上已经有的。
- **【本批】**：这次落地的第一版。
- **【提议】**：只写设计，还没做。

所有触发几率、持续天数、影响门槛都是游戏假设，统一标 **待平衡**。Claude 不下平衡结论，交 Codex 跑模拟分析。

## 0. 原则

1. **克制**：只写「发生了什么、该怎么做」，不写伤亡、不写损毁画面，不用惊吓式文案。事件插图、音效都不做。
2. **不冒充真实预警**：每一处都写明「游戏里的模拟，不是真实预警」，并链到真实发布机构（见 §2）。
3. **可复现、可预报**：和天气一样，只由「地点 + 游戏日」决定，所有玩家看到的一样，不用存档种子，也不进存档。往前、往后看的天数有上限，任何一天都能单独算出来。
4. **不困死玩家**：吃饭（`eat`）、慈善餐、野外找吃的（`forage`）从不因灾害关闭；山火只封「进来」的路，撤离方向一直通。

## 4. 五种灾害怎么来 【本批】

全部在 `core/disasters.ts`，参数在 `data/disasters.ts` `DISASTER_RULES`（待平衡）。

| 灾害 | 地区、季节 | 触发 | 级别 |
| --- | --- | --- | --- |
| 山火 | 公园、内陆、城镇、海岸、矿区（城市、港口、海岛和格莱内尔格不算） | 现有火险「极端」那天 35% 起火，「灾难性」那天 70% 起火（`unit('bushfire\|地点\|日')`） | 极端起火 → 注意并行动；灾难性起火 → 紧急警告；前一天起过火 → 提示 |
| 洪水封路 | 南纬 23° 以北，现实 12–3 月（雨季） | 看今天和前两天的风暴 | 今天风暴且 3 天里 ≥ 2 天风暴 → 紧急警告；今天风暴 → 注意并行动；前两天有风暴 → 提示 |
| 热带气旋 | 布鲁姆、黑德兰港、埃克斯茅斯、珊瑚湾，现实 11–4 月 | 风暴天 50% 算气旋过境 | 过境日 → 紧急警告；前一天 → 注意并行动；前两天、过后一天 → 提示 |
| 热浪 | 全部地点 | 连续「炎热」天数（最多往前看 5 天） | 3 天 → 提示；4 天，或内陆 3 天 → 注意并行动；内陆 5 天 → 紧急警告 |
| 停电 | 跟着别的灾害 | 气旋、山火紧急警告必停；气旋注意并行动 40%、热浪注意并行动以上 25%、非城市的风暴天 15% | 必停的是注意并行动，其余是提示 |

气旋要往后看两天的天气，因为天气本来就能预报（地点卡片已显示明天），所以玩家能提前一两天看到气旋要来。

**频率（合并 main `dd348d9` 后重算，天气已有惯性，35 个地点 × 1120 天）**：山火 2.72% 的地点日有预警（紧急 0.22%）；气旋 0.37%（过境 0.11%）；洪水 0.91%（紧急 0.19%）；热浪 2.77%（紧急 0.59%）；停电 1.61%。注意并行动以上最多的是库努纳拉（24.8% 的日子）、黑德兰港（19.3%）、卡瑞吉尼（17.8%）、布鲁姆（11.5%）。热浪明显变多，正是下面旧数字里预料的。这些都是统计结果，不是平衡结论，交 Codex。

**旧频率（合并前 main `4f9c9e5` 的天气，没有惯性）**：山火 1.8% 的地点日有预警（紧急 0.17%）；气旋 0.83%（过境 0.22%）；洪水 0.75%（紧急 0.03%）；热浪 0.13%，紧急警告一次都没出现（main 的天气没有连续性，连着 5 天炎热几乎不可能；天气分支合并后会变多，要重新统计）；停电 1.6%。注意并行动以上最多的是埃克斯茅斯（9.6% 的日子）、布鲁姆（9.2%）。这些都是统计结果，不是平衡结论。

## 5. 玩家应对 【本批】

| 应对 | 规则 | 代码 |
| --- | --- | --- |
| **封路** | 达到门槛时，进出该地点的线路在出行列表里照样列出，但标成走不了并写原因（如「卡尔巴里山火紧急警告，公路封闭」）。公路：山火、洪水、气旋紧急警告；土路：三者注意并行动；航班：只有气旋紧急警告。渡轮不在这里管（风暴规则已管）。 | `routeClosed()`；`engine.ts` `closeRoutes()` 包在 `travelOptions()` 的返回上 |
| **撤离** | 山火只封进来的方向，往外走的路一直通（洪水是路面被淹，两个方向都封）。山火、洪水、气旋紧急警告时卡片给出撤离去处（热浪紧急警告只给行动建议，不给去处）：从**这名玩家此刻真能走**的去处里（页面从 `travelOptions` 取可用的，已算封路、车、驾照、天气、钱和公交），挑没有注意并行动以上预警、最近的地点；一个都没有就提示「现在走不了：留在坚固的建筑里，听从当地指示」。 | `HazardDef.inboundOnly`、`evacuationTarget(region, loc, day, reachable)` |
| **户外关闭** | 山火、气旋注意并行动以上：徒步、露营、看星星、看日出、看风暴、农场采摘、下海类（游泳、浮潜、冲浪）关闭；热浪注意并行动以上：只关徒步、露营、农场采摘；洪水紧急警告：关徒步、露营、看星星、下海类（看日出、看风暴、农场采摘照常）。吃饭、慈善餐、野外找吃的不关。 | `activityClosed()`；`activitiesAt()`、`performActivity()` |
| **停工** | 工作地点山火、洪水、气旋紧急警告当天上不了班（不发工资，也不扣什么）；到这个地点的真实场所打上班卡也不行（之前打的卡照样能打下班卡）。热浪不停工。 | `workStopped()`；`shiftBlocked(state, region)`、`venues.ts` `workBlocked()` |
| **物资准备** | 新物品「应急包」$60（待平衡），城市、城镇、矿区有卖：停电时在家还能做饭，生存检定 +2。没有应急包，停电那天在家做不了饭（可以出去吃）。 | `items.ts` `emergency-kit`、`outageBlocksCook()`；`homeActionBlocked(state, op, region)` |

`shiftBlocked`、`homeActionBlocked` 加的是**可选**的 `region` 参数：不传时行为和以前完全一样（老测试不用改），引擎内部和页面都传。模拟脚本、fuzz 测试也改成传 `WA`。

## 6. 保险理赔接口 【本批：只提供数据】

```ts
incidentsFor(state, region, fromDay, toDay, vehicleLoc = state.loc): DisasterIncident[]
// { hazard, level: 3, loc, day, assets: ('home' | 'vehicle')[] }
CLAIMABLE = ['cyclone', 'bushfire', 'flood']
```

- 只返回事实：哪天、哪种灾害、哪个地点、涉及房子还是车。赔不赔、赔多少、免赔额、等待期由保险分支定。
- 只算紧急警告；热浪、停电不算财产损失。
- 车的位置按「现在所在地点」近似（存档里没有逐日位置）；保险分支要更准，可以自己记录并传 `vehicleLoc`。
- 一次最多查一年（366 天），防止被传入超大区间拖慢。
- 纯函数，不改存档。

**【提议】给保险分支**：每周结算时调用 `incidentsFor(state, region, 上次结算日 + 1, 今天)`，对有保单的财产生成理赔；真实保单常见「新保单生效后若干天内不保山火 / 气旋」的等待期，接之前请核对具体条款和来源。

## 11. 模拟对比（`npm run earth:sim -- --days=180 --runs=100`）

同一台机器，main `4f9c9e5` 和本分支各跑一次（只有西澳；模拟是确定性的，同样的种子）。只列有变化的行，其余策略（咖啡店、救生员等留在珀斯的）**完全没变**：珀斯是城市，不起山火，也不在气旋、洪水区。

| 策略 | 指标 | main | 本分支 |
| --- | --- | --- | --- |
| 矿工（卡尔古利，合租） | 第 60 天现金（中位） | $14,522 | $14,117 |
| | 期末净资产 | $74,396 | $73,933（−0.6%） |
| | 上班收入流水 | +448 | +445 |
| 打零工的背包客（无房） | 晕倒/人 | 10.63 | 9.70 |
| | 期末净资产 | $177 | $269 |
| | 未开工原因：地点 / 门槛 | 0.44 / 3.52 | 0.56 / 3.11 |
| 农场工（玛格丽特河，合租） | 期末净资产 | $22,181 | $22,078 |

读法（只描述，不下平衡结论）：

- 卡尔古利是矿区，夏天极端 / 灾难性火险日会起山火，紧急警告当天停工，所以矿工少上几班，净资产少 0.6%。
- 背包客会到处走，封路和户外关闭改变了它的路线和行动顺序，连带随机序列变了；晕倒次数、净资产的变化是这种连带效应，量级在随机波动以内，不能当成「灾害让背包客更好过」。
- 机器人不会买应急包，也不会主动看预警撤离；模拟里看不到这些应对的效果。
- 模拟只有 180 天、只在西澳；北部气旋、洪水区没有固定策略的机器人常驻，所以那几种灾害在模拟里几乎没出场。要评估北部，需要 Codex 加一个常驻布鲁姆或黑德兰港的策略。
