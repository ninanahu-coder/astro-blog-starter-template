# 志愿者与社区声望（分支 `claude/earth-volunteer`，2026-11-20）

在西澳、南澳生活的华人和留学生，很多人是从做志愿开始认识本地社区的：海滩清洁、食物银行、社区香肠摊、节日帮忙、动物救助、陪老人聊天、华人社团活动。
本文把游戏里已有的「声望」理一遍（**现状**），再给志愿者玩法和声望的用处补一套规则（**新提议**，其中标 **【已做】** 的在本分支第一版落地）。

所有新数值都是**待平衡**：第一版的手感值，等模拟和玩家数据再调；Claude 不下平衡结论（AGENTS.md）。

### 2.1 防刷【已做】

| 规则 | 数值（待平衡） | 位置 |
| --- | --- | --- |
| 每个游戏日最多做几次志愿 | 2 | `VOL_RULES.dailyMax` |
| 每个**现实日**（珀斯时间 0 点分界，同每日奖励）最多做几次志愿 | 6 | `VOL_RULES.realDayMax`（2026-11-20 用户定加） |
| 同一项每个游戏日 | 1 次 | `doVolunteer()` |
| 精力低于多少不让去 | 20 | `VOL_RULES.minEnergy` |
| 途中晕倒 | 次数照记、**不发声望**（`applyEffect` 晕倒时不加正声望） | 先记次数再结算，防止靠晕倒绕开每日上限 |
| 只有服务端结算 | 新动作走 `applyAction`，客户端不能写存档 | `actions.ts` |

每日 2 次按**游戏日**算，睡觉能让游戏日前进，单靠它挡不住「一直睡、一直做」。所以另加一层**现实日上限**【已做，2026-11-20 用户定】：

- 现实日用服务端时间算：`applyAction(state, region, a, now)` 的 `now` 由服务端传入（`world.ts` 传 `Date.now()`），`realDayOf(now)` 和每日奖励同一个分界（珀斯 0 点）；客户端改不了。
- 存档记 `volunteer.real = { day, n }`：这个现实日做了几次；换现实日从 1 重新数。
- 现实日满了，所有志愿都显示「今天（现实里）已经做了 6 次志愿，明天再来」，换游戏日、换项目、换地点都不行。
- 页面列表用 `Date.now()` 只算显示的「不能做」原因，真正判定在服务端。
- `realDayMax ≥ dailyMax`：一个现实日至少能把一个游戏日的 2 次做满（测试里有断言）。6 次 = 3 个游戏日做满，数值待平衡。

| 4 | 40 | 社区之星 | （第一版只是称号） |

不存档，由 `volunteer.n` 现算（`volTier()`）。

### 3.2 推荐信（新）

同一项志愿做满 **6 次**（`VOL_RULES.refShifts`）自动拿到一封推荐信，记进 `volunteer.refs`，每项一封。

用处（**工作机会**）：应聘、升职遇到声望门槛时，每封推荐信抵 **5 点**声望，最多算 **2 封**（`refRespect()`，`VOL_RULES.refRespect`/`refMax`，待平衡）。
只改了 `engine.ts` 的 `unmet()` 一行，所有职业（含其他分支新增的）自动生效。声望本身不变，排行和等级不受影响。

### 3.3 NPC（新）

志愿表里写了 `npcs` 的，那位 NPC 此刻在这个地点（`npcPresent`）时，一起做完关系 +3（`VOL_RULES.npcGain`），跨过好感门槛照常触发 TA 的剧情（复用 `unlockStories`）。
第一版接了罗莎（海豚中心志愿者）、艾拉、琳达（护林员）、萨姆（潜水向导），都是人设里本来就和这些事有关的人。

### 3.4 签证提示（只做提示）

卡片底部折叠一段说明，不改任何数值（`VISA_HINT`）：技术移民打分表里**没有「志愿服务」这一项**；和社区沾边、能加分的是「社区语言」认证（NAATI CCL）5 分；志愿经历和推荐信可以写进简历。来源：内政部打分计算器 <https://immi.homeaffairs.gov.au/help-support/tools/points-calculator>。以官网为准，游戏不是移民建议。

观察（只陈述数字，平衡结论留给 Codex 的分析）：

- 一直做志愿的机器人 180 天做了 145–193 次，平均每个游戏日 0.8–1.1 次，没有撞满每日 2 次；声望是同类不做志愿的 2–5 倍。
- 咖啡店策略第二次升职（店长，声望门槛 25）从第 43 天提前到第 19 天：志愿声望和推荐信让门槛提早够格，升职后工资高，期末净资产和买房也跟着提前。
- 咖啡店 + 志愿的支出里少了「休息」和「酒吧」（志愿顶替了原来补社交、打发时间的动作），平均心情低 4 点。
- 背包客 + 志愿：晕倒、破产天数略少，净资产差不多。
- 这些机器人是「能做就做」的上限策略，不代表普通玩家；§9 待定的数值可以参照这张表调。

### 7.2 现实日上限的影响

- 默认 N=1：每个游戏日都是新现实日，6 次的上限永远不会先于每日 2 次触发。**整份报告和加上限之前逐行相同**（`diff` 为空）。
