## 1. 现状【现状】

| 系统 | 文件 | 规则 |
| --- | --- | --- |
| 职业 | `data/careers.ts`，引擎 `careersAt` / `applyJob` / `workShift` / `tryPromote` / `promotionStatus` / `shiftBlocked` | 7 种职业 × 3 级。按地点类型或标签招人；每天最多上一个班；表现检定（能力 + 随机 0–60，难度 55/70/85）过了多发 20%；本级上满 8 班、5 班表现好、满足下一级的能力和声望要求时自动升职，升职声望 +3 |
| 技能课程 | `data/courses.ts`，`coursesAt` / `takeCourse` | 7 门，一次课直接涨一项能力；学费 = 基础价 × (1 + 当前能力/25)；每门每天一次 |
| 职业证书 | `data/certs.ts`，`certsAt` / `takeCert` / `certBonus` / `careerPay` | 每种职业一张，考一次；对口职业每班工资 +15%；途中晕倒不发证不收费 |
| 零工 | `data/activities.ts` 的 `work-cafe` / `work-mine` / `work-farm` | 不用应聘、不能升职、没有奖金 |
| 真实打卡上班 | `core/venues.ts` 的 `workTerms` | 现实中到店打卡，按职业时薪或地点零工时薪计薪 |

现状的缺口：

1. 证书只是加薪，**没有任何职位要求持证**；现实里 RSA、White Card 是上岗前提。
2. 没有「学历」：所有课程都是一次课，没有要读很久、读完换来新职位的路线。
3. 「留学生」出身和别的出身打工没有区别；现实里学生签证限工时。
4. 职业只覆盖餐饮、海滩、旅游、矿业、货运、酒吧、农场，没有建筑、护理、IT 这些华人和留学生常见的行业。

| `bachelor` | 大学学士课程（游戏缩短版） | 大学 | 30 × 4 小时 | $80 | $2,400 | 英语强化班 | 魅力 0.8、街头 0.4 | `bachelor` / +15 | 城市 |

说明：

- **报名前置是游戏设计**，不是现实入学要求（现实里各机构要求不同，见第 2 节）。前置只在报名（第一次课）时检查，开读以后不再查。
- 每次课耗精力 = 时长 / 10，娱乐 −4、社交 +4；成长走 `growSkill`（特质倍率 + 递减曲线），和其他成长一致。
- **途中晕倒**：和技能课程一样先交钱，这次课不算、学费不退。没有照搬证书的「先按没交钱跑一遍」，因为每次学费小（$25–80）；如果审查认为也要防「拿学费躲住院费」，可以改用 `paidTask`（要从 engine 导出）。
- 没有「退学」：停课超过 14 天就不算在读（只影响签证工时，第 5 节），进度保留，随时可以接着上。

### 3.3 以后可以加的【提议·未落地】

- 驾照分级（学习驾照 → 试用驾照 → 正式驾照），和现在的驾驶能力、货运公司的重型卡车驾照串起来。需要先查西澳的真实流程和费用。
- 学历课程的「学期」：按游戏日历分学期和假期，替代第 5 节「停课 14 天算假期」的简化。
- 在线课程：不用去城市，但成长打折。
- 一项「知识」能力：现在没有对应学习的能力，IT 职业借用了「街头」（随机应变、处理麻烦）做表现检定，是权宜之计。加新能力要改 `SKILL_KEYS`、存档和所有能力相关的界面，影响面大，单独立项。

### 4.3 矿业 FIFO【提议·未落地】

现实中的「飞进飞出」是连续上几天班、再飞回城市休几天。游戏可以做成矿业公司的一种排班：连续 N 天每天必须上班、包食宿（不扣房租不扣饭钱）、之后 M 天不能上班。具体天数需要来源，没有就作为纯游戏设定写明。

## 5. 留学生打工限制

### 5.1 游戏规则【提议·已落地】

现实规定见第 2 节。游戏简化为：

| 现实 | 游戏 |
| --- | --- |
| 持学生签证 | 出身是「留学生」（`origin === 'student'`） |
| 课程开课后、学期内（教学期和考试期） | **正在读某门学历课程**：上过、没上完、最近 14 个游戏日内上过课（`inSession()`） |
| 学期之间的假期、读完课程后 | 没在读任何学历课程、停课超过 14 天、或已经毕业 |
| 每两周最多 48 小时 | 每 14 个游戏日（第 0–13 天、第 14–27 天……）最多 48 小时 |
| 工作时间 | 职业班次 + 三种零工（咖啡店打工、矿场轮班、农场采摘）的时长；街头表演、捡瓶子不是雇佣，不算 |
| 超时违反签证条件，可被取消签证 | 直接不让上班（按钮置灰，显示原因），不做处罚 |

- 数据：`data/education.ts` 的 `VISA`（`capHours: 48`、`periodDays: 14`、`inSessionDays: 14`）、`VISA_GIGS`。
- 纯函数：`core/visa.ts` 的 `fortnightOf`、`inSession`、`visaCapped`、`workedMinutes`、`workMinutesLeft`、`visaBlocked`、`logWork`。
- 接入：`shiftBlocked()` 最后一项检查；零工在 `blockedReason()` 里检查；`workShift()` 和零工做完后 `logWork()`。工时**不论受不受限都记**，所以开读那天之前这两周打的工也算数。
- 存档：`workLog: { f, min }`（第几个两周、这两周的分钟数）。
- 界面：受限时「工作」卡片顶部显示「这两周还能打工 X / 48 小时」。

为什么不是「留学生永远受限」：模拟里三条咖啡店策略用的是留学生出身、每天上 6 小时班，永远受限会让这几行收入腰斩，属于平衡决定，要先经过 Codex。现在的写法下，玩家**选择读书**才进入学期、受工时限制，这也是现实里留学生的取舍：读书换学历，代价是只能兼职。若要改成永远受限，只需把 `visaCapped` 改成只看出身。

### 5.2 没覆盖的【提议·未落地】

- **真实打卡上班**（`venues.ts`）不计入签证工时：真实打卡按现实时间计薪、有自己的每日上限（`realWork`），和游戏日的两周对不上。可以按现实日折算后合并，要另外设计。
- 超时的处罚（签证被取消事件、麻烦值）：现在直接不让超时，没有违规路径。
- 毕业后的工作签证（485 类）：现在毕业后直接不限工时；以后可以做成签证有效期，到期前要找到担保雇主。需要查 Home Affairs 的现行规定。

## 6. 兼职、全职、跳槽、失业、简历和面试

### 6.1 现状【现状】

- **兼职和全职没有区别**：职业每天最多一个班，上不上由玩家决定，不上班没有后果。零工相当于临时工。
- **跳槽**：在别的雇主处应聘就自动辞掉旧工作，新工作从一级开始，本级班次清零。证书跟人走。
- **失业**：辞职或从没应聘就是无业，没有任何惩罚或补助。
- **简历和面试**：应聘只看第一级的门槛（能力、声望，本批起加上证书或学历），满足就当场录用。

### 6.2 提议·未落地

| 机制 | 提议 | 新增存档 | 影响 |
| --- | --- | --- | --- |
| 雇佣类型 | 应聘时选「兼职」或「全职」：全职每 7 个游戏日至少上 5 个班，否则先警告、再被解雇；兼职没有最低班数但升职要的班数 ×1.5；零工就是临时工（工资上浮 25%，见 `economy-design.md`） | `job.type`、`job.missed` | 会改模拟里所有上班族策略的行为 |
| 简历 | 按行业累计的班次 = 工作经历；证书和学历 = 资格。纯函数 `resume(state)` 汇总，界面「我」页展示 | `history: Record<careerId, shifts>` | 只加数据，不改现有规则 |
| 面试 | 应聘时做一次检定：职业对应能力 + 同行业经历加成 + 持有对口证书加成 + 随机（来自 `state.seed`）≥ 难度；没过同一雇主 1 天后才能再投 | `applyDays: Record<careerId, day>` | 应聘变得有失败可能，模拟要重跑 |
| 跳槽保级 | 同行业跳槽（如咖啡店 → 酒吧，同属餐饮）时，经历够的话从二级起步 | 需要职业带行业字段 `industry` | 让「换城市换雇主」不再从零开始 |
| 失业 | 无业超过 7 天，加一个「找工作焦虑」心情状态；应聘成功时消失 | 复用 `moodlets` | 现实里临时签证持有人一般拿不到失业补助，本批没查到来源，不写进游戏 |
| 解雇事件 | 表现差连续 N 班、或全职缺勤，触发「被约谈」事件 | 复用事件系统 | 需要写事件文案 |

这几项都会改变应聘或上班的结果，属于平衡决定，按 `AGENTS.md` 分工先交 Codex 模拟评估再落地。

## 9. 模拟结果

`npm run earth:sim -- --days=180 --runs=100`，本分支和 `main`（`e429bcd`）各跑一次，逐行比较输出：

**结果逐字相同**（从报告标题起 `diff` 无差异，11 种策略的所有表格都一样）。原因：

- 模拟里没有策略会读学历课程，所以留学生出身的三条咖啡店策略、酒保策略都不进入「学期内」，签证工时不生效；
- 现有 7 种职业没有加证书门槛；新职业、新证书、学历课程没有策略会用到；
- 新代码不消耗随机数（`state.seed`），所以随机序列不变。

也就是说，**本批的新内容目前没有被模拟覆盖**。要评估它们，需要在 `tools/earth/balance/sim.ts` 里加策略，例如「留学生读学士 + 咖啡店兼职（受 48 小时限制）」「背包客考 White Card 去工地」「急救证 → 护理三级 → 养老院」，这属于 Codex 的模拟任务（第 11 节）。本批没有改 `balance-report.md`。
