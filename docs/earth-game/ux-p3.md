# 体验改造 P3：画面设置三档

接 P2（`ux-p2.md`），对应方案 §7。设置在「我 · 设置 · 显示」，紧跟在语言下面。

## 1. 四个选项

默认是「跟随系统」。只存在这台设备的本机设置里（`earth.prefs.v1` 的 `visual`），不进存档、不上传。

| 项目 | 标准 | 省电 | 省流量 |
| --- | --- | --- | --- |
| 地点 AI 短片 | 自动播放 | 不放，显示静态图 | 不放，显示静态图 |
| 真实地图底图 | 开 | 开 | 关，用手绘地图 |
| 动画和飞字 | 全部 | 从简（等于「减少动画」） | 从简 |
| 配图 | 2 倍图 | 2 倍图 | 1 倍图（`public/earth/cgi/1x/`） |
| 环境音和音乐 | 按各自开关 | 暂停 | 暂停 |

- **跟随系统**：浏览器开了省流量（`navigator.connection.saveData`）就按省流量；开了减少动态效果就按省电；都没开按标准。两个都开时按省流量，它本来也省电。
  - Safari 和火狐没有省流量接口，在这两种浏览器上只看减少动态效果。
  - 玩的时候系统设置变了，会马上跟着换档。
- **只暂停，不改开关**：画面档不改玩家自己设的环境音、音乐、真实地图开关。
  - 被暂停的开关旁边写「（「省流量」档下暂停）」。
  - 换回标准档后原样恢复。
- **动画**：省电、省流量档把「跟随系统」的动画当作「减少」。玩家把动画明确设成「正常」或「减少」时，听玩家的。
- **短片**：省电、省流量档不放 `<video>`，直接给静态图，所以不会发视频请求。方案里写的是「不自动播放」，这里做得更彻底一些：省电档下没有点了再播的按钮。
- **底图**：省流量档不下地图库和图块。正在显示的真实地图会马上拆掉。

## 2. 1 倍配图

- `tools/earth/media/cgi-1x.py` 把清单里的每张图缩到一半宽，用 cwebp 质量 72 重压，存到 `public/earth/cgi/1x/` 下同名文件。
  - 238 张，从 14.3MB 降到 3.8MB，约为原来的 26%。
  - 清单里加了或改了图，要重跑这个脚本。测试会检查 1x 图齐不齐、尺寸对不对、有没有多余文件。
- 地址换算在 `src/game/ui/visual.ts` 的 `cgiSrc`，只认 `/earth/cgi/<小写名>.webp` 这一种格式，别的地址原样返回，拼不出别的路径。
- 标准档和省电档照旧用 2 倍图。

## 3. 实测（本机 wrangler dev，390×844，第 1 天新角色，起点珀斯）

为了有对照，测试时把媒体清单的短片挂到了所有地点上。

| 情况 | 视频请求 | 2 倍图 | 1 倍图 | 动画从简 | 控制台报错 |
| --- | --- | --- | --- | --- | --- |
| 标准 | 1 | 16 | 0 | 否 | 0 |
| 跟随系统（系统什么都没开） | 1 | 16 | 0 | 否 | 0 |
| 省电 | 0 | 16 | 0 | 是 | 0 |
| 跟随系统 + 减少动态效果 | 0 | 16 | 0 | 是 | 0 |
| 省流量 | 0 | 0 | 16 | 是 | 0 |
| 跟随系统 + 系统省流量 | 0 | 0 | 16 | 是 | 0 |

- 设置页四个按钮各 76×44，跟随系统时说明里先写现在按哪一档、为什么。
- 无头浏览器没有 WebGL，真实地图本来就不出来，所以底图请求在浏览器里测不了。这部分由 `ux-p3.test.ts` 检查接线：底图开关要同时看玩家开关和画面档，换到省流量档时拆掉底图。

## 4. 没做的

- 省电档下的短片没有「点了再播」的按钮。
- 1 倍图只用于 CGI 配图；头像（`public/earth/char/`）和 Fluent emoji 本来就小，没做。
- 没在真机上测过：安卓 Chrome 开省流量、iOS 低电量模式（iOS 低电量模式会让网页报告减少动态效果吗，未核实）。
