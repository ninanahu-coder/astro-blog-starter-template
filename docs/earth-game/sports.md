## 3. 日常运动【本批】

### 3.1 五项运动

| 运动 | 算作训练的现有玩法 | 新增玩法 | 比赛检定的能力权重 |
| --- | --- | --- | --- |
| 🏃 跑步 | 真实地点 `run` | 互动 `jog` 跑步：城市、镇、海边、港口、公园、岛上，5–21 点，45 分钟，免费，体能 +1.5、力量 +0.3 | 体能 0.75、力量 0.25 |
| 🏊 游泳 | 互动 `swim`、`snorkel`，真实地点 `swim` | — | 游泳 0.7、体能 0.3 |
| 🏋️ 健身 | 互动 `gym`，真实地点 `train` | — | 没有单独的比赛；准备度的 30% 算进其他项目（交叉训练） |
| 🏄 冲浪 | 互动 `surf` | — | 游泳 0.5、体能 0.3、力量 0.2 |
| 🚴 骑车 | — | 互动 `cycle` 骑车：租共享单车 $10，城市、镇、海边、港口、公园，5–20 点，90 分钟，体能 +1.5、力量 +1 | 体能 0.6、力量 0.4 |

能力成长仍然走原来的互动和真实地点动作，本批不改它们的数值。新加的两个互动是数据（`data/activities.ts`），不是引擎特例。

### 3.2 训练准备度

能力是「会不会」，准备度是「最近练没练」。准备度给了「保持状态」的理由，又不用让能力往下掉（能力只涨不跌是现有设定）。

- 每项运动一个准备度，0–100。一次训练 +12；同一项当天第 2 次 +6，第 3 次起不涨（避免一天刷满）。
- 最近一次训练后歇满 2 天开始，每天 −4。存档只记「最近一次训练后的值和那天」，读的时候现算，不需要每日结算。
- 俱乐部训练课 ×1.5（见 §5）。
- 健身准备度的 30% 算进其他项目的比赛。
- 记录方式：`applyAction` 成功、没晕倒后调用 `noteTraining()`，按动作查 `SPORTS[].acts / ops`。失败的动作、途中晕倒都不算。

### 3.3 对健康的影响

- 每个游戏日第一次运动，健康 +1（不管哪一项、练几次）。
- 运动本来就消耗精力、清洁，晕倒风险沿用现有规则；比赛扣精力更多（见 §4.4），精力不够开不了赛。
- **【待做】** 过度训练：同一天练太多次给「肌肉酸痛」（现有心情状态 `sore`）。本批只做了「第 3 次起准备度不涨」，没有惩罚。

## 4. 比赛【本批】

### 4.1 日历：用游戏日历，不用现实日历

赛事放在游戏日历上（一年四季，每季 28 天），和 `festivals.ts` 一样，**不跟现实日期同步**。理由：

1. 用户 2026-11-18 定过「游戏日历不和现实同步」（见 `plan-50.md` 第 8 批、`live-social.md` §3.1）。
2. 比赛要求「人在举办地 + 比赛日 + 发令时段」。按现实日期的话，一年只有一天能跑，错过就等一年；游戏日历一年 112 天，几天就能轮一圈。
3. 模拟（`earth:sim`）能覆盖到。

真实赛事的日期记在数据的 `ref` 里，用来决定游戏里放在哪个季节、哪一天：

- 真实月份 → 游戏季节：9–11 月春、12–2 月夏、3–5 月秋、6–8 月冬（南半球）。
- 季内第几天 = round((该季第几个月 × 30.4 + 日) ÷ 91 × 28)，夹在 1–28。

**【待做】** 和 `live-social` 的现实活动层打通：真实比赛日当天（现实时间），在举办地完成一场游戏里的同名比赛，给一次性「到场纪念」。现实活动层已经在 main（`core/live.ts`）。

### 4.3 报名

- 免费赛（公园 5 公里）不用报名，当天到场就跑。
- 收费赛开赛前 28 天开放报名，在哪都能报（网上报名），不花游戏时间。
- 比赛当天现场报名，报名费 ×1.5；发令时段结束后截止。
- 有门槛的比赛（海峡横渡要游泳 40，像真实赛事要先完成资格游）达不到不能报。
- 同时最多报 10 场，只算还没到比赛日的报名（`liveEntries()`）：错过的那届过了比赛日就不再占名额，下次报名时清掉。没去比赛不退费。
- 这一届今天已经取消（见 §4.4）：不能报名。

### 4.4 参赛和成绩计算（能力检定）

参赛条件：人在举办地、今天是比赛日、在发令时段内、已报名（免费赛不用）、达到门槛、精力 ≥ 这场比赛的要求（25–60）、没生病（比赛算剧烈运动，海上项目还算下海，`illnessBlock()`）、终点不是宠物不能去的地方（带着没寄养的宠物不能参加游到罗特尼斯岛的海峡横渡，和坐船上岛同一条规矩）。有待处理事件时不能参赛。

```
检定分 = Σ（各能力检定分 × 权重）        ← checkScore()：能力 + 特质 + 装备 + 心情，和现有检定一致
       + 准备度 × 0.25                     ← 本项准备度 + 健身准备度 × 0.3，封顶 100
       + 队友加成 4                        ← 同项目俱乐部、会员有效、最近 7 天上过训练课
       − 疲劳 0.3 × max(0, 50 − 精力)
       + 随机 0–40                         ← roll(state)，存档种子
```

| 检定分 | 结果 | 名次 | 声望（以城市长跑为例） | 心情 |
| --- | --- | --- | --- | --- |
| ≥ 难度 + 40 | 🥇 金牌 | 第 1 名 | +12 | 站上领奖台（+10，24 小时） |
| ≥ 难度 + 30 | 🥈 银牌 | 第 2 名 | +8 | 同上 |
| ≥ 难度 + 20 | 🥉 铜牌 | 第 3 名 | +5 | 同上 |
| ≥ 难度 | 🏅 完赛奖牌 | 按离铜牌线的距离排在第 4 名到参赛人数之间 | +2 | 跑完全程（+6，12 小时） |
| < 难度 | 🚩 未完赛 | — | 0 | 肌肉酸痛（现有 `sore`） |

- 用时 = 冠军用时 × (1 + 0.6 × 落后程度)，最慢 1.6 倍；记个人最好成绩。
- 花的游戏时间 = 用时 + 1 小时（检录、领物）；精力 − 比赛要求、饱食 −20、清洁 −30、社交 +10、娱乐 +20（未完赛 −5）；按项目权重涨能力（权重 × 3）；算一次训练。
- 终点在别的地点（城市到海湾 → 格莱内尔格、海峡横渡 → 罗特尼斯岛）：完赛后人在终点；未完赛留在起点。
- 比赛取消（`cancelReason()`）：海上比赛（海峡横渡、栈桥赛、冲浪赛）当天举办地是风暴；或者自然灾害预警让这项运动对应的日常互动（跑步看 `jog`、游泳看 `swim`……）在举办地暂停（`raceCancelled()` → `disasters.ts` `activityClosed()`）。报过名的点「参赛」退原价报名费、去掉报名；这一届不能再比，也不能再报名。
- 一届只能比一次（按「届」的标识：每年一次 `id:y年`，每周赛 `id:d游戏日`）。
- 卡片上显示「完赛把握约 x%、上领奖台约 y%」（按随机部分均匀分布算），检定公式和现有事件检定一样透明。

**奖牌**：本批只记在成绩里（最近 20 条）和个人最好成绩里，不做成背包物品。**【待做】** 成长页的「奖牌墙」和成就（第一次完赛、三项都完赛、金牌）。

## 6. 存档、协议和页面【本批】

### 6.1 存档字段 `sport`

按 `save-sync.md` §5：字段名 `sport`（各分支都没有这个名字），`createCharacter` 给 `emptySport()`，`sanitizeState` 里一行 `sport: cleanSport(r.sport, clock)`。没改 `SAVE_VERSION`，没改已有字段。

| 子字段 | 内容 | 清洗规则 |
| --- | --- | --- |
| `form` | 各项准备度 `{ v, d, n }` | 只留 5 项已知运动；v 钳到 0–100；d 不能晚于今天；n 1–99 |
| `total` | 各项累计训练次数 | 只留已知运动，正整数 ≤ 1e6 |
| `hday` | 最近一次「运动健康 +1」的游戏日 | 晚于今天 → −1 |
| `club` | `{ id, until, last }` | 只认已知俱乐部；until ≤ 今天 + 13 期；last 晚于今天 → −1 |
| `entries` | 已报名的届，≤ 10 | 只认已知比赛，届标识类型对得上（每周赛 `d`、每年 `y`），去重，已比过的去掉 |
| `results` | 最近成绩，≤ 20，新的在前 | 已知比赛、届标识属于这场比赛、名次档合法、日子不晚于今天、每届一条；未完赛的名次和用时归零 |
| `pb` | 各比赛最好用时（秒） | 只认已知比赛，正整数 |

序列化后通常几百字节，最多约 2 KB。没有给服务端专用的值，不需要在 `publicState()` 里清。

### 6.2 动作

```ts
| { t: 'sport'; op: 'enter' | 'race' | 'join'; id: string }   // 报名、参赛、入会/续费

```
