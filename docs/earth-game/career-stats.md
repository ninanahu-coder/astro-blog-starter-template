# 玩家生涯统计（「我 · 生涯」）

分支 `claude/earth-career-stats`，2026-11-20，从 main `4f9c9e5` 开；2026-11-22 合并 main `a640483`，更新日志改为 v76。合并时做的事见 §8。

> 和统计（`analytics.md`，PR #50，已合并）不是一回事：那边是**服务端**统计、埋点和隐私开关，给运营看；
> 这里是**存档里**的个人生涯计数，给玩家自己看、自己分享。两边不共用代码和字段。

标记：**【现状】** 是 main 上已经有的；**【新】** 是这个分支加的；**【提议】** 是还没做、留给以后的。

## 1. 现状（开工前 main 上已有的）

- 「我」页标签 `ME_TABS`：概况、资产、关系、日志、更新、设置。另有「成长」页（等级、每日、成就、相册、图鉴、鱼获、主线、足迹）。【现状】
- 能直接从存档算出来的数【现状】：
  - 来澳天数：`dayOf(clock) + 1`（「我」页头已经显示「第 N 天」）；
  - 到过的地方：`visited`（地点 id → 到访次数），所以「最常去的地方」不需要新字段；
  - 认识的人：`relations`（有过互动的 NPC）+ `met`（一起做过事、交易过的玩家，最多留最近 30 位）；
  - 有没有工作、住处、车、房产、证书：`job`、`home`、`vehicle`、`properties`、`certs`。
- 昨天回顾（`core/recap.ts`）：`dayMark` 记「今天开始时」的现金、声望、地点数，跨午夜时算出 `yday`。只有一天，不分类别。【现状】
- 车的里程 `car.km`：换车、卖车清零，不能当生涯公里。【现状】
- **没有**的：累计赚了多少、花了多少、花到哪里；累计走了多少公里；「哪一天第一次做到某件事」；周、年小结。日志 `journal` 只留最近 40 条，不能拿来回算。
- 分享：「成长」页有「分享我的进度」，只分享一句文字（带区域名）。【现状】

## 2. 设计

### 2.1 存档字段 `tally`【新】

只累积计数，不存逐条明细。按 `save-sync.md` §5.1 加：字段名 `tally`（各分支都没用过），`createCharacter` 给初值，`sanitizeState` 的 `out` 里一行 `tally: cleanTally(r.tally, tallyCtx(r, visited))`，没改 `SAVE_VERSION`。

```ts
tally: {
  from: number;        // 从哪个游戏日开始统计（新角色 0；旧存档是迁移那天）
  km: number;          // 累计出行公里（整数）
  in:  { [类别]: 元 }; // 累计收入，按来源
  out: { [类别]: 元 }; // 累计支出，按去向
  ms:  { [里程碑 id]: 游戏日 }; // −1 = 统计上线前就已达成
  pre: boolean;        // 旧存档刚迁移，下一次结算时补记「统计前」的里程碑
  wk, yr: { i, earned, out, km, places, people }; // 本周 / 本年开始时的快照
  lastWk, lastYr: { i, n, earned, spent, top, topAmt, km, places, people } | null; // 上一个结束的周 / 年
  cash?: number;       // 上次记账时的现金（合并 main 后加，见 §2.2）
}
```

大小：12 个类别 × 2 + 19 个里程碑 + 4 个小快照，序列化后约 1 KB，远小于 §5 建议的 4 KB。不放秘密，`publicState()` 不用清。

### 2.2 钱的类别【新】

| 类别 | 显示 | 来自 |
| --- | --- | --- |
| work | 工作与零工 | 上班、真实地点打卡上班、活动里赚的钱（零工） |
| transport | 出行 | 路费、油钱（出行途中当场交的罚款也在这里） |
| shop | 吃喝购物 | 买东西、用东西、卖二手、邻里换手墙的买卖（含被骗的钱），真实地点吃饭 / 喝一杯 / 采购 |
| housing | 住房与房产 | 租房（看房、租约、押金扣款、被骗租的钱）、家具、买卖房产、还贷；**周结算的房租、房产收支** |
| vehicle | 车辆 | 买卖车、保养；**周结算的车险** |
| study | 学习考证 | 课程、证书、学历课程、图书馆自习 |
| fun | 玩乐体验 | 收费体验、钓鱼、拍照、GPS 打卡、徒步路线、爱好（种子、手工材料）、运动（比赛报名费、俱乐部会费、取消退费） |
| social | 人情往来 | NPC 互动、共同事件、玩家之间送礼和二手摊、交易所（挂单费、买、出价、领邮箱的钱）、面交 |
| event | 意外事件 | 事件选项的花费和收获 |
| daily | 日常 | 活动的花费、真实地点其他动作（训练、看病……）、看病（GP / 药房 / 急诊）、养宠物、晕倒住院的医药费 |
| reward | 奖励 | 每日奖励、全服周目标、成就、现实活动、新手引导、主线和支线的奖励 |
| other | 其他 | 理财买卖（钱换成了资产，会显示成支出）、签证和雅思报名费、周结算自动扣的罚款、两次记账之间在别处变了的现金（见下）、兜底 |

**记账方法**：每一步结算完（`applyAction` / `applyCoop` / `applyTrade` / `applyWeeklyClaim` / `claimDaily`）调一次 `finishTally(prev, next, [收入类别, 支出类别])`：

1. 引擎里自己知道类别的钱先记：`weeklyTick` 用 `tallyCash()` 把房租和房产记成 housing、车险记成 vehicle、自动扣的罚款记成 other；晕倒住院的医药费记成 daily；`applyAction` 里主线、支线、新手引导发的钱记成 reward；
2. 这一步现金变化（取整后）减去第 1 步已记的净额，剩下的按动作类别记：正数记收入、负数记支出。

3. **现金锚点**（合并 main 后加）：`tally.cash` 记着上次记账时的现金。服务端交易所、面交这类不走 `applyAction` 的路径已经在纯函数里自己记账；万一还有漏的（以后新加的服务端路径、存档在没有生涯统计的部署上走过一段），下一次记账时把差额补记到 other。

所以「累计收入 − 累计支出 = 统计以来的现金变化」恒成立（测试和模拟都核对了）。代价：一步里同类的进出相抵后只记净额（比如卖旧车换新车按一笔净支出记）；周结算的房产收入和开销也按净额记。这是「只存计数」的取舍。

### 2.3 公里【新】

只在出行**真的到了目的地**时加这条路线的里程（`travelOptions` 里的 `km`，公路已含 1.25 绕行系数）。半路晕倒被送医院的不算公里，路费照记。GPS 打卡、真实地点不算公里（那是现实里走的路，不由游戏结算）。

### 2.4 里程碑【新】

数据在 `src/game/data/milestones.ts`，19 个：来澳 7 / 30 / 100 / 365 天，第一份工作、住处、车、证书、房产，到过 10 / 30 个地方，走过 100 / 1000 / 5000 公里，累计收入 $1k / $10k / $100k，认识 5 / 20 人。

- 只记「哪一天第一次做到」，**不发奖励、不影响任何数值**，所以没有平衡问题；门槛只是展示用的整数。
- 记下后不收回（辞职、卖车后也还在）。
- 标题不得带地点名（分享卡会用，测试检查）。
- 「有自己的车」对开局就有车的出身（留学生）第一步就会达成，记第 1 天。

### 2.5 周小结和年度回顾【新】

- 周 = 来澳第几周（`(游戏日 − 开局日) ÷ 7`），年 = 365 个游戏日。用游戏日而不是现实日：玩家的「来澳天数」本来就是游戏日；和全服周目标的现实周无关。
- 跨过边界时，把旧周期写成小结（`lastWk` / `lastYr`），换一份新快照。跨好几周的一步（住院、长途）合成一张，`n` 记跨了几周。跨边界那一步的钱算在旧周期里（和昨天回顾的规则一样）。
- 本周、本年至今的数现算（当前累计数 − 快照）。
- 新去的地方、新认识的人只算增加的（常遇见的人超过 30 位会挤掉旧的，这个数不会变负）。

### 2.6 旧存档迁移【新】

- 没有 `tally` 的存档：`from` = 现在这天，收支和公里从 0 开始，快照取现在的地点数和人数（迁移那周不会把所有去过的地方都算成新去的）。页面写明「收支、公里从第 N 天开始统计」。
- `pre = true`：第一次结算时，**之前就已满足**的里程碑记成 −1，显示为「统计前」，不冒充成迁移那天；这一步才新达成的记当天。还没结算前页面也按同样规则显示。
- `cleanTally` 对任何输入不抛异常；类别、里程碑只认已知 id；金额钳到 [0, 1e12]；里程碑日子不能晚于今天；快照不能超过现在的累计数；周期序号不超过现在，上一周（年）必须早于本周（年）；幂等。

### 2.7 页面【新】

「我」页标签加「生涯」（第二个）。`src/game/ui/career.ts` 第一次打开这一页时才 `import()`，不进首屏（和「更新」页同样的加载与失败重试）。

视觉沿用入境卡（`DESIGN.md`）：纸色 `--stock` 卡片（深色主题下也保持纸色）、打孔虚线和左右半圆缺口分栏、中文粗体 + 英文衬线小字的栏位标签、圆珠笔蓝的数字（`tabular-nums`）、最新一条里程碑用洋红点。不用 emoji 当图标。所有插值经过 `esc()`。

三张卡：

1. **生涯档案**：来澳天数 / 走过（地点数 · 公里）/ 赚到（收入前 3 类）/ 认识（本地人 · 玩家）；钱去哪了（前 6 类 + 比例条）；最常去的 3 个地方；里程碑时间线（新的在上）。
2. **本周小结**：本周至今，加上一周的小结；按钮「生成本周小结卡」。
3. **年度回顾**：本年至今，加上一年的回顾；按钮「生成年度回顾图」「上一年的回顾图」。

### 2.8 分享卡【新】

- `cardSvg(state, kind)` 是纯函数，输出 1080×1350 的 SVG 字符串，**同样的存档画出一模一样的字符串**（测试检查）；`cardPng()` 在浏览器里画到 canvas 转 PNG。不用 AI 生成图表。
- 内容：玩家名和形象、来澳第几天（洋红双圈章）、这一周期的收入 / 支出（大头）/ 公里 / 新地点、生涯累计、支出前 3 类比例条、最近 4 个里程碑。
- **隐私**：卡上不带地点名、地点 id、区域名、坐标（测试对全部地点逐个检查）。最常去的地方只在页面上显示，不进卡。
- 能分享文件（`navigator.canShare({ files })`）就调系统分享，不能就下载 PNG。

## 6. 和其他分支的关系（下面这些都已在 main，合并时的处理见 §8）

- `claude/earth-economy`（金融资产 `holdings`）：买卖理财产品的动作 `{ t: 'asset' }` 合并后会落到 `actionCats` 的兜底类别 other。合并时在 `actionCats` 加一行（建议新类别或归 other），并确认 `netWorth` 和这里的「收入 / 支出」口径不同：这里只看现金流。
- `claude/earth-home-vehicle`（押金、印花税、按里程折旧）：押金和印花税会随动作记进 housing / vehicle，不需要改；退押金记 housing 收入。
- `claude/earth-transport`、`claude/earth-gps-route`：如果新增改变位置的动作（不是 `travel`），公里不会自动算，要在 `applyAction` 的公里那一行补上。
- `claude/earth-activity-attrs`：改了 `engine.ts` 的 `advance()`；这里只改 `weeklyTick`，不重叠。
- `claude/earth-social-npc`：如果把认识的人改成别的字段，`peopleOf()` 要跟着改。
- 所有加 `GameAction` 新类型的分支：TypeScript 不会因为 `actionCats` 缺 case 报错（有 default），新动作的钱会记成 other，合并时补一行即可。
