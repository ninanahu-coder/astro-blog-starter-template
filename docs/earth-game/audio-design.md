# 地球人生 · 声音设计（音效、环境音、背景音乐）

v37，2026-11-20。分支 `claude/earth-audio`。

每一节都标了状态：

- **【现状】**：v37 之前 main 上已经有的。
- **【v37 已落地】**：这个分支做了，有测试。
- **【提议】**：只是设计，还没做，等定了再排期。

玩家主要是在西澳、南澳的华人和留学生，大多用手机玩，常在公交上、宿舍里、上课间隙打开。所以有三条原则：

1. 默认静音。
2. 声音只做点缀，不靠声音传递信息。
3. 不为声音多花流量。

---

## 1. 总体结构

```
AudioContext（第一次点页面时才建）
 └─ master 总线（总音量：轻 0.5 / 中 1 / 响 1.6）
     ├─ sfx 分轨：提示音        ← sound.ts playCue，跟首屏一起加载（约 1 KB）
     ├─ ambience 分轨：环境音    ← ambient.ts createBeds（懒加载，约 3.6 KB）
     └─ music 分轨：背景音乐     ← 同上
```

| 文件 | 内容 | 什么时候加载 |
| --- | --- | --- |
| `src/game/ui/sound.ts` | 提示音数据和播放；混音台 `createMixer`；场景选择的纯函数 `cueAfter`、`familyOf`、`ambienceFor`、`musicFor` | 首屏 |
| `src/game/ui/ambient.ts` | 噪声环境音和程序生成音乐的合成器 `createBeds`；配方 `BEDS`、`MOODS_DEF`、`FAMILY_TONE` | 玩家打开环境音或音乐后，用动态 `import()` 加载 |
| `src/game/ui/prefs.ts` | 本机偏好：`sound`、`ambience`、`music`、`volume` | 首屏 |
| `src/pages/earth.astro` | `ensureAudio` / `sfx` / `syncScene`，设置页的开关，切后台时暂停 | 首屏 |

**【现状】** 第 29 轮已经有 4 个提示音（ok / fail / event / ach）。全部用 Web Audio 振荡器合成，有一个开关，默认关闭，直接接到扬声器。

**【v37 已落地】** 改成了上面的三条分轨加总线，增加了环境音和音乐。

## 2. 音效清单

所有提示音都是 1–4 个短音。每个音由一个振荡器（正弦或三角波）加一个增益包络组成：起音 10 毫秒，然后指数衰减。单个音的峰值是 0.08，再乘总音量；最响一档也不超过 0.13。整段不超过 0.5 秒，频率在 150–2000 Hz 之间。这些限制都由 `tests/earth/sound.test.ts` 检查。

| 提示音 | 时机 | 音 | 状态 |
| --- | --- | --- | --- |
| `ok` | 动作做成 | 660 Hz 一声 | 现状 |
| `fail` | 动作失败 | 220 Hz 一声低音 | 现状 |
| `event` | 事件弹窗出现 | 523→784 两音上行 | 现状 |
| `ach` | 达成成就 | C-E-G 三音 | 现状 |
| `tap` | 切换底部标签（按钮） | 880 Hz，30 毫秒 | v37 已落地 |
| `arrive` | 出行到达，而且没有马上弹事件 | 392（三角）→587 | v37 已落地 |
| `rain` | 到达时那里在下雨 | 三个短高音，像水滴 | v37 已落地 |
| `storm` | 到达时那里是风暴 | 165/196 Hz 三角波，持续约 0.4 秒，像闷雷 | v37 已落地 |
| `level` | 声望升级（`level(respect).lv` 变大） | C-E-G-C 四音上行 | v37 已落地 |
| `stamp` | 入境卡盖章 | 170/340 Hz 三角波，短促的闷响 | v37 已落地数据；**接线留给 `claude/earth-start-ui`**，见 §9 |

**一次动作只响一声。** 选哪一声由 `cueAfter()` 决定（纯函数，有测试）。优先级如下：

1. 失败 → `fail`。
2. 成就 → `ach`。
3. 升级 → `level`。
4. 出行：
   - 到达后马上弹事件：不响，让 `event` 来响；
   - 风暴 → `storm`；
   - 下雨 → `rain`；
   - 其他天气，包括天气分支新加的 `cold` → `arrive`。
5. 其他 → `ok`。

**【提议】** 下面这些还没做：

- 周结算预警响一声低音。注意：预警本来就有文字卡片，声音只能是附加。
- 收到聊天消息时响一声很轻的提示。默认关，单独开关，避免公共场所尴尬。
- 钓鱼、拍照任务成功时，用专属的短音型。

## 3. 环境音

**【v37 已落地】** 不用音频文件。一段 2 秒的白噪声缓冲区，用固定种子的线性同余生成器生成，所以循环接缝处是同一段噪声。这段噪声循环播放，经过 `BiquadFilter` 塑形；需要时再加一个低频振荡器（LFO），让音量或滤波频率慢慢起伏。

| 环境音 | 用在 | 配方 |
| --- | --- | --- |
| `sea` 海浪 | 海岸、岛、港口，或带 beach / reef / surf 标签的地点 | 低通 480 Hz，音量约 9 秒起落一次 |
| `city` 城市 | kind = city（珀斯、曼杜拉、阿德莱德、甘比尔山） | 带通 220 Hz 的平稳车流，加一层 900 Hz 的人声底噪 |
| `inland` 内陆 | 矿区、内陆、公园、不靠海的小镇 | 带通 700 Hz 的风，风的音高慢慢摆动 |
| `rain` 雨 | 当地今天下雨 | 高通 2600 Hz 的细密雨声，加一层低频 |
| `storm` 风暴 | 当地今天风暴 | 雨，加低通 200 Hz 起伏的风 |

规则：

- 分类优先级：城市 > 海边 > 内陆。有海滩的城市，比如珀斯，算城市。
- 下雨和风暴的声音盖过地点本身的声音；其他天气按地点放。

**换场景时**（出行、天气变、天色变、节日开始）：旧的声音在 1.5 秒内淡出后停止，新的同时淡入。同一个场景再设一次不重建。

**【提议】** 下面这些还没做：

- 夜里在海边、内陆加虫鸣层，可以用高频振荡器做颤音合成。
- 港口偶尔响一声汽笛，城市偶尔有电车铃。都用随机间隔的一次性合成音。
- 室内场景（在家、上班）把环境音压低，再过一个低通滤波，模拟隔着窗户听。

## 4. 背景音乐

**【v37 已落地】** 背景音乐由程序生成，不用任何现成的曲子。

`musicFor()` 返回 `情绪:地点类`，比如 `day:sea`，共 5 × 3 = 15 种组合：

- **情绪**：节日进行中（`festivalsSoon().here`）用 `festival`；否则按当地真实天色 `skyPhase()`，分 `dawn` / `day` / `dusk` / `night`。不认识的天色按 `day`。
- **地点类**：决定根音和音色。

| 地点类 | 根音 | 音色 |
| --- | --- | --- |
| 海边 | A3 | 正弦 |
| 城市 | C4 | 三角波 |
| 内陆 | G3 | 正弦 |

| 情绪 | 小节 | 点缀音概率 | 音量 | 感觉 |
| --- | --- | --- | --- | --- |
| dawn | 4.8 s | 0.35 | 0.035 | 舒缓、上扬 |
| day | 4 s | 0.5 | 0.04 | 明亮 |
| dusk | 5 s | 0.3 | 0.035 | 从小调和弦开始 |
| night | 6 s | 0.2 | 0.025 | 最轻、最慢 |
| festival | 2.4 s | 0.9 | 0.04 | 最快，点缀音最多 |

**生成方式：**

- 每小节铺一个三音和弦垫。和弦慢起慢收，持续到下一小节开头，所以和弦之间是连着的。
- 按概率加一个五声音阶的点缀音。
- 所有音都在 80–1200 Hz 之间。

**排程：**

- 每小节用定时器提前排下一小节，时间用 AudioContext 的时钟。
- 后台标签页的定时器会变慢；落后时从当前时间接着排，不一口气补很多音。
- 切到后台时整个 AudioContext 暂停（`suspend`），回到前台再恢复。

**【提议】** 下面这些还没做：

- 每个节日给一个专属的短动机，叠在 festival 和弦上。例如中秋用五声音阶下行，澳洲日用大调琶音。
- 首次到达标志性地点时，响一个 4 小节的「主题句」，之后回到常规音乐。
- 按天气给音乐加滤波：雨天低通，风暴天降低音量。

## 5. 音量分轨和开关

**【v37 已落地】** 设置页「我 · 设置 · 显示」里有下面这些项：

| 设置 | 键 | 默认 | 说明 |
| --- | --- | --- | --- |
| 音效 | `sound` | 关 | 第 29 轮已有 |
| 环境音 | `ambience` | 关 | 新 |
| 背景音乐 | `music` | 关 | 新 |
| 音量 | `volume` | 中 | 轻 / 中 / 响，作用于总线 |

- 设置存在本机 `localStorage` 的 `earth.prefs.v1`，不进存档、不上传。
- 读进来的值按不可信数据处理：不认识的音量档、不是布尔值的开关，都退回默认（`parsePrefs`，有测试）。
- 设置页点到不认识的音量档也不会改（有界面测试）。
- 增益变化用 `setTargetAtTime` 平滑过渡，大约 50 毫秒，开关时不会有咔哒声。

**【提议】** 每条分轨各自的音量滑杆。现在的三档总音量加三个开关已经够用，等有玩家反馈再加。

## 6. 移动端自动播放限制

iOS Safari 和 Android Chrome 都要求先有用户操作，才能创建或恢复 AudioContext 并出声。

**【现状】** 提示音只在玩家点按钮之后才响，所以第 29 轮在第一次出声时才建 AudioContext。

**【v37 已落地】**

- 打开页面时**绝不**建 AudioContext，就算本机设置里环境音、音乐是开着的也不建。界面测试会断言：打开页面后建了 0 个。
- 玩家第一次点页面任何地方（`click` 监听里，在判断按钮之前），这时才建音频、加载合成器，开始放环境音和音乐。
- 在设置页打开环境音或音乐，这一下点击本身就算用户操作，马上能听到。
- 切到后台（`visibilitychange`，`document.hidden`）时暂停，回来时恢复。这样省电，锁屏后也不会继续响。
- 浏览器没有 Web Audio 时：建不了音频就什么都不做，不报错（有界面测试）。
- 所有音频调用都包在 `try/catch` 里，声音出错不影响游戏。

## 7. 首屏体积和流量预算

| | 首屏脚本（esbuild 压缩后、未 gzip） |
| --- | --- |
| main（e429bcd） | 392,671 B |
| 本分支 | 396,295 B（+3.6 KB） |
| 懒加载的 `ambient.ts` 分包 | 约 3.6 KB |

- `tests/earth/bundle.test.ts` 的上限还是 400 KB，这个分支没改。测试里加了一条：`ambient.ts` 不能进首屏，要在单独的分包里。
- 音频文件：0 个，网络流量为 0。环境音和音乐全是现场合成的，一直开着也不会再下载东西。
- 并行分支里有几个把上限提到了 410–420 KB。这个分支只加 3.6 KB；合并时取最大的上限，再重新测一次。

**以后如果要用音频文件**（提议，现在不需要）：

- 只用懒加载：玩家打开对应开关后再下载。
- 格式用 Opus 或 AAC，单个文件不超过 60 KB，循环素材不超过 15 秒。
- 走 Service Worker 缓存。

## 8. 素材来源和许可

**【v37 已落地】** 所有声音都是程序合成的，仓库里没有音频文件，也不引用外部音源：

- 提示音：振荡器加包络，频率表写在 `CUES` 里。
- 环境音：滤波后的白噪声，配方写在 `BEDS` 里。
- 音乐：和弦进行和五声音阶的点缀音，写在 `MOODS_DEF`、`PENTA` 里。

这些和弦进行（I–vi–IV–V 一类）是通用的和声常识，不是哪首曲子的旋律。

**规则**（以后加素材时照着做）：

1. 优先用程序合成。
2. 必须用录音素材时，只用可商用、无需署名或署名要求明确的许可：CC0 优先，其次 CC-BY 4.0。不用 CC-BY-NC、CC-BY-ND，也不用「仅个人使用」的素材。
3. 每个素材在 `public/earth/audio/manifest.json`（到时候新建）里登记这几项：
   - 文件名；
   - 出处 URL；
   - 作者；
   - 许可证；
   - 下载日期；
   - 改动说明（裁剪、降噪、转码）。

   和 `public/earth/cgi/manifest.json` 一样，加测试检查每个文件都登记了。
4. 不用任何现有游戏的音乐、音效或可识别的标志性声音，也不做「听起来像某某游戏」的仿制。
5. 不用真人可识别的声音片段。

## 9. 和其他分支的接口

- **入境卡 `claude/earth-start-ui`**：提交入境卡时有盖章动画。`stamp` 提示音已经在 `CUES` 里了。合并后在盖章动画开始时调用 `sfx('stamp')` 就行。
  - 创建页这时还没有 `state`，但 `sfx` 不依赖 `state`。
  - 点「提交」本身就是用户操作，满足自动播放限制。
  - 音效开关默认关，所以新玩家第一次开局听不到。如果想让盖章默认响，需要另外定：例如创建页单独放一个「开声音」按钮。这是**提议**，没做。
- **天气 `claude/earth-weather`**：新加了 `cold` 天气。`ambienceFor`、`cueAfter` 对不认识的天气都按地点或普通到达处理，不用改。将来要给寒潮配声音，可以在 `BEDS` 里加一个 `cold` 配方，比如高通的冷风。
- **节日 `claude/earth-live-social`**：节日音乐用的是 `festivalsSoon(clock, loc).here`。那个分支如果改了节日的判断方式，这里会跟着走。
- **主界面 `claude/earth-main-ui`**：这个分支只在「我 · 设置 · 显示」卡里加了行，在 `click` 处理里加了两行。主界面如果改了设置页布局，合并时注意保留 `onOff(...)` 和 `seg('volume', ...)`。

## 10. 无障碍

- 声音默认全关。所有声音传达的信息都有文字或画面：
  - 失败有 toast；
  - 事件有弹窗；
  - 成就有提示；
  - 升级有名牌进度环；
  - 到达有地点页；
  - 天气有图标和文字。
- 设置页写明了「重要的事都有文字提示，不开声音不会错过」。
- 不用声音做倒计时或催促，没有「只听声音才能完成」的玩法。
- 音量偏轻，没有突然的大声。所有音都有起音和淡入淡出，没有爆音；没有高于 2 kHz 的提示音。
- 开关按钮带 `aria-pressed`，音量是有 `aria-label` 的按钮组，通过 `a11yIssues` 检查。
- 系统的「减少动态效果」不影响声音，两者是独立的设置。**【提议】** 系统开了「减少动态效果」时，第一次打开环境音或音乐前提示一句。
