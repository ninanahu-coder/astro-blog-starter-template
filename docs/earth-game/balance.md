# 数值平衡：第一轮

用 `npm run earth:sim` 让 5 类机器人玩家各玩 60 个游戏日、每类 100 个随机种子，走的是服务器同一个结算入口 `applyAction()`。原始数据见 [balance-report.md](balance-report.md)（脚本自动生成，每次调数值后重跑覆盖）。

## 机器人策略

| 策略 | 出身 / 特质 | 做什么 |
| --- | --- | --- |
| 咖啡店上班族 | 留学生 / 自来熟、爱干净 | 珀斯咖啡店上班，租合租房间 |
| 救生员 | 冲浪手 / 水性好、运动健将 | 珀斯海滩救生队上班，租一居室公寓 |
| 矿工 | 矿区轮班工 / 运动健将、皮糙肉厚 | 去卡尔古利当矿工，租合租房间 |
| 打零工的背包客 | 背包客 / 独行侠、精打细算 | 不找正式工作，没钱了打零工，到处走，露营 |
| 什么都不干（对照组） | 背包客 / 无 | 不工作，只吃饭睡觉 |

所有机器人都会：饿了吃饭、累了睡觉、脏了洗澡、无聊了去玩、孤单了找 NPC 聊天；事件一律选第一个选项。

## 发现的问题和改动

| # | 发现 | 原因 | 改动 |
| --- | --- | --- | --- |
| 1 | 能力 15–30 天就满 100，之后检定、升职要求、装备加成全部失效 | 每次成长是固定值，没有递减 | 能力增长 = 原值 × 特质倍率 × 0.35 × (1 − 当前值/110)。主要能力 60 天到 64–83 |
| 2 | 矿工 60 天赚 $33,504，是其他职业的 3–4 倍 | 矿工每班 $480，远高于其他职业 | 矿工工资 $480/$640/$820 → $300/$380/$470。按小时算现在和其他职业持平（$32–34/小时），矿工多赚是因为班更长、心情更差 |
| 3 | 有钱人晕倒一次损失极大（$17,000 → 一次扣 $3,400） | 医药费是现金的 20% | 医药费 = $100 + 现金的 10%，最多 $500 |
| 4 | 在卡尔古利晕倒被送到 600 公里外的珀斯，之后再也回不去上班 | 全地图只有珀斯有医院 | 卡尔古利、杰拉尔顿、奥尔巴尼、黑德兰港、布鲁姆加医院；晕倒送最近的医院 |
| 5 | 没钱的人 60 天晕倒 8–13 次，陷入死循环 | 城市里没钱就没有任何吃东西的办法 | 加慈善午餐（12–13 点）和慈善晚餐（18–19 点），城市 / 港口 / 城镇免费，各 +50 饱食 |
| 6 | 没有“等一会儿”的办法，想等开工只能睡 8 小时，常常睡过上班时间 | 最短的通用动作是 8 小时露营 | 加“歇一会儿”：任何地方都能做，1 小时，精力 +4 |
| 7 | 表现检定形同虚设，100 个种子工资完全一样 | 难度太低 | 难度 35/50/65 → 55/70/85（配合 #1 才真正生效） |
| 8 | 两周就升到最高级 | 每级只要 5 个班 | 每级 8 个班、其中 5 个表现好 |

## 调整后的结果（60 天，100 个种子，中位数）

| 策略 | 第 30 天现金 | 第 60 天现金 | 日均净收入 | 平均心情 | 晕倒 | 破产天数 |
| --- | --- | --- | --- | --- | --- | --- |
| 咖啡店上班族 | $4,442 | $8,218 | +$117 | 45 | 0 | 0% |
| 救生员 | $5,383 | $10,967 | +$170 | 47 | 0 | 0% |
| 矿工 | $10,440 | $19,200 | +$281 | 20 | 0 | 0% |
| 打零工的背包客 | $357 | $354 | −$6 | 36 | 1.9 | 21% |
| 什么都不干 | $3 | $3 | −$10 | 33 | 0 | 68% |

我对这组结果的判断：

- **有正式工作就能稳定攒钱，没工作只能勉强糊口**，这个梯度是对的。
- **矿工多赚一倍，代价是心情长期低落（20，“低落”档，所有检定 −10）**，算是合理的取舍。
- **没钱不会再死循环**：对照组 68% 的日子身无分文，但靠慈善餐不再晕倒。
- **打零工是困难模式**，偶尔晕倒，属于预期。

## 还没解决的问题

1. **钱没地方花。** 上班族 60 天攒下 $8,000–19,000，除了买车（$4,500 / $12,000）和房租，几乎没有花钱的地方。需要加消费：买房、家具、更好的装备、旅行套餐、投资。这是内容问题，不是调参能解决的。
2. **第二次升职卡在声望上。** 店长要声望 25、救生队长要 30，只上班不探索的人拿不到。这是有意的设计（逼玩家出去探索），但要在界面上说清楚。
3. **矿工升不了职。** 设备操作员要驾驶 25，矿区出身的人只有 15，不开车就练不上去。可以考虑在矿场工作本身加一点驾驶成长。
4. **心情普遍偏低（33–47，“一般”）。** 上班族的心情也只有 45，可能需要更多便宜的娱乐方式，或者降低娱乐、社交的衰减速度。
5. **机器人策略很简单**：事件永远选第一项，不买车，不追求声望。真实玩家的数字会更分散。

## 第二轮：消费系统阶段 A 上线后

机器人学会了花钱：升职卡在能力上就去上课，现金超过 $2,500 时做当地没做过的体验，超过 $7,000 时买车；有工作的机器人每周休一天。

| 策略 | 第 60 天现金 | 第 60 天净资产（含车） | 和第一轮比 |
| --- | --- | --- | --- |
| 咖啡店上班族 | $6,197 | $9,095 | 现金少约 $2,000（课程、体验、休息日） |
| 救生员 | $3,314 | $6,278 | 买了车，现金少约 $7,600 |
| 矿工 | $16,693 | $17,103 | 用休息日上驾校，第 43 天升职（第一轮从不升职） |
| 打零工的背包客 | $354 | $351 | 不变 |
| 什么都不干 | $3 | $3 | 不变 |

结论：

- **钱开始有去处**，低收入玩家不受影响。
- **矿工升不了职的问题解决了**：上驾校练到驾驶 25 就能升。
- **收藏数偏低**（中位 0–1 个），因为上班的机器人很少离开工作地点。体验系统本来就是为出门旅行的玩家准备的，真实玩家的数字会高得多。
- 现金仍在堆积（上班族第 60 天还剩 $6,000，矿工 $16,000），需要阶段 B、C（家具、房产）继续吸收。

## 怎么重跑

```bash
npm run earth:sim                              # 60 天 × 40 个种子，结果打印在终端
npm run earth:sim -- --days=120 --runs=100     # 更长、更稳
npm run earth:sim -- --runs=100 --out=docs/earth-game/balance-report.md
```

改数值时，先跑一遍记下基线，改完再跑一遍对比。数值集中在 `src/game/data/`（工资、房租、互动、物品）和 `src/game/core/engine.ts` 顶部的常量（需求衰减、医药费、能力成长）。
