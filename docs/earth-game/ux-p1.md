# 体验改造 P1：今天页三层、反馈组合、点击区和字号

依据：体检和方案见 `~/Documents/Playground/earth-ux/地球人生-体验改造方案.md`（在线版 https://claude.ai/artifact/7MHptU4289VgbYBTdYXatF）。2026-11-21 用户定的两条：先合完第一批 26 个分支再做 P1；商店移出今天页，改成抽屉。

## 1. 今天页分三层

| 层 | 内容 | 形式 |
| --- | --- | --- |
| 现在 | 回流卡片、状态环、「刚才」、下一步、心愿、快捷动作、周结算预警、排队、昨天回顾、新手指南、新出现的功能 | 一直展开 |
| 在这里 | 真实定位打卡（直接点），以及按组的一行摘要：做事、买东西、工作、住处、这里的人、体验和爱好、学习、车和房产、宠物、地点 | 点摘要行从底部弹出抽屉，内容和以前那张卡一样 |
| 以后 | 主线（默认收起）、现实里的节日和假期、节日、之后会出现 | 收着 |

- 「做事」抽屉里，能做的排在上面；没开门、钱不够这类做不了的事收进「稍后开门或现在做不了 · N 项」。
- 商店整个挪进「买东西」抽屉。
- 地点卡（主视觉、简介、天气预报、气候）和打卡点、小知识、留言板挪进「地点」抽屉。地点名和天气在顶栏已经有了。
- 渐进出现（v36）照旧包住同样几组：钓鱼、摄影和星空在「体验和爱好」里，课程、证书、学历在「学习」里，车行、修车厂和房产在「车和房产」里，没解开的组不出现摘要行。
- 摘要行只在这一组有内容时出现。

### 抽屉

- 借用事件用的底部弹窗 `#modal`：没有待处理事件、也没有事件结果页时才画抽屉；有事件时事件优先。
- `role="dialog"`、`aria-modal`、`aria-labelledby` 指向抽屉标题；打开时焦点放到「关闭」上，背后的页面 `inert`。
- 关法：「关闭」按钮、Esc、点遮罩、切标签。关上后焦点回到打开它的那一行。
- 在抽屉里做成一件事后自动收起，让玩家看到状态环的变化；「买东西」除外，可以连着买。
- 抽屉开着时，今天页重画（留言后到、后台同步）会跟着重画抽屉，不抢焦点。
- 抽屉名先核对在 `placeGroups` 里（`Object.hasOwn`），原型链上的名字打不开；统计只记组名（白名单 `drawer`）。

## 2. 反馈组合

| 发生了什么 | 画面 | 声音 | 震动 | 文字 |
| --- | --- | --- | --- | --- |
| 做成一件事 | 变了的需求环跳一下、飘出 +N/−N，数字从旧值滚到新值（500ms）；状态环下面出现「刚才」：结果一句话和变化小签 | 按结果挑一声（v37 的 `cueAfter`） | 10ms | 提示条 |
| 钱变了 | 顶栏钱数跳一下、飘出 +$N/−$N | 同上 | 同上 | 同上 |
| 没做成 | 提示条变成警示色并左右轻摇 | `fail` | 12-50-12ms | 写明原因 |

- 读屏：变了的环 `aria-label` 写「刚才加了 N」；飘字 `aria-hidden`。
- 「减少动态效果」时所有动画关掉，也不震。
- 震动走 `navigator.vibrate`：只有安卓浏览器有，iPhone Safari 没有这个接口。设置里有「震动」开关，默认开（`Prefs.haptic`）。

## 3. 点击区、字号、便签

- 进游戏后的 CSS 字号最小 12px（底部标签栏原来是 11px）。例外：开场入境卡（另有设计语言）、地图和印章里的 SVG 文字（随画面缩放）、读屏跳过的装饰性英文小标签（NEXT、地名英文）。测试 `tests/earth/ux-p1.test.ts` 守住。
- 顶栏心情胶囊、真实地图上的地点标记，点击区补到 44px（心情胶囊用负外边距抵掉多出的高度，顶栏高度不变）。
- 页面有新手便签时不放装饰横幅，第一屏留给便签和内容。

## 6. 多角度复核（2026-11-21）

四个角度（正确性、无障碍、安全、和本文对照）各一名审查员只读审查，每条问题再单独找人反驳一遍。14 条全部成立（有重复），已修：

- 地点短片挪进抽屉后不播放：`wireClips` 也接上抽屉里的视频。
- 商店抽屉买完一件跳回顶部、焦点丢失：同一个抽屉重画时放回滚动位置和按钮焦点。
- 每次画今天页都去拉留言板，留言到了再重画，冲掉刚出现的环和钱数动画：只在「地点」抽屉打开时拉、打开时重画。
- 别的页做的事、后台同步换了存档，回今天页时还飘「刚才」：换页和同步时清掉。
- 减少动态效果时飘字不淡出、一直挂着：直接不显示（读屏和「刚才」一栏照样有变化）。
- 顶栏英文地名并没有对读屏隐藏，字号豁免的前提不成立：加 `aria-hidden`。
- 事件结果页开着时 Esc、点遮罩关的是后面的抽屉：结果页优先。
- 「新出现」便签和节日卡还指向旧位置：改成「在这里 · 体验和爱好 / 学习 / 车和房产」。
- 「车和房产」把自己的房算在售、「做事」没算在车里睡：已改。

这些行为大多在测试用的假页面里测不到（视频、滚动、真实焦点），`tests/earth/ux-p1.test.ts` 用代码断言守住，每条都做过变异检查。
