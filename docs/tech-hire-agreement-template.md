# 技术人员聘用协议模板（创始人保护版）
## YNG LAB 盈扬工作室 · 供执业律师定稿用底稿

> ⚠️ **使用说明**：本文件是谈判与起草底稿，不是法律意见。签署前必须由 WA 执业律师定稿；
> Fair Work Act 的 NES（National Employment Standards）是强制底线，任何低于底线的条款自动无效。
> 本模板的策略：**每一条都取「可执行范围内对公司最有利」的位置**——过狠的条款会被法院整条剔除，反而失去保护。

---

## 总体结构：两阶段（这是第一层保护）

```
阶段一：独立承包商试用（3 个月）→ 不合适：7 天通知走人，零股份零纠纷
阶段二：正式雇佣 + ESOP 期权    → 合适：才谈股份，且全部带 vesting
```

**为什么这样最大化创始人利益**：股份谈判发生在你已经看过他 3 个月真实产出之后，
信息优势完全在你这边；试用期内他没有任何股权请求权。

---

## 阶段一 · 独立承包商协议（Contractor Agreement）要点

| 条款 | 内容 | 保护点 |
|---|---|---|
| 服务范围 | 附件 A 列明交付物（如：数据库 v2 模块、订阅计费集成），按周验收 | 按交付物验收，不养人 |
| 报酬 | A$__/小时，凭发票（ABN）月结；封顶 __ 小时/月 | 封顶控预算 |
| 期限与终止 | 3 个月固定期；任一方 **7 天书面通知**可终止，无补偿 | 随时止损 |
| 股份 | **本阶段无任何股权、期权或其承诺** | 白纸黑字排除口头承诺 |
| IP | 所有工作成果自创作时即转让给公司（present assignment），含源码、文档、模型配置、prompt | 即时归属，不等付款 |
| 保密 | 无限期；含客户名单、bot token、数据库结构、定价 | 无限期是保密条款的合法上限 |
| 注意 | 若其主要以个人劳务计酬，法律上仍可能需付 super——让会计师核一次 | 避免事后被追缴 |

## 阶段二 · 雇佣合同（Employment Agreement）逐条

### 1. 职位与职责
- 职位：后端 / 数据工程师；职责见附件（数据库 v2、私有化交付包、订阅计费、bot 网关维护）
- **公司可随业务需要合理调整职责与汇报线**（写入这句，重组时不构成变相解雇）

### 2. 薪酬（现金侧压到市场 7–8 折，差额用期权补）
- 基本工资：A$______ /年 + superannuation（法定比例）
- **薪资已包含合理的额外工时**（reasonable additional hours）——技术岗标准写法，避免加班费争议
- 调薪：**由公司酌情决定**（at the Company's discretion）；无保证奖金、无保证调薪
- 任何奖金计划均为酌情性质，不构成合同权利

### 3. 试用期
- **6 个月**（Fair Work 允许的小企业上限内）；试用期内通知期 1 周
- 试用期内不授予任何期权（期权授予日期 = 转正日，见第 5 条 cliff 起算）

### 4. 期权条款（整份合同的核心，逐条都是创始人保护）

| 条款 | 设置 | 为什么这样写 |
|---|---|---|
| 工具 | **ESOP 期权**，不是直接给股 | 行权前无股东权利：不能看账、不能投票、不进股东名册 |
| 数量 | ____%（fully diluted 口径，从 10% ESOP 池内出） | 池内授予不稀释创始人谈好的结构 |
| 行权价 | 授予日公允价值（用 ATO ESS startup 安全港估值） | 员工享税收递延，公司不担税务风险 |
| **Vesting** | **4 年 + 12 个月 cliff**，cliff 后按月 | 干不满 1 年 = 0 |
| **里程碑混合 vesting** | 50% 按时间、**50% 按里程碑**（数据库 v2 验收上线 / 私有化交付包首单交付 / 订阅计费系统上线，是否达成由董事会认定） | 时间混不出股份，必须交东西 |
| 未成熟期权 | 离职即全部作废 | 标准且必须 |
| **Good / Bad Leaver** | Bad leaver（有因解雇、违反限制条款、**入职 24 个月内主动离职**）：已成熟期权由公司按「行权成本与公允价孰低」回购或作废。Good leaver：保留已成熟，离职后 **90 天行权窗**，逾期作废 | 最强的一条：早走的人带不走股份 |
| 行权时点 | 可选「**仅退出事件可行权**」（exit-only）：只有公司出售/IPO 时才能行权 | 创始人最大化选项——中途没有小股东 |
| 控制权变更 | **无单触发加速**（no single-trigger acceleration） | 收购方最恨自动加速；保住卖价 |
| 行权后股份 | 自动受股东协议约束：**drag-along（拖售权）** + 创始人 **ROFR（优先购买权）** + 禁止向第三方转让 | 就算行权了，股份也走不出你的控制 |
| 回购权 | 公司对已行权股份保留回购选择权（离职后 12 个月内，公允价） | 清理 cap table 的后门 |

### 5. 知识产权（第二核心）
- **在职期间创作的、与公司业务相关或使用公司资源产生的一切成果自动归公司**——源码、架构、prompt、模型配置、数据库 schema、文档、客户资料
- 签署 **moral rights 同意书**（同意公司修改、不署名使用其作品）
- 入职时书面申报既有个人项目（附件 B）；未申报的视为无保留
- 离职交接清单：源码仓库权限、密钥、bot token、部署账号、文档——**交接完成是最后一笔工资支付的前提条件**（在合法扣压范围内由律师定稿）

### 6. 保密
- 无限期保密义务；明确列举：客户库、订阅名单、定价、模型编排方案、自建数据库结构、合作方（含 broker 渠道）条款

### 7. 离职后限制（restraint of trade，用阶梯式写法保证可执行）
澳洲法院只执行「保护合法商业利益所必需」的范围，所以写成**阶梯条款**（cascading）——法院可以砍长度砍范围，但不会整条作废：
- **非招揽**：离职后 [12 → 9 → 6] 个月内不得招揽公司客户、在谈客户与员工
- **非竞争**：离职后 [6 → 3] 个月内，[西澳 → Perth 都会区] 范围内不从事与公司直接竞争的 AI 获客/分析订阅业务
- 在职期间：兼职与外部项目须**事先书面批准**；不得为竞品工作

### 8. 公司财产
- GitHub 组织、云账号、API key、bot token、客户数据全部为公司财产；个人账号不得持有生产密钥

### 9. 终止
- 通知期：按 NES 最低标准（服务年限阶梯）；公司可选择支付代通知金即时生效
- 严重不当行为（serious misconduct）：即时解雇，无通知期

### 10. 其他
- 管辖法律：Western Australia；争议先调解后诉讼
- 完整协议条款（entire agreement）：**取代此前一切口头承诺**——防「当初你说过给我 X%」

## 谈判让步阶梯（你的底牌表，不给对方看）

| 项目 | 开价 | 可让到 | 绝不让 |
|---|---|---|---|
| 工资 | 市场价 70% | 市场价 80% | 超过预算线 A$110k |
| 期权 | 1% | 2%（资深且降薪多） | 3% 以上进合伙人谈判，另议 |
| Cliff | 12 个月 | 12 个月 | 取消 cliff |
| 里程碑 vesting | 50% | 30% | 全时间制 |
| Exit-only 行权 | 要 | 可放弃（换里程碑保留） | — |
| 24 个月 bad-leaver | 要 | 18 个月 | 12 个月以下 |
| 竞业 | 6 个月/WA | 3 个月/Perth | 完全取消 |

## 签署前 checklist
- [ ] WA 执业律师定稿（预算 A$1,500–3,000，含 ESOP 规则文件）
- [ ] 会计师出 ESS startup 安全港估值（行权价依据）
- [ ] ESOP 计划规则 + 股东协议（drag-along / ROFR）先于第一份期权授予存在
- [ ] Fair Work 合规复核（工资不低于相应 Award / NES）
- [ ] 试用期合同先签，正式合同在转正时签
