# eDog Australia 产品 vs 中国电商(淘宝/天猫/京东/1688)价格对比

调研日期:2026-08-31
汇率参考:1 澳元 ≈ ¥4.7 人民币;1 美元 ≈ ¥7.1 人民币

## 调研说明与方法

- 调研对象为 eDog Australia 官网(edogaustralia.com.au)在售的 12 款 Houndware / BarkTec 品牌训犬产品。
- **调研环境无法直接访问 edogaustralia.com.au、淘宝、天猫、京东、1688 的页面**(出站网络被代理拦截),因此:
  - 澳元价格主要来自 eDog 自营 eBay 店(edogaustraliastore)、同一运营方的姊妹站(Aetertek Australia、eDog NZ)、以及 BuyWisely / MyDeal / Kogan / Harvey Norman 等第三方渠道的搜索快照;
  - 人民币价格来自搜索结果快照:什么值得买(smzdm)收录的京东/天猫促销价、1688 批发页快照、供应商网(gys.cn)B2B 报价、百度百科行业价格数据等。
- 因此所有价格为**区间参考价**,非实时精确价,标"~"者尤其如此。

## 核心结论

1. **这批产品基本可确认为中国 OEM 贴牌**。两个直接证据:
   - BTU20 手持超声波训狗器在澳洲/新西兰同时以 Aetertek(中国训犬项圈代工厂品牌)名义原样销售,且 Aetertek Australia 与 eDog 为同一运营方;
   - "鸟屋"造型超声波止吠器与阿里巴巴上"factory cheap price"批售的通用 OEM 型号 CSB-19 外观规格一致(PetSafe/DOGTEK 同款壳)。
   - 已确认的 OEM 型号:BT-100(香茅喷雾项圈)、BTU20/BTU10(手持超声波)、BT-300(鸟屋止吠器)、T720(二合一遥控训犬止吠项圈)。
2. **价差极大**:止吠项圈类在 1688 批发价约 ¥10–76(约 AU$2–16),国内零售 ¥45–200,而 eDog 售价 AU$79–229(约 ¥370–1080),零售价差约 **3–10 倍**,对批发价约 **10–40 倍**。
3. 超声波类设备是最便宜的品类(1688 ¥6–118);围栏系统类 OEM 整套出厂价约 ¥200–290。
4. 香茅喷雾项圈(#4)是唯一在中国国内零售渠道很少见的品类(基本只做出口),GPS 围栏和室内无线围栏在国内也以出口为主、内销少。
