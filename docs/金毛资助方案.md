# 「陪伴延续」金毛资助方案(VIP 客户定制)

> 内部文档 · 仅供接待与客户经理参考执行

---

## 一、客户画像

| 项目 | 内容 |
|------|------|
| 基本情况 | 女性,25 岁,广东、山西混合家庭背景 |
| 经济能力 | 年收入 2 亿元以上,持有爱马仕、百达翡丽等藏品(估值数千万) |
| 情感背景 | 深爱金毛犬;爱犬近期因癌症去世,正处于哀伤期 |
| 与本店关系 | 曾在本店寄养爱犬,对狗舍环境与团队有信任基础 |
| 意向 | 已表达资助狗舍金毛的意向 |

**核心洞察:**
- 她此刻需要的不是"消费项目",而是一个**安放思念的出口**。
- 高净值、年轻、有审美的客户,反感被推销,重视**私密、定制、有仪式感**的体验。
- 资助的意义对她而言是"让爱延续",而非慈善捐款。所有方案设计与话术都应围绕**缅怀与延续**,绝不能让她感到被"盯上钱包"。

---

## 二、方案理念:以缅怀开场,以陪伴延续

整个方案分为两个自然衔接的阶段:

1. **缅怀仪式**——为她逝去的爱犬举办一场私密、庄重的追思仪式,帮助她完成情感告别。
2. **资助计划**——在仪式的尾声,自然引出"让这份爱在其他金毛身上延续"的资助方式,由她自主选择参与深度。

关键原则:**仪式是目的,资助是自然的延伸。** 即使她当天不确定资助方式,仪式本身也必须完整、真诚、不打折扣。

---

## 三、缅怀仪式设计(「金色的告别」)

### 1. 时间与场地
- 选择狗舍环境最好的时段(建议黄昏,"金色时刻"与金毛毛色呼应)。
- 场地封闭管理,当天仅接待她一位客人(可携亲友),保证私密。

### 2. 仪式流程(约 60–90 分钟)

| 环节 | 内容 |
|------|------|
| 迎接 | 客户经理一对一接待,不谈任何商业内容 |
| 追思角 | 布置爱犬生前在本店寄养时的照片、视频(提前整理寄养期间的影像存档),鲜花以金黄、奶白色系为主 |
| 纪念植树 / 纪念牌 | 在狗舍院内种一棵树或设置一块定制铜牌,刻爱犬名字与一句她选定的话,成为永久的纪念角落 |
| 与在住金毛相处 | 安排性格温和的金毛与她自然接触(不强迫、不安排"表演"),让她感受熟悉的温度 |
| 纪念信物 | 赠送定制纪念品(见下),表达狗舍的心意 |

### 3. 定制纪念品(符合其审美层次)
- 委托手工银器或珐琅工坊定制**爱犬名字吊牌 / 摆件**(质感优先,避免廉价感)。
- 精装《寄养时光》相册:整理爱犬在本店寄养期间的全部照片与工作人员手写回忆。
- 如客户保留有爱犬毛发,可代为对接**毛发封存纪念饰品**的定制渠道(仅在她主动提及时提供,不主动建议)。

## 四、资助计划:「金色守护人」

在仪式尾声,由主理人(而非销售人员)以一段话自然引出:

> "如果您愿意,我们想以 __(爱犬名字)__ 的名义,设立一份属于它的守护计划——让它的名字,继续温暖这里的每一只金毛。"

然后呈上一份印制精美的资助手册(不报价、不催促,请她带回慢慢看)。资助分三个层级,由她自主选择:

### 层级一:纪念守护(以爱犬之名的日常资助)
- 以爱犬名义认养狗舍中 1 只金毛,承担其年度食宿、护理费用。
- 被认养金毛的名牌上加注"由 __(爱犬名字)__ 守护"。
- 每月收到该金毛的照片、视频与近况手记。
- 参考额度:每年 3–5 万元。

### 层级二:年度守护人(深度参与)
- 包含层级一全部内容。
- 资助覆盖狗舍全部金毛的年度体检与疫苗。
- 每季度专属探访日:狗舍为她单独开放半天,可自由陪伴犬只。
- 狗舍年度报告中列为"年度守护人"(可匿名,尊重其隐私偏好)。
- 参考额度:每年 20–50 万元。

### 层级三:「__(爱犬名字)__ 金毛医疗基金」(与她的经历最深的呼应)
- **以她爱犬的名字设立专项基金,专门用于金毛犬癌症的早期筛查、治疗与救助**——这直接回应了她失去爱犬的原因,是三个层级中情感意义最重的一项。
- 基金用途:本店及合作救助渠道中金毛的肿瘤筛查、手术与化疗费用;条件成熟时可扩展至流浪金毛救助。
- 配套:
  - 独立账目,每季度向她提供资金使用明细与受助犬只案例报告(高净值客户极重视透明度)。
  - 每一只经基金救治的金毛,档案中记录"受 __(爱犬名字)__ 基金资助"。
  - 每年爱犬的纪念日,狗舍组织一次小型纪念活动并邀请她出席。
- 参考额度:首期 100 万元起,后续由她根据基金运转情况自主追加。

### 层级设计说明
- 三个层级**不是套餐推销,而是参与深度的选择**,手册中并列呈现,不做倾向性引导。
- 以她的财力,金额本身不是门槛;真正决定她选择的是**情感共鸣与信任感**。层级三与她的经历呼应最深,大概率是她最终的选择,但必须由她自己走到那一步。

## 五、服务与沟通规范

### 接待规范
- 全程由主理人或指定客户经理一对一对接,不换人。
- 她的家庭背景、财务信息严格保密,内部仅限必要人员知悉。
- 尊重其消费习惯与品位:接待细节(茶具、伴手礼、印刷品)保持质感,但**不攀附、不谈论她的奢侈品收藏**。

### 话术红线(务必遵守)
- ❌ 不主动提金额,不催促决定,不使用"套餐""优惠""赞助回报"等商业词汇。
- ❌ 不说"再养一只就好了"之类的话——对哀伤期的养宠人是严重冒犯。
- ❌ 不在仪式过程中谈钱;资助手册只在尾声递上,请她带回。
- ✅ 多用"守护""延续""以它的名义";倾听多于表达。
- ✅ 若她当场落泪或情绪波动,暂停流程,只陪伴,不推进任何环节。

### 后续跟进节奏
| 时间 | 动作 |
|------|------|
| 仪式后第 2 天 | 手写感谢卡寄出(不提资助) |
| 仪式后 1 周 | 客户经理发送纪念角落(树/铜牌)的照片,附一句问候 |
| 她主动回应后 | 再根据其意向推进资助细节;若两周无回应,只保持每月一次的犬只近况分享,不催促 |

## 七、预算参考(狗舍投入)

| 项目 | 预估费用 |
|------|----------|
| 仪式布置(鲜花、场地) | 3,000–5,000 元 |
| 定制纪念品(银器/珐琅 + 相册) | 8,000–15,000 元 |
| 纪念树 / 定制铜牌 | 2,000–5,000 元 |
| 资助手册设计印制 | 1,000–2,000 元 |
| **合计** | **约 1.5–2.7 万元** |

这笔投入的意义不在于换取某一笔资助,而在于与这位客户建立**长期、真诚的信任关系**——对她而言,这里将成为爱犬记忆的安放之地,也自然会成为她长期支持的地方。
