用多模型 Agent 编排（Claude / Codex / Hermes），通过 Telegram（OpenClaw 接入）交付六大服务：静态网站引流工厂、资料分析、股市分析、加密市场分析、财经时事→宏观波动解读、私人助手。

凭什么是我们

100+ 天全职实战：四套工具链跑通、自建数据库落地，且已有三类实盘业务在运行——电商、宠物垂直网站、多个 Telegram bot。不是想法，是已在赚钱路上的系统。

市场有多大

AI Agent 市场规模 2024 年约 51 亿美元，预计 2030 年达 471 亿美元，年复合增速 ~44.8%（MarketsandMarkets）。

怎么赚钱

三层收入：订阅制分析简报（TG 会员）＋ 项目制（网站工厂 / 定制 Agent）＋ 高端私有化部署（自建数据库、专属助手）。

差异化壁垒

数据私有化：客户数据存于自建加密数据库而非第三方云端 SaaS——隐私、私密、稳定，专为高质量、高客单客户设计。

PART III · 澳洲与西澳
09为什么是西澳 ②

UTC+8：Perth 与北京、香港、新加坡零时差

0 时差
AWST = UTC+8，全年无夏令时——与中国大陆、香港、新加坡完全同步；悉尼（UTC+10/11，有夏令时）反而错位 2–3 小时。
  • 金融分析业务的天然主场：A 股、港股交易时段（09:30–16:00）与 Perth 工作时间完全重合；盘前简报、盘中警报、收盘综述全部在正常工作时间交付，无需夜班。
  • 华语客户服务零摩擦：目标客户集中在 UTC+8 时区带——客户上班时我们也在线，Telegram 消息即时响应。
  • 7×24 加密市场：由 Agent 值守补齐非工作时段，人机分工清晰。
  • 对比结论：做亚洲市场的金融信息服务，Perth 是全澳时区条件最优的城市——这是地理事实，不是判断。

来源：timeanddate.com（2026）；WA 无夏令时为州法律现状。

  • 一句话建站：Codex + Claude 从行业描述直接生成整站——落地页、博客、SEO 文案、询盘表单一次到位（本企划书所在仓库即为 Astro 站点模板之一）。

① 对外是产品——向中小企业按项目 + 月维护收费；

17模块 C · 分析线

股市分析助手：机构级信息密度，订阅制价格

  • 盘前简报：隔夜全球市场、期货、宏观日历、个股要闻——开盘前 30 分钟送达 TG。
  • 持仓监控：客户自选股票池；异动、公告、评级变化实时推送并附解读。
  • 财报季引擎：财报发布后分钟级生成解读：超预期项、指引变化、电话会要点。
  • 多因子聚合：技术面信号 + 基本面变化 + 资金流向 + 舆情热度，四维打分呈现，而非单一指标噪音。

边界与合规

重要 本模块为信息与研究服务：呈现事实、数据与情景分析，不提供买卖建议、不代客操作、不承诺收益。每份简报附风险提示。合规细节见「合规与安全」页。

为什么客户付费

同等信息密度的替代品是数万美元/年的机构终端；我们以个人可负担的订阅价格，交付其中对个人交易者最实用的部分。

18模块 D · 分析线

加密市场分析：7×24 市场需要 7×24 的 Agent

  • 链上 + 场内双源：交易所行情、资金费率、未平仓量，叠加链上大额转账、巨鲸地址异动、稳定币增发。
  • 叙事追踪：Agent 持续扫描社媒与新闻，识别正在形成的板块叙事（如 RWA、AI 币、L2），量化热度变化。
  • 事件联动：与模块 E 打通——宏观事件（议息、监管、地缘）自动触发对加密资产的传导分析。
  • 个性化警报：「BTC 资金费率超过 X」「某地址转出超 Y」等条件监控，全天候值守。

为什么这是最好的切入市场

· 用户本来就活在 Telegram，转化路径为零
