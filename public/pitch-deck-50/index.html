03执行摘要

一页看懂盈扬

我们做什么

用多模型 Agent 编排（Claude / Codex / Hermes），通过 Telegram（OpenClaw 接入）交付六大服务：静态网站引流工厂、资料分析、股市分析、加密市场分析、财经时事→宏观波动解读、私人助手。

凭什么是我们

100+ 天全职实战：四套工具链跑通、自建数据库落地，且已有三类实盘业务在运行——电商、宠物垂直网站、多个 Telegram bot。不是想法，是已在赚钱路上的系统。

市场有多大

AI Agent 市场规模 2024 年约 51 亿美元，预计 2030 年达 471 亿美元，年复合增速 ~44.8%（MarketsandMarkets）。

怎么赚钱

三层收入：订阅制分析简报（TG 会员）＋ 项目制（网站工厂 / 定制 Agent）＋ 高端私有化部署（自建数据库、专属助手）。

差异化壁垒

数据私有化：客户数据存于自建加密数据库而非第三方云端 SaaS——隐私、私密、稳定，专为高质量、高客单客户设计。

本轮融资

天使轮 $80 万（条款面议，详见「融资需求」页），24–30 个月跑道。回报逻辑见「浪潮论证与回报」章节：以公开基准倒推，3–5 倍属里程碑达成情形下的保守区间。

PART I · 行业与时机
08趋势三

数据主权觉醒：客户开始为「不上云」付费

  • 监管趋严：GDPR、各地数据出境与本地化法规持续加码，企业对第三方云端 AI 服务的合规审查越来越苛刻。
  • 信任稀缺：高净值个人的持仓、交易偏好、商业往来属于最敏感数据——「你的数据存在谁的服务器上」成为成交前的第一个问题。
  • SaaS 疲劳：云端服务改价、限流、停服的案例反复发生；关键业务数据被锁在别人的产品里，是企业主的真实焦虑。

我们的回答

自建加密数据库 + 可本地部署的 Hermes 推理：

· 客户资料、对话记忆、分析档案不出我们可控的环境
· 高端客户可选完全私有化部署——数据不出客户自己的门
· 相对云端 SaaS，稳定、可控、可承诺

PART I · 行业与时机
09时间窗口

为什么是现在：四个拐点同时到来

① 能力拐点

前沿模型（Claude 等）已能稳定完成多步骤长程任务：从一句话生成整站、读完百页研报输出要点，错误率进入商用区间。

② 成本拐点

同等能力推理价格两年降逾 90%，静态网站托管（Cloudflare 等边缘平台）近乎零成本——单客户服务成本第一次低于其付费意愿。

③ 生态拐点

OpenClaw、Hermes、MCP 等开源件把「组装一个 Agent 系统」的门槛从团队级降到个人级——但窗口也意味着 12–18 个月后竞争者会涌入。

④ 需求拐点

企业获客成本逐年上涨、金融市场波动加剧、数据隐私焦虑扩散——三类客户的痛感都在变强，且互相导流。

窗口期 12–18 个月：现在融资加速，把先发的 know-how 变成数据与客户壁垒。

PART III · 澳洲与西澳
12为什么是西澳 ②

UTC+8：Perth 与北京、香港、新加坡零时差

0 时差
AWST = UTC+8，全年无夏令时——与中国大陆、香港、新加坡完全同步；悉尼（UTC+10/11，有夏令时）反而错位 2–3 小时。
  • 金融分析业务的天然主场：A 股、港股交易时段（09:30–16:00）与 Perth 工作时间完全重合；盘前简报、盘中警报、收盘综述全部在正常工作时间交付，无需夜班。
  • 华语客户服务零摩擦：目标客户集中在 UTC+8 时区带——客户上班时我们也在线，Telegram 消息即时响应。
  • 7×24 加密市场：由 Agent 值守补齐非工作时段，人机分工清晰。
  • 对比结论：做亚洲市场的金融信息服务，Perth 是全澳时区条件最优的城市——这是地理事实，不是判断。

来源：timeanddate.com（2026）；WA 无夏令时为州法律现状。

19模块 A · 获客线

静态网站生成工厂：把「建站获客」变成流水线

  • 一句话建站：Codex + Claude 从行业描述直接生成整站——落地页、博客、SEO 文案、询盘表单一次到位（本企划书所在仓库即为 Astro 站点模板之一）。

46合规与安全

合规红线与安全承诺

金融信息服务边界

· 只提供信息、数据与情景分析，不提供个股 / 币种买卖建议
· 不代客操作、不托管资金、不承诺收益

· 按客户所在司法辖区维护服务白名单，受限地区不提供加密相关服务

数据保护

· 静态与传输全程加密，客户数据分区隔离
· 最小化收集，支持「一键导出 + 彻底删除」
· 客户数据不用于外部模型训练
· 对齐 GDPR 等目标市场数据法规要求

内容与营销合规

· 站群内容标注 AI 生成属性（按辖区要求）
· 不做夸大收益类广告素材
· 潜客研究仅用公开与授权数据

安全工程

· 密钥与凭证隔离管理，最小权限原则
· 本地 + 异地加密备份，恢复演练常态化
· 融资后引入第三方渗透测试与年度安全审计
