刚出生的幼犬看不见、听不见、不能自己调节体温、不能自主排泄——它们的生命完全依赖母犬和照护者。本手册面向 FluffyWA 幼犬区(K4)员工,按周龄给出从出生到 8 周的日常护理操作,数据基于兽医权威来源(**Merck 兽医手册、AKC、WSAVA、AAHA、AVSAB、CAPC、Royal Canin 学院、Cornell/UF 收容医学**)整理,与《提高幼犬存活率方案》配套使用:该方案讲"为什么",本手册讲"每天怎么做"。

> **重要免责**:本手册中的温度、喂量、体重等数值为通用参考,**任何临床处置决定必须经监管兽医确认**。新生幼犬病情可在数小时内恶化——存疑时立即联系兽医,不要观望。

## 一、出生头 24 小时:最关键的一天

**出生后立即(通常由母犬完成,人工仅在母犬不做时介入):**

1. 确认每只幼犬**呼吸道通畅**:母犬会舔破胎膜并舔干幼犬;若母犬不处理,立即撕开口鼻处胎膜,用干净毛巾轻擦口鼻、擦干全身并刺激呼吸。**切勿把幼犬"甩"出羊水**(甩头动作有脑出血风险),用毛巾包裹上下轻擦即可
2. 脐带由母犬咬断即可;人工处理时在离腹部约 2–3 cm 处结扎剪断,碘伏(聚维酮碘)消毒断端
3. 让每只幼犬**尽快吃到初乳**——初乳富含 IgG 抗体,肠道吸收在出生后 **4 小时达峰,12–16 小时后基本停止,约 24 小时"肠道关闭"**(Merck),**头 12 小时是硬窗口**
4. 检查每只幼犬:口鼻(有无腭裂)、四肢、肛门、脐部;记录性别、毛色标记
5. **出生后 12 小时、24 小时各称重一次**,建立每只幼犬的体重档案

**新生幼犬正常生理参考(AKC / Merck,偏离要报告):**

| 指标 | 第 1 周新生犬 |
| --- | --- |
| 直肠体温 | **35.0–36.7°C**(成犬标准下偏低,但对新生犬正常);2–3 周升到 37–38°C |
| 心率 | **> 200 次/分** |
| 呼吸 | **约 15–35 次/分** |
| 睡眠占比 | 约 **90%**(其余时间吃奶) |

**同时照看母犬**:确认胎盘数量与幼犬数量对应(滞留胎盘会引发子宫感染),提供水和食物,产后 24–48 小时内由兽医检查一次。

## 二、保温:第一杀手是低体温

幼犬约 **4 周龄前不能自我调节体温**(Merck)。产箱一角放加热垫或加热灯(**只覆盖约一半面积**,让母犬和幼犬能自行离开热源),避免直吹风。

**环境温度(按日龄,AKC / Merck):**

| 日龄 | 产箱环境温度 |
| --- | --- |
| 第 1–4 天 | **29.4–32.2°C** |
| 第 7–10 天 | 逐步降到 **约 26.7°C** |
| 第 4 周末 | **约 22.2°C** |

- 健康幼犬安静聚堆睡;**四散趴开=太热,挤成一团尖叫、爬到热源上=太冷**
- **核心体温低于 35°C** 会导致心率下降、吸吮反射消失、肠道停摆——低温、低血糖、脱水三者互相叠加,即典型的"衰弱幼犬综合征(fading puppy)"
- **绝不给发凉的幼犬喂奶**:低体温会让肠道停摆,奶水滞留发酵 → 反流误吸致命。先用 30–60 分钟**缓慢**复温(贴身包裹、温水袋隔毛巾;过快复温会加重脱水),等幼犬温暖、有吸吮反射再喂

## 三、喂养:母乳优先,人工喂养按规程

**母乳哺育(默认方式):**

- 头 2 周幼犬每天大部分时间在吃奶和睡觉;确认**每只**幼犬都能占到奶头,弱小的要人工放到后排出奶多的奶头上
- 吃饱的幼犬安静入睡;**持续哭叫、到处乱拱=没吃够**,查母犬奶量并考虑补喂
- 每天检查母犬乳腺:红肿、发硬、发热、奶水变色(乳腺炎信号)立即报兽医

**人工喂养(孤儿犬或母乳不足时补喂,参考 Merck / Royal Canin):**

- 只用**犬用代乳粉**(如 Esbilac),按说明冲调,喂前温到约 **38°C**,滴在手腕内侧不烫为准;**绝不用牛奶**(蛋白/脂肪/乳糖比例不对,会致腹泻)
- 参考量:每天约 **30ml / 100g 体重**,分次喂;能量需求约每天 **15–25 kcal / 100g 体重**(随日龄增加),以代乳粉说明和体重增长曲线为准校正
- 频率:**第 1 周每 2–3 小时一次(含夜间)**,第 2 周每 3–4 小时,第 3 周起每 4–6 小时——对应自然哺乳每天 8–10 次,核心目的是防低血糖
- 姿势:幼犬**俯卧、头略抬**(模仿自然吃奶姿势),绝不仰面喂——会呛入气管
- 奶嘴孔大小以倒置缓慢滴出为准;喂后轻拍背部帮助排气
- 冲调好的奶冷藏不超过 24 小时,喂剩的弃掉

**低血糖防控**:新生幼犬几乎没有糖原储备,不进食约 24 小时肝糖就耗尽(病弱犬更快)。参考血糖:正常约 **90–200 mg/dL**(以兽医判断为准)。信号:虚弱、发抖、持续哭叫、身体发凉、瘫软。预防靠**勤喂 + 保温**,不靠事后抢救。

## 四、排泄刺激:头 3 周不能自主排泄

3 周龄前幼犬**不能自主排尿排便**,靠母犬舔舐刺激。母犬带的幼犬无需干预;**孤儿或母犬忽视的幼犬,每次喂奶前后用温水浸湿的棉球/软布轻擦肛门和会阴部**,直到排出尿便,并记录:

- **正常尿液**:淡黄、量足;深黄/橙色、量少 = 脱水信号
- **正常大便**:黄棕色、成形软便;水样、绿色、带血或超过 24 小时无便 = 报兽医

## 五、称重与发育里程碑:每天一杆秤

**体重是最灵敏的预警指标**,下降往往先于其他症状(AKC)。

- **每天同一时间用克秤称重**,记录到每犬档案,至少持续头 3 周
- 正常增重:**每天约为出生体重的 5–10%**;出生体重应在 **7–10 天翻倍**
- **红旗:任何体重下降(尤其 >4%)或连续 2 天停滞**,当天报告并查找原因(占不到奶头?母犬奶量?环境温度?)

**发育里程碑(AKC / Merck,偏离过多要报告):**

| 周龄 | 里程碑 |
| --- | --- |
| 第 1–2 周 | 闭眼闭耳,只会爬;睡眠约 90% |
| 第 2 周 | **眼睛睁开(10–14 天)**,耳道随后打开(14–18 天) |
| 第 3 周 | 开始站立、走路、乳牙萌出;能自主排泄和调温(仍需辅助) |
| 第 4 周 | 走稳、互相玩耍、开始对声音和人有明显反应 |
| 第 5–8 周 | 断奶完成、疫苗启动、社会化黄金期全面展开 |

## 六、产箱与卫生:干净但不过度打扰

- 产箱垫料(毛巾/尿垫)**每天更换**,脏污随时换;换下的垫料按幼犬区洗涤规程高温洗涤
- 头 2 周尽量减少无关人员接触;**进出幼犬区前后洗手并更换/消毒鞋底**——细小病毒防控从第一天开始(详见《提高幼犬存活率方案》)
- **育婴区消毒剂选择(细小防控关键)**:幼犬周围日常用**氯己定(洗必泰)**温和清洁,但注意**氯己定杀不死细小**;需要杀细小时(空箱周转、暴露后)先彻底清洁去有机物,再用**漂白剂 1:32、停留 ≥10 分钟**或**加速过氧化氢**,消毒后**充分通风、冲净晾干**再放回幼犬——避免漂白剂/酚类气味在新生犬周围聚集
- 产箱每周至少一次彻底清洁消毒(把母犬幼犬移出,消毒剂按幼犬区清洁 SOP,干透再放回)
- 未完成免疫前,幼犬**不接触外来犬只、不去公共犬活动区**

## 七、驱虫与免疫时间表

以兽医制定的方案为准,通用参考(与《提高幼犬存活率方案》一致):

| 项目 | 时间 | 依据 |
| --- | --- | --- |
| 驱虫(蛔虫/钩虫,经胎盘与母乳传播,无症状也要驱) | **2、4、6、8 周龄各一次**,之后每月一次到 6 月龄 | CAPC / AAHA |
| 首针核心疫苗(DHPP:细小/犬瘟等联苗) | **6–8 周龄开始** | AAHA / WSAVA |
| 加强针 | 每 2–4 周一针,**末针 ≥16 周龄** | AAHA / WSAVA 2024 |
| 保护起效 | **末针后约 1–2 周**才算真正受保护 | — |
| 母犬 | 与幼犬同步驱虫(哺乳期用药遵兽医) | — |

> **易感窗口**:母源抗体每约 10 天减半,通常 8–12 周(部分幼犬到 16 周)降到既不足保护、又干扰疫苗的水平——这就是为什么要打**一系列**苗、半程幼犬仍有真实风险。

## 八、断奶与早期社会化

**断奶(3–8 周,循序渐进,Royal Canin):**

- **3–4 周**:浅盘提供温水调成糊状的幼犬粮(可混代乳粉),每天 3–4 次,让幼犬自由舔食;母乳继续
- **5–6 周**:糊状逐步变稠、减少加水;幼犬粮为主、母乳为辅
- **7–8 周**:完全过渡到泡软/干幼犬粮,常备清水;**不早于 8 周离开母犬和同窝**

**早期社会化(出生第 3 天就开始):**

- 第 1–2 周:每天每只幼犬**轻柔上手 1–2 次、每次几分钟**(称重即是机会),让它们熟悉人的气味和触摸
- 第 3–4 周起:引入日常声音(轻放的收音机、走动、器具声)、不同质地的垫料和安全玩具
- 第 5–8 周:每天与人正面互动,接触不同的人(戴帽、男女声)、短时单独相处练习
- **AVSAB 立场**:社会化关键窗口约 **3–14 周**,错过会造成终身恐惧/攻击;行为问题(而非传染病)是 3 岁以下犬只头号死因,所以社会化**不应**等疫苗全程打完——在**打过一针满 7 天 + 首次驱虫**后,即可对**已知健康/已免疫的犬、消毒过的地面**做可控接触
- 原则:**一切以幼犬自愿、正面为准**,出现躲避、尖叫就退一步放慢

## 九、母犬产后护理

母犬状态直接决定整窝幼犬存活。每天检查并记录:

- **食欲与饮水**:哺乳期食量可达平时 2–3 倍,自由采食幼犬粮配方、常备清水
- **恶露**:产后数周内暗红/棕绿色无臭属正常;**脓性、恶臭、鲜红大量出血 = 立即报兽医**(子宫感染/子宫蓄脓)
- **乳腺**:每天触摸,红肿硬热痛、奶水带血或变色 = 乳腺炎,报兽医
- **产后子痫(低血钙)红旗**:烦躁、喘、走路僵硬、发抖、抽搐——**急诊级别**,多见于产后 1–4 周的**小型犬**(WSAVA / Merck)
- 母犬拒绝照顾幼犬、频繁离开产箱、对幼犬粗暴:报告主管,评估是否转人工喂养

## 十、红旗信号速查:见一条,报一条

以下任何一条,**立即报告并联系兽医**,不要等下一班:

- 体重下降(尤其 >4%)或连续不增重
- 摸起来发凉、瘫软、吸吮无力或不找奶头
- 持续哭叫超过一顿奶的间隔
- 腹泻(尤其带血/发臭)、呕吐、腹胀
- 呼吸费力、张口呼吸、鼻腔奶水(呛奶)、牙龈发白/发紫
- 脱水迹象(牙龈发黏、皮肤回弹慢、尿少色深)
- 脐部红肿流脓
- 发抖、抽搐、惊厥(低血糖/低体温)
- 与同窝明显分离、被母犬推出窝外的幼犬(母犬常最先察觉病弱)

## 每日护理速查清单(K4 育婴区)

- [ ] 环境温度按日龄达标(第 1–4 天 29–32°C);观察幼犬睡姿判断冷热
- [ ] 受凉幼犬先复温 30–60 分钟再喂,**绝不喂冷幼犬**
- [ ] 确认每只幼犬头 12 小时吃到初乳
- [ ] 孤儿用犬用代乳粉,喂前温到 38°C,第 1 周每 2–3 小时一次(含夜间)
- [ ] 头 3 周孤儿犬每餐前后刺激排泄,记录尿便
- [ ] **每天同一时间称重**,红旗:不增重 / 掉重 >4% → 找兽医
- [ ] 垫料每天换、脏即换;进出育婴区洗手换/消毒鞋底
- [ ] 驱虫 2/4/6/8 周;免疫 6–8 周起每 2–4 周一针、末针 ≥16 周
- [ ] 社会化打过一针满 7 天 + 首次驱虫后开始,只接触健康已免疫犬
- [ ] 母犬每天查食欲、恶露、乳腺;子痫征兆按急诊处理
- [ ] 红旗信号表张贴在育婴区墙上,存疑即打电话
