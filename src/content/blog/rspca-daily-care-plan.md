适合四间狗舍(K1–K4,约 160 成犬 + 15 幼犬)每天运营的一份安全、稳定的基础方案,把"福利 + 防疫 + 合规"落到每天可执行的动作上。每条标注依据来源:**【RSPCA】** RSPCA 建议 · **【NSW准则】** NSW Code of Practice No 5 · **【维州准则】** 维州寄养准则 · **【收容医学】** 行业最佳实践(非法规) · **【须核对当地】** 以所在 council 犬舍执照为准。

> **两条必须先说清的合规前提:**
>
> ① **WA 没有专门的寄养犬舍强制准则**——WA 走《动物福利法 2002》+ 各**地方 council 的「Kennel Establishment Licence(犬舍执照)」条件**,那才是对四个场地有法律约束力的规则,**每个场地须单独核对所在 council 的执照条件**,它优先于本方案。RSPCA 本身不发 WA 专项标准,而是指向 Five Domains 与各州准则。
>
> ② 本方案具体数字来自对 NSW COP No 5、维州寄养准则、RSPCA 知识库的检索整理;正式写进 SOP 前**请以官方原文核对**。标【收容医学】的条目是行业通行做法,**非 RSPCA 或澳洲法规的强制要求**。

## 一、清洁与消毒

### 频率(硬性节奏)

- **犬舍及活动区每天清洁至少一次**【NSW准则】【维州准则】——冲洗、清粪、换垫料、洗食盆水盆
- **每周至少消毒一次**;此外**新犬入住前、疫情爆发后必须消毒**【NSW准则】
- **换客时做终末深度清洁消毒**【RSPCA】【收容医学】
- 粪尿**随见随清**,不等固定时段【收容医学】

### 正确流程:先清洁,再消毒

- **先用热水 + 清洁剂把有机污物彻底洗净,再消毒**——有机物会让消毒剂失效【收容医学】
- 给够**停留时间**(按产品标签),再冲净、晾干
- 消毒剂"按适用性、安全性、有效性选择"【NSW准则】

### 消毒剂与病原(关键)

- **季铵盐(quats)对犬细小病毒不可靠**;杀细小用**加速过氧化氢**,或**漂白剂约 1:30、停留约 10 分钟**(仅对无孔、已洗净有机物的表面有效)【收容医学】
- 若任一场地同时养猫:**避免松焦油/苯酚/煤酚/氯二甲酚类**消毒剂,对猫有毒【NSW准则】

### 防交叉污染

- **清洁顺序:健康幼犬 → 健康成犬 → 患病犬 → 隔离区最后**;同区内最脆弱的先做【收容医学】
- **工具分区、颜色区分**(各区专用拖把/桶/消毒剂),健康区与隔离区绝不共用【收容医学】
- 清完隔离/患病区后换/防护衣物、手套,洗手
- 内表面须**不透水、坚固、可冲洗**,地墙接缝密封,地面利于排水【NSW准则】;清洁时**保持犬只干爽**

## 二、喂食与饮水

- **成犬每天至少喂一次**【NSW准则】【维州准则】;FluffyWA 实践成犬两餐
- **6 月龄以下幼犬每天至少喂两次**【NSW准则】(FluffyWA 幼犬按月龄 3–4 餐,新生犬另按存活方案频率)
- **随时供应新鲜清洁饮水**(不间断);高温天在阴凉处多放几个水盆,防被打翻【NSW准则】【RSPCA】
- 食物**卫生配制,盛在干净、不易打翻的容器**;食盆水盆每天清洗【NSW准则】
- **沿用犬只原有食谱,避免突然换粮**(减少肠胃不适)【RSPCA】
- **每天监督喂食、饮水并观察**,记录每犬进食量与食欲【NSW准则】;体况评分定期记录【收容医学】

## 三、每日健康检查

### 频率与责任

- **每天检查每一只在舍犬**,确认健康与福利——这是明确要求【NSW准则】【维州准则】【RSPCA】
- **高风险犬更频繁**:幼犬、患病、隔离、术后、老年犬【收容医学】
- 发现患病/受伤**及时兽医处理**;疑似传染病**立即隔离**(须有隔离设施:场内或兽医处)【NSW准则】

### 每日检查清单(逐只过一遍)

| 观察项 | 看什么 / 异常信号 |
| --- | --- |
| 食欲 / 饮水 | 是否吃完、拒食、饮水异常 |
| 排泄 | 频次、腹泻、带血、里急后重、呕吐 |
| 精神 / 行为 | 沉郁、爱躲、异常——常是伤病早期信号 |
| 活动 / 步态 | 跛行、不愿负重、僵硬 |
| 被毛 / 皮肤 | 肿块、伤口、跳蚤蜱虫 |
| 眼 / 鼻 | 分泌物、脓涕 |
| 呼吸道 | 咳嗽、喘(犬舍咳) |
| 体况 / 体重 | 过瘦/过胖、体重异常变化 |
| 疼痛 / 应激 | 疼痛姿势、持续应激信号 |

> 判色沿用**三色状态法**(绿=正常 / 黄=观察 24h 复查 / 红=警戒即隔离上报),与《经理管控系统》一致。拿不准就高不就低。

### 入舍与疫苗

- **入舍前须出示疫苗证**,证明过去 12 个月内接种**犬瘟热、肝炎、细小、犬舍咳**(即 **C5**)【NSW准则】
- 入舍前须先接种的**提前天数以所在 council/兽医要求为准**(常见做法提前接种,但"提前 14 天"非 NSW 准则明文)【须核对当地】
- 入舍当天做**健康与行为检查、记录基线**;新入住犬应**更密切观察**(应激会降低免疫、更易感染)【收容医学】【RSPCA】
- 确保寄养期间**可及时看兽医**,留存主人的兽医联系方式【RSPCA】

### 热应激(Perth 夏季重点)

- **识别**:持续快速喘、心跳快、牙龈苍白或发红、流涎、呕吐腹泻、虚弱嗜睡、肌肉震颤、抽搐、少尿、虚脱【RSPCA】
- **预防**:持续供应阴凉通风处与充足饮水;避免高温地面(水泥/沙);运动只安排在最凉时段(清晨/傍晚),避开一天最热时【RSPCA】
- **急救**:"先降温、后送医"——立即开始降温,再送兽医【RSPCA】

## 四、落到每天:四场地一日节奏

骨架沿用围绕狗作息的两个重活块 + 值守;四个场地按规模执行(K3 分区轮转,K4 含幼犬专人)。

| 时段 | 清洁消毒 | 喂食饮水 | 健康检查 |
| --- | --- | --- | --- |
| 07:00–09:00 晨 | 粪尿随清、补水盆 | 查水、备餐 | **当天第一次逐只巡查** |
| 09:00–12:00 上午 | **趁狗出舍:每日清洁**;消毒日则清洁后消毒 | 早餐;喂后 15 分钟记进食 | 放风时观察活动/步态/社交;记黄红 |
| 12:00–13:00 午 | 值守、随清 | 查水补水 | 巡查一次,重点黄红犬 |
| 13:00–16:00 下午 | 换客终末消毒;活动场清理 | 晚餐;幼犬按月龄加餐 | 第二轮放风观察;高温天加密查中暑 |
| 16:00–18:00 傍晚 | 关舍前终检、垫料、补水 | 幼犬晚喂 | 晚巡逐只,交接黄红名单 |
| 夜间(K4 驻场) | 随清、保持干爽 | 幼犬按月龄夜喂,随时供水 | 幼犬夜间三查、患病犬巡查 |

> **顺序铁律**:任何时段的清洁与巡查都按「健康幼犬 → 健康成犬 → 患病/隔离最后」的顺序;隔离区专人专具、进出换手套。

## 依据与免责

- **RSPCA**:Five Domains 福利模型、"每天检查伤病"、防暑、寄养择选与兽医可及性(kb.rspca.org.au)。
- **NSW Code of Practice No 5(犬猫寄养场所)**:每日清洁 / 每周消毒 / 喂食频率 / 每日巡查 / 入舍疫苗——澳洲最具体的对标参考(WA 非强制)。
- **维州寄养准则**:每日清洁与巡查、每日喂食、清洁饮水。
- **收容医学最佳实践**(UW-Madison、ASPCApro 等):先清洁后消毒、细小消毒剂选择、清洁顺序与工具分区——**非法规**。
- ⚠️ 数字来自检索整理,**正式 SOP 前请核对官方原文**;**四个场地各以所在 council 犬舍执照条件为准**;临床阈值以监管兽医为准。
