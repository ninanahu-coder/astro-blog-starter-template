本指导书是 FluffyWA 犬舍的清洁标准作业程序(SOP),把**成犬**和**幼犬**的清洁分开规定,因为两者的风险和方法完全不同:成犬区重在维持卫生和防疫,幼犬区重在极致防病和用药温和。所有员工上岗前须阅读并按此执行。

> 总原则贯穿全书:**先清洁(去有机物)、再消毒(杀病原)、给够停留时间、冲净晾干**。临床/防疫阈值以监管兽医意见为准。

## 通用铁律(成犬幼犬都适用)

1. **顺序:先清洁再消毒**——有机物残留会让季铵盐、漂白剂失效,顺序不能反
2. **停留时间是硬指标**——喷完立刻冲=没消毒,用计时器
3. **清洁方向:易感→抵抗,干净→脏**——幼犬最先、健康成犬其次、隔离/患病犬最后
4. **工具分区、颜色区分**——成犬区、幼犬区、隔离区各用独立工具,严禁跨区借用(工具本身是传播媒介)
5. **绝不混用化学品**——漂白剂 + 含氨清洁剂 = 有毒气体;漂白剂 + 季铵盐互相失效
6. **手卫生**——接触不同犬群之间洗手或换手套;换群时换鞋或用专用鞋
7. **趁狗出舍时清洁**——放风时清空舍位再清洁,减少犬对噪音/器具的恐惧,便于彻底消毒

# 第一部分:成犬清洁

## 成犬清洁频率表

| 项目 | 频率 |
| --- | --- |
| 犬舍粪便/尿液即时清理 | 随时,发现即清 |
| 犬舍地面清洁 | 每日 |
| 食盆、水盆清洗 | 每日(食盆每餐后) |
| 垫料更换 | 每日或脏污即换 |
| 犬舍消毒 | 每日一次 |
| 活动场清理 | 每日 |
| 活动场深度清洁 | 每周 |
| 犬舍深度消毒 | 每周至少一次;换犬入住前;疫情后 |
| 换客(不同狗入住同一舍位) | 每次彻底清洁 + 消毒 |

## 成犬每日清洁步骤

1. **移出狗**到活动场或临舍(不在狗在场时喷化学品)
2. **干清理**:铲粪、收剩食、清脏垫料、扫毛发(先干后湿,减少病原扩散)
3. **洗涤剂刷洗**:地面、墙脚、笼门,重点角落和排水口
4. **清水冲净**洗涤剂残留
5. **上消毒剂**:日常用加速过氧化氢(5–10 分钟)或季铵盐(10 分钟),喷洒均匀,**等足停留时间**
6. **冲净 + 晾干**:漂白剂等消毒后必须冲净以免灼伤狗爪;潮湿滋生细菌霉菌,务必晾干
7. **食盆水盆**:每日清洗、消毒液浸泡、冲净晾干
8. **垫料**:更换,脏的高温洗涤烘干

## 成犬消毒剂选择

| 消毒剂 | 用途 | 停留时间 |
| --- | --- | --- |
| 加速过氧化氢(AHP) | **日常主力**,温和好冲 | 5–10 分钟 |
| 季铵盐(QUAT) | 日常常规(**杀不死细小**) | 约 10 分钟 |
| 过硫酸氢钾 | 每周深度消毒、防疫 | 约 10 分钟 |
| 漂白剂 1:32 | 细小疫情/病史舍位终末消毒 | 10 分钟,冲净通风 |

# 第二部分:幼犬清洁(最严格)

幼犬(尤其未完成免疫的)是犬舍最脆弱群体:细小易感窗口长、呼吸道娇嫩、对消毒剂气味敏感。幼犬区(K4)必须**完全独立**于成犬群,用独立工具、独立 PPE,最好专人负责。

## 幼犬清洁频率表

| 项目 | 频率 |
| --- | --- |
| 排泄物即时清理 | 随时,比成犬更勤(幼犬排泄频繁) |
| 育婴区/舍位地面清洁 | 每日 ≥1–2 次 |
| 食盆、水盆、喂食器具清洗 | 每次喂食后(幼犬每天 3–4 餐) |
| 垫料更换 | 每日,脏污/潮湿即换(幼犬易失温) |
| 舍位常规清洁消毒 | 每日 |
| 育婴区深度消毒(空置周转时) | 每次周转 + 每周 |
| 换窝/新幼犬入住 | 每次彻底清洁 + 杀细小消毒 |

## 幼犬清洁步骤(与成犬的关键差异)

1. **移出幼犬到安全温暖处**——幼犬 4 周龄前不能自我调温,清洁期间注意保温,湿冷会致命
2. **干清理**排泄物和脏垫料
3. **温和洗涤剂刷洗**,彻底去有机物
4. **清水冲净**
5. **消毒——这里是幼犬与成犬最大的不同**(见下)
6. **充分通风**:消毒后一定通风、冲净晾干,再让幼犬回舍——**绝不让消毒气味在幼犬周围聚集**
7. **保持干燥温暖**:换上干净干燥的垫料

## 幼犬消毒剂选择(关键)

**新生犬周围避免漂白剂、酚类(松油/来苏尔类)、季铵盐的挥发气味**——气体可能伤害呼吸道、诱发衰弱综合征。

| 场景 | 用什么 | 说明 |
| --- | --- | --- |
| 新生犬周围日常温和清洁 | **氯己定(洗必泰)** | 温和,但**注意:氯己定杀不死细小** |
| 需要杀细小(空舍周转、暴露后、新幼犬入住) | **加速过氧化氢 1:16,约 5 分钟** | 相对温和、比漂白剂刺激小,**幼犬区杀细小首选** |
| 细小疫情终末消毒 | 漂白剂 1:32,10 分钟 | 幼犬须先移出,消毒后充分通风冲净晾干再回舍 |

> 因为氯己定杀不死细小,而漂白剂气味对幼犬有害——所以幼犬区杀细小优先用**加速过氧化氢**,兼顾"杀得死"和"够温和"。

## 幼犬区额外注意

- **完全独立**:专用扫把、拖把、水桶、抹布,与成犬区绝不混用
- **清洁顺序里幼犬最先**:员工一天里先做幼犬区,再做成犬,最后做隔离/患病犬——避免把病原带给最脆弱的幼犬
- **换群换衣**:进出幼犬区前后洗手,理想情况下换鞋或穿专用鞋、换外衣
- **清洁不打断保温和喂食节奏**:低体温 + 低血糖是幼犬三大杀手中的两个,清洁时优先保证幼犬不受凉

## 一页纸对照速查

| | 成犬 | 幼犬 |
| --- | --- | --- |
| 地面清洁 | 每日 | 每日 1–2 次 |
| 食盆清洗 | 每餐后(每日 2 餐) | 每餐后(每日 3–4 餐) |
| 日常消毒剂 | 加速过氧化氢 / 季铵盐 | **氯己定**(温和) |
| 杀细小 | 漂白剂 1:32 / AHP / 过硫酸氢钾 | **加速过氧化氢 1:16**(优先) |
| 深度消毒 | 每周 + 换客 | 每周 + 每次周转 |
| 清洁顺序 | 幼犬之后、隔离之前 | **最先** |
| 特别注意 | 冲净防烧爪、晾干 | **避免刺激气味、保温、专用工具** |

> 本指导书与《清洁消毒时间表》《提高幼犬存活率方案》《最有效运营方案》配套使用。建议把"一页纸对照速查"和各自的消毒剂表打印张贴在成犬区和幼犬区的清洁间。
