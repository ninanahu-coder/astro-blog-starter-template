为了保证狗舍的日常运营井然有序,让每一只狗狗都能得到妥善的照顾,特制定以下工作安排。全体工作人员请严格按照时间表执行,并做好每日记录。

## 每日工作时间表

### 上午

| 时间 | 工作内容 |
| --- | --- |
| 07:00 – 07:30 | 到岗巡查,检查每只狗狗的精神状态和健康情况 |
| 07:30 – 08:30 | 清理犬舍,更换垫料,清洗水盆和食盆 |
| 08:30 – 09:00 | 早餐喂食,按照喂养记录表配餐 |
| 09:00 – 10:30 | 分批遛狗、户外活动 |
| 10:30 – 11:30 | 美容护理:梳毛、洗澡(按预约排班) |
| 11:30 – 12:00 | 补充饮水,记录上午情况 |

### 下午

| 时间 | 工作内容 |
| --- | --- |
| 12:00 – 13:30 | 工作人员轮流午休,留守人员值班巡查 |
| 13:30 – 14:30 | 犬舍消毒,清理运动场 |
| 14:30 – 16:00 | 训练与社交活动,幼犬单独看护 |
| 16:00 – 17:00 | 晚餐喂食,清点物资库存 |
| 17:00 – 18:00 | 傍晚遛狗,收拾场地 |
| 18:00 – 18:30 | 晚间巡查,填写工作日志,交接班 |

## 每周任务分工

- **周一**:全面大扫除,犬舍深度消毒,更换全部垫料
- **周二**:检查疫苗和驱虫记录,预约兽医巡诊
- **周三**:盘点狗粮、药品和清洁用品库存,提交采购清单
- **周四**:设备检修(围栏、笼具、供水系统、监控)
- **周五**:整理领养与寄养档案,回访客户
- **周六 / 周日**:接待日,安排参观和领养面谈,人手加倍排班

## 注意事项

1. **健康优先**:发现狗狗有食欲不振、腹泻、咳嗽等异常情况,立即隔离并上报负责人,必要时联系兽医。
2. **喂食规范**:严格按照每只狗狗的喂养记录表配餐,注意特殊饮食需求(幼犬、老年犬、过敏犬只)。
3. **安全管理**:遛狗时必须使用牵引绳,大型犬与小型犬分开活动;进出犬舍随手关门。
4. **消毒制度**:食盆水盆每日清洗,犬舍每日消毒一次,公共区域每周深度消毒。
5. **记录完整**:每日工作日志必须如实填写,交接班时当面确认,不得遗漏。
6. **应急预案**:紧急联系电话张贴在值班室,任何突发情况第一时间通知当班负责人。

如有排班调整需求,请提前至少两天向负责人申请,确保每个时段都有足够人手在岗。感谢大家的辛勤付出,让我们一起为狗狗们提供一个安全、干净、温暖的家!
