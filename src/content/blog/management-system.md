核心思路:**狗的作息是固定的,员工的工作和经理的监控都围绕它设计,而不是反过来。** 一个经理管不过来 160+ 只狗的每个细节——高效的关键是「按异常管理」:让需要关注的狗自动浮上来,90% 正常的狗不用盯,精力放在异常的 10%。

## 一、以「狗的一天」为轴

| 时段 | 狗的状态与需求 | 员工对应工作 | 经理关注点 |
| --- | --- | --- | --- |
| 07:00–09:00 晨 | 苏醒、排泄、饥饿,精神最能看出问题 | 巡查、补水、备餐 | 汇总晨检黄/红,分配人手 |
| 09:00–12:00 上午 | 精力最旺,需运动排泄 | 喂食 → 趁出舍清舍 → 第一轮运动 | 新入舍分配、跨场地调度 |
| 12:00–13:00 午 | 自然休息期 | 值守巡查、补水 | 12:00 电话轮询 |
| 13:00–16:00 下午 | 第二活跃期 | 消毒 → 第二轮运动 → 晚餐 | 推进周任务、物资 |
| 16:00–18:00 傍晚 | 进食后平静,接送高峰 | K4 接待、晚巡、关舍 | 17:45 日报汇总 |
| 18:00–07:00 夜 | 睡眠(幼犬仍需喂食保温) | K4 驻场、巡查、远程监控 | 值班待命、看远程报警 |

## 二、员工每日部署与动态调整

重活集中在狗活跃的两个 1.5 人工时段(9–12、13–16),正好趁狗出舍运动时清洁消毒;值守时段只做轻活。

| 触发情况 | 调整动作 |
| --- | --- |
| 某场地出现隔离病犬 | 加派、专人专工具、清洁顺序改最后 |
| K4 幼犬增多/新生 | 增夜班驻场、幼犬专人 |
| 周末接送高峰 | K4 前台加人、预约错峰 |
| 员工请假 | 就近组机动顶替,替班岗经理顶 |
| 极端高温 | 增补水巡查、检查制冷 |
| 兽医巡诊日 | 与深度消毒错峰,留人陪诊 |
| 某场地爆发疑似疫情 | 封场限流、暂停跨场地人员流动、隔离区专人到底 |
| 停电/制冷故障 | 优先保幼犬区与隔离区温控,启动应急联系与转移预案 |
| 大量新入舍(周五/长假前) | 前置健康筛查人手、错峰办理入舍、观察区先满 |

## 三、经理的管控系统（核心）

### 每犬三色状态

| 状态 | 含义 | 谁处理 |
| --- | --- | --- |
| 🟢 绿 | 正常 | 员工日常,经理不介入 |
| 🟡 黄 | 观察(轻微异常) | 记录+交接,经理知晓,24h 复查 |
| 🔴 红 | 警戒(异常/隔离/用药) | 经理每日盯,必要时兽医 |

**经理每天只看黄红清单**,一眼看清全公司需要关注哪几只。

**三色判定标准**(让一线员工不用猜、判色一致):

| 观察项 | 🟢 绿 | 🟡 黄(观察) | 🔴 红(警戒) |
| --- | --- | --- | --- |
| 进食 | 正常吃完 | 一餐吃不完/挑食 | 连续两餐拒食 |
| 排便 | 成形正常 | 偏软一次 | 腹泻、带血、呕吐 |
| 精神/活动 | 活泼反应正常 | 略沉、爱躲 | 明显萎靡、站不起 |
| 呼吸道 | 无 | 偶发单声咳/喷嚏 | 持续咳、脓涕、喘 |
| 其它 | 无异常 | 轻微跛行/小伤口 | 大出血、抽搐、胀气、无法负重 |

> 定色原则:**取最重那一项**——任一项落到红,整只狗即为红。拿不准时**就高不就低**,宁可多观察一次。黄色若 24h 内未复原或加重,自动升红。

### 经理每日控制闭环

| 时间 | 动作 | 内容 |
| --- | --- | --- |
| 07:00–08:30 | 计划 | 看昨夜日报和预约,排人手 |
| 08:30 | 点名 | 四场地点名,汇总黄红 |
| 12:00 | 监控 | 轮询,确认任务完成、新异常 |
| 15:00 | 调整 | 实时调兵、推进周任务 |
| 17:45 | 复盘 | 四场地日报汇总 |

**点名/电话轮询固定脚本**(30 秒问完,避免"还好吧"式无效汇报):

1. 今天有没有新转黄或转红?分别是哪几只、什么情况?
2. 昨天的红名单现在怎样——好转、持平还是加重?
3. 计划任务(清洁/喂食/放风)全部按时完成了吗?没完成的原因?
4. 人手够不够?有没有需要跨场地支援的?
5. 有没有物资/设备问题(制冷、水、消毒剂库存)?

### 交接班要点(白班↔夜班、班次之间)

- **书面为准、口头为辅**:黄红名单、用药执行情况、未完成任务一律写进交接表,不靠记忆
- **逐只交接红名单**:每只红色犬当面点清现状、下一步、复查时间
- **未闭环事项挂账**:上一班没处理完的,明确写清由谁在何时接手
- **物资与设备状态**:制冷、监控、消毒剂库存、异常报警一并交接

### 分级上报阈值

绿→无需上报;黄→记录+交接告知组长;红/急症→立即电话经理,幼犬急症/胀气/大出血/抽搐同时联系急诊兽医。

### 远程监视与效率指标

摄像头巡四场地 + 幼犬/隔离区温度报警;衡量指标:量力照护比、任务准时完成率、健康闭环时间、运动达标率、幼犬存活率。

**核心指标定义与目标**(口径统一,便于四场地横向对比):

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 量力照护比 | 在舍犬数所需工时 ÷ 实际可用工时,>1 即超载 | ≤1(不长期超载) |
| 任务准时完成率 | 按时完成的清洁/喂食/放风任务数 ÷ 计划任务数 | ≥95% |
| 健康闭环时间 | 从发现异常(转黄/红)到有处置结果的耗时 | 黄 ≤24h、红当天 |
| 运动达标率 | 达标运动犬数 ÷ 在舍犬数 | ≥95% |
| 幼犬存活率 | 断奶存活幼犬数 ÷ 出生数 | 逐月追踪、持续提升 |

> 经理每周看一次趋势线而非单日值:某场地任一指标连续下滑,通常是人手、流程或健康问题的早期信号。

## 四、达到最高效率的四个杠杆

1. **围绕狗的作息排班**——清洁在狗出舍时做,既不折腾狗又省工
2. **按异常管理**——经理只盯黄红,不微观管理 160 只
3. **跨场地弹性**——两两成组机动
4. **预防优于补救**——入舍筛查、疫苗、消毒、体重监测把问题挡在前面
